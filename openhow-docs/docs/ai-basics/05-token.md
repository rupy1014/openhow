**토큰은 AI가 글을 세는 단위예요. 그리고 이게 곧 돈이에요.**

## 얼마나 되는데

대충 이 정도예요.

- 한글 1글자 = 약 1~2 토큰
- 영어 1단어 = 약 1~2 토큰

```text
"안녕하세요"    = 약 5 토큰
"Hello world"  = 약 2 토큰
```

한글이 영어보다 토큰을 더 먹어요. 같은 말이면 영어가 싸다는 뜻이죠.
그렇다고 영어로 쓸 필요는 없어요. 알아두기만 해요.

## 입력이랑 출력이 값이 달라

| 구분 | 뭐야 | 값 |
| --- | --- | --- |
| **입력 토큰** | 내가 AI한테 보내는 글 | 싸 |
| **출력 토큰** | AI가 써주는 글 | 입력의 3~5배 |

그래서 이런 차이가 생겨요.

```text
긴 문서 요약   → 입력 많고 출력 적음 → 싸다
"자세히 설명해줘" → 출력이 길어짐    → 비싸다
```

## 진짜 돈이 새는 곳은 따로 있어요

여기가 핵심이에요.

**AI는 대화할 때마다 지금까지의 대화를 통째로 다시 읽어요.**

```text
1번째 질문 → 질문 1개만 읽음
10번째 질문 → 지금까지 대화 9개 + 새 질문을 전부 다시 읽음
50번째 질문 → 49개를 전부 다시 읽음
```

대화가 길어질수록 **매번 읽는 양이 늘어나.** 그래서 갑자기 느려지고 비싸져요.

이건 AI가 기억을 못 해서 생기는 일이에요. 자세한 건 [AI는 기억하지 않는다](./context) 에서 다뤄요.

## 그래서 뭘 하면 돼요

세 개만 기억하면 돼요.

**1. 주제가 바뀌면 새 대화를 열어요**

블로그 글 고치다가 갑자기 이력서 얘기를 꺼내지 마세요. 앞의 대화를 계속 다시 읽게 되니까요.

**2. 길어지면 압축해요**

Claude Code 에서 `/compact` 라고 치면 대화를 요약해서 줄여줘요.

**3. 범위를 좁혀서 말해요**

```text
❌ "이 프로젝트 개선해줘"      → 파일을 다 읽어봄
✅ "계획.md 파일의 3번 항목만 고쳐줘"  → 그것만 읽음
```

## 토큰을 세고 있어야 하나요?

아니요. 세는 사람 없어요.

**"대화가 길어지면 비싸진다"** 는 감각 하나면 충분해요.
실제 요금이 어떻게 되는지는 [얼마 들어?](../claude-code/cost) 에서 숫자로 다뤄요.

## 자주 헷갈리는 포인트

### 토큰이 얼마나 남았는지 어떻게 보나요?

Claude Code 에서는 화면 아래쪽에 남은 컨텍스트가 % 로 떠요. 웹에서는 안 보여줘요.

### 짧게 쓰면 무조건 좋은가요?

아니요. 필요한 맥락을 안 주면 결과가 나빠져서 다시 시키게 돼요. 그게 더 비싸요.
**필요한 건 다 주고, 필요 없는 건 빼는 것**이 맞아요.

### 파일을 많이 만들면 토큰을 더 먹나요?

파일이 있다고 먹는 게 아니라 **읽어야 먹어.** 파일은 많아도 되고, 대신 "이 파일만 봐" 라고 짚어주면 돼요.

## 한 줄 정리

> 토큰은 AI가 글을 세는 단위고, 대화가 길어질수록 매번 다시 읽어서 비싸져요.
