## 핵심 요약

이 문서의 핵심은 세 줄이에요.

- **AI는 기억하지 않아.** 기억하는 것처럼 보일 뿐이고, 실제로는 대화 맨 위부터 매번 다시 읽어 내려와요.
- 이 사실 하나가 **오염, 컴팩트, 토큰, 검증**을 전부 설명해요. 따로 외울 게 아니라 하나로 이어져 있어요.
- 기억을 진짜로 남기고 싶으면 **파일에 적어야 해.** 그게 메모리예요.

```text
컨텍스트 = 지금 대화에서 매번 다시 읽는 내용 (단기)
메모리 = 파일에 적어둬서 계속 참고하는 내용 (장기)
```

## 1. AI는 매번 처음부터 다시 읽는다

이게 이 문서에서 제일 중요한 문장이에요.

대화를 예로 들어볼게요.

```text
나: 1 더하기 2는 뭐야?
AI: 3이야.

나: 셰익스피어 희극에는 뭐가 있어?
AI: 한여름 밤의 꿈, 십이야 같은 게 있어.

나: (세 번째 질문)
```

세 번째 질문을 던지면 AI는 어떻게 할까요?

앞의 대화를 "기억"해서 이어가는 것 같죠?

아니에요.

**맨 위 "1 더하기 2는 뭔가요?"부터 다시 읽으면서 내려와요.**

매번 그래요. 질문할 때마다 전체를 처음부터 다시 읽어요.

```text
기억하고 있는 게 아니라,
매번 전체를 다시 읽어서 기억하는 것처럼 보이는 것이다.
```

이걸 무상태성이라고 불러요. 어려운 말 같지만 그냥 "기억력이 없다"는 뜻이에요.

이 하나만 이해하면 뒤에 나오는 게 전부 자연스럽게 이어져요.

## 2. 그래서 대화가 길어지면 느려지고 비싸진다

매번 처음부터 다시 읽는다는 건, 대화가 길어질수록 읽어야 할 양이 계속 늘어난다는 뜻이에요.

```text
질문 1개일 때  → 조금 읽음
질문 30개째    → 앞의 29개를 전부 다시 읽고 답함
```

그래서 대화가 길어지면 답이 느려지고, 비용도 올라가요.

이 "지금 대화에서 읽고 있는 전체 내용"을 컨텍스트라고 불러요.

그리고 여기에 담을 수 있는 한도가 있어요. 그 한도를 컨텍스트 윈도우라고 해요.

Claude는 예전에 200K 토큰이었는데, 지금은 100만 토큰까지 늘어났어요.

숫자는 계속 바뀌니까 외울 필요 없어요. **"담을 수 있는 그릇의 크기가 있다"** 정도만 알면 돼요.

지금 얼마나 썼는지 궁금하면 이렇게 확인할 수 있어요.

```text
/context
```

## 3. 컨텍스트는 오염된다

여기서 진짜 실전 문제가 나와요.

한 세션에서 이런 흐름으로 작업했다고 해봐요.

```text
1. 로그인 기능을 개발했다
2. 갑자기 기획 얘기를 좀 했다
3. 다시 개발로 돌아왔다
```

이제 AI는 매번 이 전부를 처음부터 다시 읽어요.

개발 얘기 사이에 낀 기획 얘기까지 매번 같이 읽는 거예요.

이런 상태를 **컨텍스트가 오염됐다**고 말해요.

```text
작업의 종류가 중간에 바뀌면 컨텍스트가 오염된다.
```

오염되면 답이 뭉개져요. 엉뚱한 걸 참고하고, 아까 지나간 얘기를 다시 꺼내요.

그래서 이런 기준을 잡으면 좋아요.

| 상황 | 어떻게 |
| --- | --- |
| 기능 개발하다가 버그 수정으로 넘어감 | 새 세션을 여는 게 좋아 |
| 기획하다가 개발로 넘어감 | 새 세션을 여는 게 좋아 |
| 헤더 메뉴 고치다가 같은 화면 히어로 영역 고침 | 그냥 이어서 해도 돼 |
| 파일 A 설명 듣고 파일 B 설명 들음 | 그냥 이어서 해도 돼 |

기준은 간단해요.

```text
작업의 목적 자체가 바뀌었나?
→ 바뀌었으면 새 세션
→ 범위만 조금 움직인 거면 그냥 진행
```

**컨텍스트를 잘 관리하는 게 AI에게 똑똑하게 일 시키는 방법이에요.**

## 4. 컴팩트 — 대화를 압축하기

대화가 길어져서 그릇이 차오르면 압축을 해야 해요. 그걸 컴팩트라고 불러요.

한 70% 정도 차면 자동으로 압축이 걸려요. 이걸 오토 컴팩트라고 해요.

그런데 오토 컴팩트는 문제가 있어요.

**전체 맥락을 기준으로 뭉뚱그려서 줄이거든요.**

아까 예로 든 상황을 다시 봐요. 개발하다가 중간에 기획 얘기를 좀 했었죠.

오토 컴팩트가 걸리면 그 불필요한 기획 얘기까지 압축본 안에 남을 수 있어요.

그래서 직접 압축하면서 방향을 지정해주는 게 좋아요.

```text
/compact 개발 내용 중심으로 정리해줘
```

이렇게 하면 남길 내용을 골라서 압축할 수 있어요.

구체적으로 말할수록 더 잘 정리돼요.

```text
오토 컴팩트 = 알아서 뭉뚱그려 줄임
직접 컴팩트 = 뭘 남길지 내가 지정
```

예전 200K 시절엔 자주 눌러줘야 했는데, 100만 토큰으로 늘어난 뒤로는 그 빈도가 많이 줄었어요.

## 5. 진짜 기억은 파일에 적는 것이다

컨텍스트는 창을 닫으면 사라져요. 단기 기억이니까요.

그럼 다음에도 계속 알고 있어야 하는 건 어떻게 할까요?

**파일에 적으면 돼.** 그게 메모리예요.

대표적인 게 `CLAUDE.md`예요.

Claude Code는 세션을 시작할 때 이 파일을 먼저 읽어요. 그래서 매번 다시 설명 안 해도 되는 거예요.

```text
컨텍스트 = 이번 대화에서만 유효 (창 닫으면 사라짐)
메모리 = 파일에 적혀서 다음에도 계속 읽힘
```

`CLAUDE.md`를 어떻게 쓰는지, 전역 설정과 프로젝트 설정이 어떻게 다른지는 이미 다뤘어요.

- [첫 프로젝트 만들기](/claude-code/first-project) — global / project 감각
- [일 잘 시키기](/working-with-ai/good-prompts) — `CLAUDE.md`에 뭘 적을지

여기서는 한 가지만 기억하면 돼요.

```text
같은 설명을 두 번 하고 있다면, 그건 파일에 적을 때가 된 거다.
```

## 6. "AI를 학습시킨다"는 오해

이 오해가 정말 흔해요.

대화를 많이 하면 AI가 나에 대해 학습한다고 생각하는 거죠.

아니에요.

AI는 이미 회사에서 학습을 다 끝내놓은 상태로 우리에게 와요.

우리가 대화로 하는 건 학습이 아니라, **이미 들어 있는 것 중에서 꺼내는 것**에 가까워요.

```text
학습 = 회사가 미리 해둔 것
대화 = 그 안에서 원하는 걸 끄집어내는 것
```

진짜 학습은 데이터를 수천에서 수만 번 밀어 넣는 별도의 작업이에요. 우리가 대화로 하는 게 아니고.

여기서 따라오는 사실이 하나 더 있어요.

AI는 내용을 이해해서 답하는 게 아니라, **가장 그럴듯한 패턴을 확률로 골라서** 답해요.

확률로 고른다는 건 평균값에 가까운 걸 고른다는 뜻이에요.

```text
AI는 평균적인 답을 내놓는 경향이 있다.
```

그런데 우리가 만들려는 건 보통 평균에서 벗어난 거잖아요.

내가 원하는 게 구체적일수록 AI의 평균과는 멀어져요.

그래서 질문을 잘게 쪼개서 던져야 하고, 빈칸은 사람이 채워야 해요.

이 얘기는 [다음 문서](/working-with-ai/better-results)에서 실전 방법으로 이어갈게요.

## 7. 토큰은 곧 비용이다

토큰은 AI가 글을 처리하는 단위예요. 그리고 그게 그대로 비용이에요.

크게 세 가지로 나뉘어요.

| 종류 | 뭔가 |
| --- | --- |
| 입력 토큰 | 내가 보내는 것 + 매번 다시 읽는 대화 전체 |
| 출력 토큰 | AI가 최종적으로 내놓는 답변 |
| 사고 토큰 | 답을 만들기 전에 분석하고 계획하는 과정 |

앞에서 "매번 처음부터 다시 읽는다"고 했죠?

그래서 대화가 길어질수록 **입력 토큰이 자연스럽게 계속 늘어나요.**

Claude Code는 단순히 답만 하는 게 아니라 분석하고, 설계하고, 계획하고, 실행해요.

그 모든 단계에서 토큰을 써요.

토큰을 아끼는 소소한 방법들이 있긴 해요.

```text
영어로 쓰면 토큰 수가 적게 들고 이해도도 높다
이모지는 한 개당 토큰을 꽤 먹는다
"50줄 미만으로 답해줘" 같은 제약을 주면 출력이 줄어든다
```

영어가 유리한 건 맞는데, 어려우면 그냥 한국어로 해도 돼요. 실제로 대부분 한국어로 작업해요.

그리고 마지막으로 제일 중요한 얘기.

```text
지금은 토큰 신경 쓰지 마.
```

토큰이 모자랄 정도로 개발할 단계가 아니에요.

일단 써보면서 "아 이만큼 쓰면 이 정도 나가는구나" 감을 잡는 게 먼저예요.

지금은 AI한테 질문 던지고 결과 보는 게 편해지는 것, 그게 훨씬 중요해요.

## 자주 헷갈리는 포인트

### AI가 갑자기 멍청해졌어요

대부분 컨텍스트 오염이에요. 대화가 길어졌거나 작업 종류가 중간에 바뀌었을 가능성이 높아요. 새 세션을 열고 필요한 내용만 다시 주면 대체로 해결돼요.

### 컴팩트는 언제 눌러야 하나요?

작업이 한 덩어리 끝났을 때가 좋아요. 작업 중간에 누르면 필요한 맥락까지 날아갈 수 있어요. 그리고 그냥 누르지 말고 "무슨 내용 중심으로"를 같이 말해줘요.

### 새 세션 열면 처음부터 다시 설명해야 하잖아요

그래서 `CLAUDE.md`가 있는 거예요. 매번 설명하는 내용이라면 파일에 적어두면 돼요. 이번 작업 상황은 투두 문서로 넘기면 되고.

### 대화 내용을 AI가 학습해서 다음에 써먹나요?

아니요. 창을 닫으면 사라져요. 남기고 싶으면 파일에 적어야 해요.

### 토큰이 얼마나 남았는지 어떻게 보나요?

`/context`로 지금 대화의 사용량을 볼 수 있어요. 플랜 사용량은 일정 시간마다 다시 채워지니까, 처음엔 그냥 쓰면서 감만 잡으면 돼요.

### 컨텍스트랑 메모리랑 계속 헷갈려

이 두 줄만 기억해요. 컨텍스트는 지금 대화에서 매번 다시 읽는 것, 메모리는 파일에 적어둬서 다음에도 읽히는 것.
