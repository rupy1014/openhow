# AI 입문 자료실

**IT를 하나도 몰라도 읽을 수 있게 만든 무료 자료실이에요.**

유튜브 보다가 "저거 나도 해보고 싶은데" 싶었는데,
막상 찾아보니 무슨 말인지 하나도 모르겠던 적 있죠?

여기는 그 지점부터 시작해요.

## 여기 뭐가 있나요?

| 단계 | 내용 |
| --- | --- |
| 🚩 여기부터 | 이 자료실이 뭐고, 뭐부터 보면 되는지 |
| 📖 용어 사전 | 모르는 말 나오면 찾아보는 109개 용어 |
| 💻 컴퓨터 기초 | 폴더, 터미널, VS Code — 진짜 기본부터 |
| 🧠 AI 기초 | AI가 뭐고, 왜 가끔 멍청해지는지 |
| ⚡ Claude Code 시작 | 설치하고 첫 실행까지 |
| 🤝 일 잘 시키기 | 같은 AI인데 결과가 다른 이유 |
| 🤖 업무 자동화 | 반복하는 일을 명령어 하나로 |
| 🛠️ 서비스 만들기 | 아이디어부터 인터넷에 올리기까지 |
| 📣 팔아보기 | 피드백 받고, 사람 모으고, 돈 받기 |
| 📎 더 보기 | MCP, 브라우저 자동화 같은 심화 |

## 처음이면 이거만 기억해요

**모르는 말이 나와도 멈추지 마세요.**

용어 사전에서 찾거나, AI한테 그냥 물어보면 돼요.

```text
방금 나온 "배포"가 무슨 뜻인지 초등학생도 알아듣게 설명해줘.
```

이게 이 자료실을 쓰는 가장 빠른 방법이에요.
