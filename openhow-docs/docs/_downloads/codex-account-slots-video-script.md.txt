# 카쫀쿠 1개, 비쫀쿠 2개, 겜쫀쿠 4개 — ChatGPT·Codex 싸게 쓰는 법

## 영상 핵심 방향

이 영상의 주인공은 **겜스고를 실제로 구매하고, 계정을 받고, ChatGPT와 Codex에 로그인해서 사용하는 과정**이다.

다만 공유형 계정의 장점만 이야기하지 않는다.

**“가격은 매우 저렴하지만, 그만큼 공유 계정이라는 구조적인 단점이 있다. 따라서 어떤 사람에게는 추천하고, 어떤 사람에게는 추천하지 않는다.”**

이 균형을 유지한다.

카카오 + 쫀득쿠키.

싶었죠.

Business 쪽 프로모션을 활용해서 여러 좌석을 상대적으로 저렴하게 쓰는 방식인데요.

조건도 있고, 인증이나 최소 사용량 같은 부분도 있어서 모든 사람에게 맞는 방법은 아닙니다.

그런데 제가 직접 몇 달 써보면서 찾은 방법 중에 더 저렴한 게 하나 있어요.

오늘 소개할 **겜쫀쿠**입니다.

겜스고 같은 계정 공유 플랫폼을 활용하는 방법이에요.

쉽게 말하면 넷플릭스 공유처럼 하나의 서비스 계정을 여러 사람이 나눠 쓰는 구조입니다.

가격만 보면 상당히 저렴해요.

제 경우에는 대부분의 사용자가 ChatGPT에서 일반적인 질문을 하는 정도고, Codex나 Work를 적극적으로 사용하는 사람은 상대적으로 적어 보였어요.

**이건 공유 계정이에요.**

이 부분은 뒤에서 조금 더 자세히 말씀드릴게요.

오늘 영상에서는

직접 보여드릴게요.

## 1:50~5:20 메인 — 겜스고에서 사고 설정하기

겜스고 닷컴에 들어가서 로그인을 합니다.

여기 보면 상품 유형이 몇 가지 있는데요.

오늘은 **공유형**을 기준으로 볼게요.

혼자 쓰는 형태의 상품도 있는데 당연히 가격은 조금 더 올라갑니다.

저희는 오늘 최대한 저렴하게 여러 개를 확보하는 방식으로 볼게요.

제가 이걸 약 3개월 정도 사용해 봤는데요.

**제 환경에서는** 다른 사람이 많이 써서 제가 작업을 못 하는 상황은 거의 없었습니다.

다만 다시 말씀드리지만, 이건 공유형 서비스라서 다른 사용자의 사용량에 영향을 전혀 받지 않는다는 뜻은 아니에요.

저는 Codex를 사용하는 사람이 생각보다 적어서 괜찮았던 것 같고요.

이 부분은 직접 한 달 정도 써보면서 판단하시는 게 가장 좋습니다.

그럼 실제로 구매해볼게요.

오늘은 **개수로 가는 공유형** 기준입니다.

구매 자체는 어렵지 않습니다.

### 1. 가입

겜스고에 들어가서 이메일로 가입합니다.

### 2. 상품 찾기

검색창에 ChatGPT를 검색하면 상품이 나옵니다.

공유형과 개인형 또는 충전형처럼 상품 유형이 나뉘어 있으니, 오늘은 공유형을 선택할게요.

### 3. 기간 고르기

기간은 여러 개가 있을 텐데요.

**처음 사용하시는 분은 저는 1개월을 추천합니다.**

왜냐하면 이 서비스가 내 사용 방식에 맞는지 먼저 확인해야 하기 때문이에요.

특히 공유형 계정이라는 구조 자체가 불편한 분들도 있을 수 있거든요.

가격이 싸다고 여러 개월을 한 번에 결제하기보다는,

**한 달 직접 써보고 괜찮으면 그때 늘리는 게 좋습니다.**

### 4. 프로모션 코드

그리고 이거 놓치시는 분들이 많아요.

결제창에 프로모션 코드를 넣는 칸이 있습니다.

촬영하는 시점에 실제로 적용 가능한 코드가 있다면 제가 직접 넣어볼게요.

코드에 따라 할인율이 달라질 수 있으니까,

이 영상에서 나오는 최종 가격이 항상 유지된다고 보시면 안 됩니다.

그래서 저는 화면에 **촬영 날짜와 실제 결제 가격**도 같이 표시해둘게요.

할인이 적용되면 월 비용을 조금 더 낮출 수 있습니다.

### 5. 결제

이제 실제로 결제를 진행하면 됩니다.

여기서는 결제 정보나 주문번호 같은 민감한 정보는 블러 처리할게요.

### 6. 계정 받기

결제가 끝나면 공유형 계정 정보를 받게 됩니다.

여기서 실제로 받은 계정으로 로그인해볼게요.

**계정 정보는 절대 영상에 노출하지 않겠습니다.**

이제 받은 이메일과 비밀번호로 ChatGPT에 로그인해볼게요.

로그인이 되고요.

실제로 Plus 권한이 활성화되어 있는지 확인합니다.

그리고 바로 ChatGPT를 사용할 수 있습니다.

Codex를 쓰시는 분들은 실제로 Codex CLI 로그인까지 해볼게요.

기기 인증이 필요한 경우 인증 과정을 진행하면 되고요.

로그인이 정상적으로 완료되면 바로 작업을 시작할 수 있습니다.

결국 과정은 이거예요.

**사고 → 계정 받고 → 로그인하고 → 바로 쓰기.**

처음 한 번만 설정하면 됩니다.

그리고 꼭 겜스고에서만 계정을 구해야 하는 건 아닙니다.

통신사나 다른 서비스 제휴로 구독을 받고 계신 분도 있을 수 있고,

회사에서 제공하는 계정을 쓰는 분도 있을 거고요.

오늘은 제가 직접 사용해봤고, 비교적 쉽게 접근할 수 있는 하나의 경로를 보여드리는 겁니다.

## 5:20~6:20 팁 — 계정이 여러 개일 때

여기까지가 사실 오늘 영상의 메인입니다.

그런데 계정이 두세 개 이상 생기면 새로운 문제가 생겨요.

**계정을 바꾸는 게 귀찮습니다.**

Codex는 기본적으로 한 번에 하나의 로그인 상태를 사용하게 되니까,

계정을 바꿀 때마다 로그아웃하고,

다른 계정으로 로그인하고,

브라우저 인증하고,

이 과정을 반복해야 해요.

처음에는 별거 아닌데 계정이 여러 개가 되면 이게 생각보다 귀찮습니다.

그래서 저는 계정마다 로그인 정보를 따로 보관해두고,

필요할 때 빠르게 전환할 수 있도록 하는 스킬을 사용하고 있어요.

설치는 간단합니다.

```bash
cp -R codex-auth ~/.claude/skills/

printf 'cli_auth_credentials_store = "file"\n' >> ~/.codex/config.toml
```

자주 쓰는 명령어는 세 개 정도예요.

* `$S add 슬롯이름` → 계정 추가
* `$S quota` → 계정별 남은 사용량 확인
* `$S next` → 다음 계정으로 빠르게 전환

예를 들어 Codex 쿼터를 다 썼어요.

그러면 `$S next` 한 번 실행하고 다른 계정으로 전환해서 계속 작업하면 됩니다.

계정이 하나면 필요 없는 방법이고요.

여러 계정을 운영하시는 분들에게만 유용한 팁입니다.

스킬 링크는 설명란에 남겨둘게요.

| 비쫀쿠 | Business 다계정 활용 | 프로모션·조건 확인 필요      |
| 겜쫀쿠 | 공유형 Plus 여러 계정  | 가격은 저렴하지만 공유 구조    |

겜쫀쿠의 장점은 단순합니다.

**가격 대비 계정 수와 사용량을 늘릴 수 있다는 것.**

예를 들어 월 비용을 기준으로 보면

Plus 계정을 정가로 여러 개 구독하는 것보다 훨씬 낮은 비용으로 여러 계정을 확보할 수 있습니다.

다만 하나 정확하게 말씀드릴게요.

**Plus 네 개가 Pro 하나와 똑같다는 얘기는 아닙니다.**

Pro에만 제공되거나 더 높은 한도를 제공하는 기능과 모델이 있을 수 있어요.

카쫀쿠는 그 Pro를 엄청나게 저렴하게 제공했던 이벤트였으니까,

그건 그거대로 정말 강한 딜이었던 거고요.

그런데 내가 Pro의 최고급 기능이 꼭 필요한 게 아니라,

**그냥 사용량이 부족해서 쿼터가 계속 끊기는 문제 때문에 Pro를 보고 있었던 거라면**

여러 개의 계정을 확보하는 방식도 하나의 선택지가 될 수 있습니다.

특히 Codex처럼 작업량과 사용 한도가 중요한 도구에서는요.

## 7:00~8:00 이건 알고 쓰세요

그런데 이건 꼭 말씀드리고 싶습니다.

이 방법이 무조건 좋은 건 아닙니다.

세 가지만 알고 사용하세요.

### 하나. 작업 중에는 계정을 바꾸지 마세요.

Codex가 작업하고 있을 때 로그인 정보를 바꾸면 현재 실행 중인 작업이나 인증 상태에 영향을 줄 수 있습니다.

작업이 끝난 다음 계정을 전환하는 게 안전합니다.

### 둘. 공유형 계정에는 민감한 정보를 넣지 않는 걸 추천합니다.

이게 가장 중요합니다.

공유형은 말 그대로 다른 사람과 계정을 같이 사용하는 구조예요.

그래서 **대화 기록이나 작업 기록이 계정에 남는 방식이라면 다른 사람이 볼 가능성을 완전히 배제할 수 없습니다.**

따라서 저는 이런 용도로는 추천하지 않습니다.

* 회사의 비공개 코드
* 고객 개인정보
* API 키, 비밀번호, 토큰
* 내부 사업 자료
* 개인적으로 공개되면 곤란한 대화
* 다른 사람이 보면 안 되는 소스코드

이런 걸 다뤄야 한다면 비용이 조금 더 들더라도

**본인 개인 계정이나 회사에서 정식으로 관리하는 계정을 사용하는 게 맞습니다.**

저는 이걸 어디까지나

**민감한 정보가 없는 개인 작업, 테스트, 일반적인 개발 작업, 사용량을 많이 소모하는 실험적인 작업**

위주로 활용하는 게 낫다고 생각합니다.

가격이 싼 데는 이유가 있습니다.

**개인정보 보호와 계정 소유권 측면에서 정식 개인 구독과 동일한 경험을 기대하면 안 됩니다.**

### 셋. 처음에는 1개월만 써보세요.

그래서 아까 처음에는 1개월을 추천한다고 말씀드린 거예요.

내 사용 패턴에서 정말 괜찮은지 먼저 확인해야 합니다.

서비스 정책이나 계정 제공 방식도 변경될 수 있고,

환불 조건도 일반적인 구독 서비스와 다를 수 있습니다.

그래서 장기간 한 번에 결제하기보다는

**일단 한 달 직접 써보고 판단하는 걸 추천합니다.**

그리고 마지막으로,

이런 공유 계정 서비스의 이용 방식이 OpenAI의 서비스 약관이나 정책과 충돌할 가능성도 직접 확인하시는 게 좋습니다.

계정이 여러 사람에게 공유되는 구조 자체에 대한 리스크가 있을 수 있기 때문입니다.

저는 이 영상을 **“이 방법이 공식적으로 권장되는 방법이다”라고 소개하는 게 아니라, 실제로 이런 저렴한 사용 방식이 있고 제가 직접 사용해본 경험을 공유하는 것**으로 봐주시면 좋겠습니다.

## 8:00~8:40 마무리

정리할게요.

카쫀쿠는 29,000원에 Pro 한 개.

비쫀쿠는 조건에 따라 여러 좌석을 활용하는 방법.

그리고 오늘 소개한 겜쫀쿠는
