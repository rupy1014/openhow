**앞으로 계속 켜두게 될 작업실이에요.**

메모장이랑 터미널이랑 파일 목록을 따로 띄우면 창을 계속 왔다 갔다 해야 하잖아요.
그걸 한 화면에 모아둔 게 VS Code 예요.

## IDE 라는 말이 나오면

**IDE = 통합 개발 환경**. 그냥 "작업실" 이라고 읽으면 돼요.

```text
메모장 + 터미널 + 파일 관리 = IDE
```

VS Code 는 그중에 제일 많이 쓰는 거고, 무료예요.

## 어떻게 깔아요

[code.visualstudio.com](https://code.visualstudio.com) 들어가서 큰 파란 버튼 누르면 돼요.
윈도우인지 맥인지 알아서 골라줘요.

설치할 때 나오는 체크박스는 **기본값 그대로** 두고 넘어가면 돼요.

## 화면이 세 칸이에요

처음 열면 복잡해 보이는데, 크게 세 덩어리예요.

```text
┌──────────────────┬────────────────────────┐
│  파일 목록        │      편집 영역          │
│  (왼쪽)          │      (가운데)          │
│                  │                        │
│  📁 my-project   │   여기서 파일을 보고    │
│    📄 CLAUDE.md  │   고쳐                 │
│    📄 계획.md     │                        │
├──────────────────┴────────────────────────┤
│  터미널 (아래)                             │
│  $ 여기에 명령어를 쳐                       │
└───────────────────────────────────────────┘
```

| 칸 | 뭐하는 곳 |
| --- | --- |
| **왼쪽** | 지금 열어둔 폴더 안에 뭐가 있는지 |
| **가운데** | 파일 내용을 보고 고치는 곳 |
| **아래** | 터미널. 앞 문서에서 본 그 검은 창 |

터미널이 안 보이면 메뉴에서 `터미널` → `새 터미널` 을 눌러요. 아래에 나타나요.

## 제일 중요한 건 "폴더를 여는 것"

VS Code 는 **파일 하나가 아니라 폴더 하나**를 여는 게 기본이에요.

`파일` → `폴더 열기` → 아까 만든 `my-first-project` 선택.

왼쪽에 그 폴더가 뜨면 성공이에요.

**이게 왜 중요하냐면** — 나중에 AI한테 일을 시킬 때, AI는 "지금 열어둔 이 폴더 안" 에서만 일하거든요.
폴더를 안 열고 파일만 열면 AI가 주변을 못 봐요.

## 한글로 바꾸고 싶으면

왼쪽 끝 네모 4개 아이콘(확장) 누르고 `Korean` 검색 → 한국어 팩 설치 → 재시작.

영어가 부담되면 깔아요. 근데 나중에 검색할 때는 영어 메뉴 이름이 더 잘 나와서, 익숙해지면 다시 영어로 돌리는 사람도 많아요.

## 익스텐션이 뭔가요?

VS Code 에 기능을 추가하는 부품이에요. 방금 깐 한국어 팩도 익스텐션이고.

지금은 아무것도 안 깔아도 돼요. 필요해질 때 그때 깔면 돼요.

## 자주 헷갈리는 포인트

### 꼭 VS Code 여야 하나요?

아니에요. Cursor, WindSurf 같은 것도 있어요. 근데 자료랑 검색 결과가 제일 많은 게 VS Code 라, 처음엔 이게 편해요.

### 왼쪽에 파일이 잔뜩 생겼어요

정상이에요. AI가 작업하면서 만든 파일들이에요. 하나씩 안 봐도 돼요.

### 저장은 어떻게 하나요?

`Ctrl + S` (맥은 `⌘ + S`). 파일 이름 옆에 점(●)이 떠 있으면 아직 저장 안 된 거예요.

### 실수로 지웠어요

`Ctrl + Z` (맥은 `⌘ + Z`) 로 되돌려져요. 파일 자체를 지웠으면 휴지통에 있어요.

## 한 줄 정리

> VS Code 는 작업실이고, **파일이 아니라 폴더를 여는 것**이 첫 습관이에요.
