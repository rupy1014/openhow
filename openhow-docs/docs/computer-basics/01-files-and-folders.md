**파일은 물건이고, 폴더는 그 물건을 넣어두는 상자예요.**

너무 당연한 얘기 같죠? 근데 앞으로 나오는 거의 모든 설명이 이 위에 서 있어요.
여기가 흔들리면 뒤가 다 흔들려요.

## 파일이 뭔가요?

내용이 담긴 것 하나하나예요.

```text
이력서.hwp        ← 문서 파일
고양이.jpg        ← 사진 파일
발표자료.pptx     ← 프레젠테이션 파일
```

## 점 뒤에 붙은 건 뭔가요?

`.hwp`, `.jpg`, `.pptx` 처럼 이름 뒤에 붙은 걸 **확장자**라고 해요.

**이 파일이 어떤 종류인지 알려주는 꼬리표**예요. 컴퓨터는 이걸 보고 뭘로 열지 정해요.

| 확장자 | 뭐야 |
| --- | --- |
| `.txt` | 그냥 글자만 있는 파일 |
| `.md` | 글자 + 간단한 서식 (앞으로 제일 많이 봄) |
| `.json` | 설정값을 적어두는 파일 |
| `.html` `.css` `.js` | 웹페이지를 만드는 파일들 |

> 윈도우는 확장자를 기본으로 숨겨요. 파일 탐색기 → `보기` → `파일 확장명` 체크하면 보여요.
> 맥은 Finder → `설정` → `고급` → `모든 파일 확장자 보기`.
>
> **꼭 켜둬.** 안 보이면 나중에 헷갈려요.

## 폴더가 뭔가요?

파일을 넣어두는 상자예요. 상자 안에 상자를 또 넣을 수도 있어요.

```text
📁 내프로젝트/          ← 큰 상자
   📁 자료/             ← 그 안의 작은 상자
      📄 조사내용.md
   📄 계획.md
```

앞으로 **프로젝트**라는 말이 계속 나오는데, 그냥 이 "큰 상자 하나"예요.
AI한테 일 시킬 때 "이 상자 안에서만 일해"라고 정해주는 단위죠.

## 경로가 뭔가요?

**그 파일이 어느 상자 안에 있는지 적은 주소**예요.

```text
내프로젝트/자료/조사내용.md
```

이렇게 읽어요. "내프로젝트 상자 안 → 자료 상자 안 → 조사내용.md 파일."

슬래시(`/`)가 "그 안으로 들어가"라는 뜻이에요. 주소에서 시·구·동 나누는 것처럼.

> 윈도우는 역슬래시(`\`)를 쓰기도 해요. 같은 뜻이에요. 놀라지 마세요.

## 자주 보게 될 기호 두 개

| 기호 | 뜻 |
| --- | --- |
| `.` | 지금 있는 폴더 |
| `..` | 한 칸 위 폴더 |

`../자료/조사내용.md` 는 "한 칸 위로 나갔다가, 자료 상자로 들어가서, 그 파일" 이에요.

## 이걸 왜 알아야 해요

AI한테 일을 시키려면 **어디서 일할지**를 정해줘야 하거든요.

```text
❌ "블로그 글 써줘"
✅ "내프로젝트/자료/조사내용.md 읽고 블로그 글 써줘"
```

아래쪽이 훨씬 좋은 결과가 나와요. AI가 뭘 보고 써야 할지 아니까요.

## 직접 해볼 것

바탕화면에 폴더 하나 만들고 이름을 `my-first-project` 라고 지어봐요.

- **한글보다 영어**로 짓는 걸 추천해요. 나중에 도구들이 한글 폴더명에서 가끔 말썽을 부려요.
- **띄어쓰기 대신 하이픈(`-`)** 을 써요. `my project` 보다 `my-project` 가 안전해요.

이 폴더가 다음 문서들에서 계속 쓰일 작업실이 될 거예요.

## 자주 헷갈리는 포인트

### 폴더랑 디렉토리는 다른 건가요?

같은 거예요. 마우스로 보면 폴더, 명령어로 다루면 디렉토리라고 부르는 것뿐이에요.

### 파일 이름에 한글 쓰면 안 되나요?

안 되는 건 아니에요. 근데 인터넷에 올리는 파일이라면 영어가 안전해요. 한글이 깨져서 주소가 이상해지는 경우가 있거든요.

### 확장자를 바꾸면 파일 종류가 바뀌나요?

아니요. 꼬리표만 바뀌고 내용은 그대로예요. `.jpg` 를 `.md` 로 바꾼다고 글이 되진 않아요.

## 한 줄 정리

> 파일은 물건, 폴더는 상자, 경로는 주소. 이 셋이면 앞으로 나올 설명 대부분이 읽혀요.
