**글자 파일인데, 기호 몇 개로 제목이랑 목록을 표시할 수 있는 형식이에요.**

앞으로 나오는 파일 중에 `.md` 가 제일 많이 나와요. `CLAUDE.md`, `README.md`, `prd.md` 전부 이거예요.

## 왜 워드나 한글이 아니에요

`.docx` 나 `.hwp` 는 글자 말고도 서식 정보가 잔뜩 들어 있어요. 사람 눈엔 예쁜데 프로그램이 읽기엔 지저분해요.

`.md` 는 그냥 글자예요. 그래서

- 아무 프로그램에서나 열려
- AI가 통째로 읽기 좋아요
- 변경 내역을 남기기 좋아요

그래서 개발이든 기획이든 AI랑 같이 일할 땐 다 이걸 써요.

## 기호 다섯 개면 돼요

```markdown
# 제일 큰 제목
## 중간 제목
### 작은 제목

- 목록 첫 번째
- 목록 두 번째

**굵게** 쓰고 싶으면 별표 두 개

1. 번호 목록
2. 이렇게

| 이름 | 값 |
| --- | --- |
| 표도 | 이렇게 |
```

`#` 이 제목, `-` 가 목록, `**` 가 굵게요. 진짜 이게 다예요.

- `#` 개수가 제목 크기예요. 많을수록 작아져요.
- `#` 뒤에는 **꼭 한 칸 띄어야** 해요. `#제목` 은 안 먹어요.

## 어떻게 만들어요

VS Code 왼쪽 파일 목록에서 **새 파일** 아이콘 누르고 이름을 `테스트.md` 로 지어봐요.

그리고 아무거나 써봐요.

```markdown
# 내 첫 마크다운

- 오늘 배운 것
- 내일 할 것
```

`Ctrl + Shift + V` (맥은 `⌘ + Shift + V`) 누르면 미리보기가 떠요. 제목이 커지고 목록에 점이 찍혀 있으면 성공.

## 외워야 하나요?

아니요. 필요할 때 AI한테 시키면 돼요.

```text
아래 내용을 마크다운으로 정리해줘.

(내용 붙여넣기)
```

**`.md` 파일을 보고 "아 이건 글자 파일이구나" 하고 안 놀라는 것**만 하면 돼요.

## 이게 왜 중요하냐면

AI한테 일 시킬 때 **구조를 갖춰서 주면 결과가 확 달라져요.**

```text
나쁜 예:
"사용자 정보 받아서 저장해줘. 이름이랑 이메일이랑 전화번호"

좋은 예:
"사용자 정보 저장 기능 만들어줘.

## 받을 정보
- 이름 (글자)
- 이메일 (이메일 형식)
- 전화번호 (010-XXXX-XXXX 형식)"
```

아래쪽이 훨씬 정확하게 나와요. 사람도 그렇잖아요. 말로 주르륵 하는 것보다 목록으로 주는 게 알아듣기 쉽죠.

## 가끔 같이 나오는 형식

깊게 안 봐도 되는데, 이런 것도 있다는 것만 알아둬요.

| 형식 | 언제 봐 | 생김새 |
| --- | --- | --- |
| `.json` | 설정 파일 | `{ "이름": "값" }` |
| `.txt` | 진짜 글자만 | 아무 기호도 없음 |

`.json` 은 중괄호 `{}` 랑 따옴표가 잔뜩 있어요. 설정값이 적힌 파일이구나 정도로 보면 돼요.
직접 고칠 일이 생기면 그때 AI한테 시키면 되고.

## 자주 헷갈리는 포인트

### 미리보기 말고 원래 화면으로 돌아가려면?

탭을 닫으면 돼요. 원본 파일은 그대로 있어요.

### 마크다운을 꼭 배워야 하나요?

아니요. `#` 이 제목이라는 것만 알면 나머진 필요할 때 찾아도 돼요.

### 표를 손으로 그리기 귀찮아요

AI한테 "이거 마크다운 표로 만들어줘" 하면 돼요. 손으로 그리는 사람 거의 없어요.

## 한 줄 정리

> `.md` 는 그냥 글자 파일이에요. `#` 이 제목이라는 것만 알면 오늘은 충분해요.
