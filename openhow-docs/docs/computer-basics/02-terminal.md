**컴퓨터한테 마우스 대신 글자로 시키는 창이에요.**

영화에서 해커가 두드리던 그 검은 화면 맞아요. 근데 실제로는 훨씬 시시해요.

## 마우스로 하면 되잖아요

둘 다 되는데 방식이 달라요.

| 약어 | 뜻 | 방식 |
| --- | --- | --- |
| **GUI** | Graphic User Interface | 마우스로 클릭 |
| **CLI** | Command Line Interface | 글자로 명령 입력 |

GUI는 메뉴판 보고 주문하는 거예요.
CLI는 주방에 직접 말로 주문하는 거고.

메뉴판에 없는 걸 시키려면 주방에 말해야 하잖아요. 그게 CLI를 쓰는 이유예요.

## 어떻게 열어요

- **윈도우**: 시작 → `PowerShell` 검색 → Enter
- **맥**: `⌘ + Space` → `터미널` 검색 → Enter

열면 이런 게 떠요.

```text
taesup@MacBook ~ %
```

이건 "명령 기다리는 중" 이라는 뜻이에요. `%` 나 `>` 뒤에 글자를 치면 돼요.

## 망가뜨리면 어떡해요

**웬만해선 안 망가져요.**

무서운 건 딱 하나예요. **뭘 하는지 모르는 명령어를 그냥 붙여넣는 것.**
특히 인터넷 아무 데서나 주운 명령어요. 그건 하지 마세요.

이 자료실에 나오는 명령어는 다 안전해요. 그대로 복사해서 붙여넣어도 돼요.

> 붙여넣기가 안 되면? 맥은 `⌘ + V`, 윈도우 PowerShell 은 마우스 **오른쪽 클릭** 이면 붙여져요.

## 자주 쓰는 명령어 네 개

외울 필요 없어요. 이런 게 있다는 것만 알면 돼요.

```bash
pwd          # 지금 내가 어느 폴더에 있는지 보기
ls           # 이 폴더에 뭐가 있는지 보기 (윈도우는 dir)
cd 폴더이름   # 그 폴더로 들어가기
cd ..        # 한 칸 위로 나가기
```

`cd` 는 change directory 의 줄임말이에요. "그 상자로 들어가" 라는 뜻.

## 한 번 해봐요

터미널 열고 순서대로 쳐봐요. 한 줄 치고 Enter, 또 한 줄 치고 Enter.

```bash
pwd
ls
cd Desktop
ls
```

`Desktop` 은 바탕화면이에요. 앞 문서에서 만든 `my-first-project` 폴더가 목록에 보이면 성공.

아무것도 안 망가졌죠? 그거면 돼요.

## 빨간 글씨가 떴어요

정상이에요. **에러는 고장이 아니라 컴퓨터가 말을 거는 거예요.**

```text
cd: no such file or directory: Desktp
```

이건 "Desktp 라는 폴더가 없는데요?" 라는 뜻이에요. `Desktop` 오타죠.

에러가 나면 그 문장을 **그대로 복사해서 AI한테 붙여넣어.** 그게 제일 빨라요.

```text
터미널에서 아래 에러가 났어. 나는 초보야. 무슨 뜻이고 어떻게 고쳐?

(에러 붙여넣기)
```

## 명령어를 외워야 하나요?

아니요. 나도 안 외워요.

앞으로는 명령어를 직접 칠 일이 거의 없어요. AI가 대신 쳐줄 거거든요.
**터미널이 뭔지, 에러가 났을 때 겁먹지 않는 것**만 하면 돼요.

## 자주 헷갈리는 포인트

### 터미널이랑 PowerShell 이랑 다른가요?

같은 거예요. 맥에서는 터미널, 윈도우에서는 PowerShell 이라고 부를 뿐이에요.

### 화면이 글자로 꽉 찼어요

`clear` 라고 치면 지워져요. 내용이 사라지는 게 아니라 화면만 깨끗해지는 거예요.

### 뭔가 실행되다가 안 끝나

`Ctrl + C` 를 누르면 멈춰요. 맥도 `⌘` 아니고 `Ctrl` 이에요.

## 한 줄 정리

> 터미널은 컴퓨터한테 글로 시키는 창이에요. 에러는 고장이 아니라 안내문이고.
