**AI로 뭔가 만들어보고 싶은 사람이, 용어에 막혀서 포기하지 않게 하려고 만든 자료실이에요.**

## 왜 만들었냐

AI 관련 글은 많아요. 근데 대부분 이미 아는 사람끼리 하는 말이에요.

```text
"CLI에서 레포 클론하고 npm install 하면 로컬에서 뜹니다"
```

이 한 줄에 모르는 말이 다섯 개예요.
그럼 거기서 그냥 창을 닫게 돼요.

이 자료실은 그 다섯 개를 먼저 설명하는 쪽을 골랐어요.

## 누구를 위한 거예요

- 컴퓨터로 하는 일이 **문서 작성이랑 검색 정도**인 사람
- "코딩" 하면 검은 화면에 초록 글씨가 떠오르는 사람
- 유튜브에서 AI로 뭘 만들었다는 거 보고 **해보고 싶어진** 사람
- 회사에서 반복하는 일을 **좀 줄이고 싶은** 사람

전공이나 경력은 안 물어봐요. 진짜 아무것도 몰라도 돼요.

## 뭘 하게 되냐

순서대로 따라오면 이 정도까지 가요.

```text
컴퓨터 기본 용어를 알아듣는다
→ AI한테 일을 제대로 시킨다
→ 반복 업무를 명령어 하나로 줄인다
→ 내 아이디어를 화면으로 만든다
→ 인터넷에 올려서 남한테 보여준다
```

마지막 줄까지 안 가도 괜찮아요. 중간에서 멈춰도 남는 게 있어요.

## 솔직하게, 안 되는 것도 있어요

이런 기대라면 여기랑 안 맞아요.

- **"아무것도 안 해도 AI가 알아서 돈 벌어준다"** — 그런 건 없어요. AI는 속도를 올려주지 방향을 정해주진 않아요.
- **"자격증이나 수료증을 따고 싶다"** — 여기서는 안 줘요.
- **"당장 취업용 포트폴리오가 필요하다"** — 결과물은 남지만 그걸 목표로 만든 자료는 아니에요.

## 돈 드는 거 있나요?

자료는 전부 무료예요. 로그인도 필요 없어요.

다만 실제로 따라 하려면 **Claude 유료 플랜(월 $20부터)** 이 필요해요.
얼마나 드는지, 어떻게 아끼는지는 [얼마 들어?](../claude-code/cost) 에서 따로 다뤄요.

읽기만 할 거면 아무것도 안 내도 돼요.
