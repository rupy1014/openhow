## 지금 어디쯤인가요?

| 지금 상태 | 여기부터 봐 |
| --- | --- |
| 터미널? 폴더? 그게 뭔지도 모르겠어 | [💻 컴퓨터 기초](../computer-basics/files-and-folders) |
| 컴퓨터는 좀 쓰는데 AI는 ChatGPT만 써봤어 | [🧠 AI 기초](../ai-basics/what-is-ai) |

## 진짜 아무것도 모르면 이 순서로

고민되면 그냥 위에서부터 순서대로 봐요. 이렇게 이어져 있어요.

```text
컴퓨터 기초   → 폴더가 뭐고 터미널이 뭔지 알게 됨
AI 기초       → AI가 왜 가끔 이상해지는지 알게 됨
Claude Code   → 설치하고 첫 실행까지 함
일 잘 시키기   → 결과가 눈에 띄게 좋아짐
자동화        → 반복 업무가 명령어 하나로 줄어듦
서비스 만들기  → 내 아이디어가 화면이 됨
팔아보기      → 남이 쓰기 시작함
```

한 단계에 하루씩 잡아도 일주일이에요. 급할 거 없어요.

## 읽다가 막히면

**1. 모르는 단어면 → [용어 사전](../glossary)**

109개 정리해뒀어요. `Ctrl + F` (맥은 `⌘ + F`) 로 찾으면 바로 나와요.

**2. 설명이 이해가 안 되면 → AI한테 물어봐요**

이 자료를 그대로 복사해서 넣고 이렇게 말해요.

```text
아래 내용이 이해가 안 돼. 나는 IT를 전혀 몰라.
초등학생한테 설명하듯이 비유를 들어서 다시 설명해줘.

(여기에 붙여넣기)
```

**3. 순서가 꼬인 것 같으면 → 한 단계 앞으로**

용어가 갑자기 어려워졌으면 대체로 앞 단계를 건너뛴 거예요. 되돌아가면 풀려요.

## 이것만 지켜줘

**눈으로만 읽지 마세요.**

한 문서 읽으면 하나는 직접 쳐봐요. 안 되면 안 되는 대로 괜찮아요.
에러 나는 걸 한 번 겪어봐야 그다음부터 안 무서워져요.
