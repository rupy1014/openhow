# 톤앤매너 가이드 — AI 입문 자료실

이 문서가 **정본**이다. 본문·제목·frontmatter를 쓸 때 여기 적힌 것만 따른다.
`scan.exclude` 에 걸려 있어서 사이트에는 노출되지 않는다.

레퍼런스: `developers.bootpay.ai` — 같은 플랫폼(openhow)에서 같은 해요체를 쓴다.

## 0. 한 줄 요약

> **존댓말로 쓰되, 초등학생도 알아듣게 쉽게.**
> 토스처럼 — 정중하지만 딱딱하지 않고, 짧고, 전문용어를 그냥 던지지 않는다.

## 1. 말투: 해요체

**`~해요` / `~돼요` / `~예요`** 로 쓴다. 이게 전부다.

| 금지 | 이유 | 대체 |
| --- | --- | --- |
| `~합니다`, `~습니다`, `~됩니다`, `~입니다` | 너무 딱딱하다. 공지문 같다 | `~해요`, `~돼요`, `~예요` |
| `~해`, `~야`, `~거야`, `~돼` | 반말이다 | `~해요`, `~예요`, `~거예요`, `~돼요` |
| `~한다`, `~된다`, `~이다` | 서술체. 보고서 같다 | `~해요`, `~돼요`, `~예요` |
| `~함`, `~됨`, `~임` | 개조식. 메모 같다 | `~해요`, `~돼요`, `~예요` |

```
X  설치가 완료되었습니다.
X  설치 완료됨.
X  설치가 끝났어.
O  설치가 끝났어요.
```

### 받침에 따라 갈리는 것

| 앞 글자 | 형태 | 예 |
| --- | --- | --- |
| 받침 있음 | `~이에요` | 방식**이에요**, 뜻**이에요**, 곳**이에요** |
| 받침 없음 | `~예요` | 도구**예요**, 거**예요**, 하나**예요** |

`아니야` 는 예외다. → **`아니에요`**

### 그 밖의 종결

| 평어 | 해요체 |
| --- | --- |
| `~거든` | `~거든요` |
| `~지` | `~죠` |
| `~네` / `~군` | `~네요` / `~군요` |
| `~잖아` | `~잖아요` |
| `~하지 마` | `~하지 마세요` |
| `~해보자` (청유) | `~해봐요` |
| `아니` (대답) | `아니요` |

## 2. 질문형 제목

제목은 **질문형 구어체**로 쓴다. `개요`, `방법`, `소개` 같은 레이블 제목은 금지.

질문 종결은 아래 셋 중 하나로만 쓴다.

| 뒤에 오는 말 | 형태 | 예 |
| --- | --- | --- |
| 동사 | `~나요?` | 어떻게 설치**하나요?** / 꼭 있어야 **하나요?** |
| 형용사 | `~ㄴ가요? / ~은가요?` | 뭐가 **다른가요?** / 왜 **위험한가요?** |
| 명사 + 이다 | `~인가요?` | 이게 **뭔가요?** / 그럼 **실패인가요?** |

```
X  ## 개요
X  ## 터미널이 뭐야?
X  ## 터미널이 뭐예요?      ← 틀리진 않지만 제목엔 안 쓴다
O  ## 터미널이 뭔가요?

X  ### 꼭 VS Code 여야 해?
O  ### 꼭 VS Code 여야 하나요?
```

**조건절로 끝나는 제목은 그대로 둔다.** 이미 자연스럽다.

```
O  ## 한도에 걸리면?
O  ### 배포가 실패하면?
O  ## 동시에 여러 개 하려면?
```

## 3. 쉬운 말

**전문용어를 그냥 던지지 않는다.** 처음 나오면 바로 옆에 풀어준다.

```
X  런타임에서 실행돼요.
O  엔진 같은 게 돌려줘요. 이걸 런타임이라고 불러요.
```

| 이렇게 쓰지 마 | 이렇게 |
| --- | --- |
| 런타임 | 프로그램을 돌려주는 프로그램 |
| CLI | 터미널에서 글자로 명령하는 방식 |
| 프론트엔드 | 눈에 보이는 화면 |
| 트리거 | 자동으로 실행되는 조건 |
| 프롬프트 | AI한테 하는 말 |

**비유를 쓴다.** 처음 나오는 개념은 일상 비유로 한 번 풀어준다.

```
X  서브 에이전트에는 독립된 컨텍스트가 할당돼요.
O  담당자마다 새 메모장을 받아요. 다른 사람 메모는 안 보여요.
```

**영어 약어는 처음에 한글을 붙인다.**

```
O  코딩 실력 테스트(SWE-bench)에서 상위권이에요.
```

모르는 말이 나올 것 같으면 [용어 사전](/glossary) 으로 링크한다.

## 4. 인칭

| 금지 | 대체 |
| --- | --- |
| 여러분 | (생략) 또는 주어 없이 |
| 당신, 귀하 | (생략) |
| 너, 네 | (생략) 또는 "내" |
| 고객님, 사용자님 | (생략) |

주어는 웬만하면 **생략**한다. 한국어는 생략이 자연스럽다.

```
X  여러분이 원하는 결과를 얻으려면
X  네가 원하는 결과를 얻으려면
O  원하는 결과를 얻으려면
```

"나"는 써도 된다. 글쓴이 자신을 가리킬 때만.

## 5. 문장

- **짧게.** 한 문장에 한 가지만.
- 1~3문장 쓰고 빈 줄.
- 서론 없이 결론부터.

```
X  이번 시간에는 터미널에 대해서 알아보도록 하겠습니다.
O  터미널은 컴퓨터한테 글자로 시키는 창이에요.
```

## 6. frontmatter

| 필드 | 형태 | 예 |
| --- | --- | --- |
| `title` | 질문형 또는 명사형. 짧게 | `터미널이 뭔가요?` |
| `nav` | 사이드바용. title보다 짧게 | `터미널` |
| `hook` | **해요체 한 문장** | `검은 창에 글자 치는 그거예요.` |
| `description` | **메타 설명. `~다` 로 끝내는 명사형 서술** | `터미널이 뭔지 정리한 문서다.` |

`description` 만 `~다` 인 이유: 사람한테 말 거는 문장이 아니라 검색엔진·카드용 메타 텍스트라서다. 레퍼런스(`developers.bootpay.ai`)도 같다.

## 7. 손대지 않는 것

아래는 해요체로 바꾸지 않는다.

- **코드 블록 안** (` ``` `) — 명령어, 설정 파일, 프롬프트 예시
- **인라인 코드** (`` ` ``)
- **인용한 나쁜 예시** — "이렇게 쓰면 안 돼요" 하고 보여주는 원문
- **AI에게 줄 지시문 예시** — 프롬프트는 반말이 자연스럽다

```
O  AI한테는 이렇게 말해요.

    ```text
    이 파일 읽고 요약해줘.
    ```
```

- **문서 템플릿 인용** — `CLAUDE.md`, `/write` 같은 파일 내용은 서술체 그대로

## 8. 자가 점검

글을 쓰고 나서 이것만 확인한다.

1. `~습니다` / `~합니다` 가 있나? → 있으면 고친다
2. `~해` / `~야` / `~거야` 로 끝나는 문장이 있나? → 있으면 고친다
3. 제목이 `~해?` / `~뭐야?` 로 끝나나? → `~하나요?` / `~뭔가요?` 로
4. "여러분" 이 있나? → 지운다
5. 처음 나온 전문용어를 안 풀어줬나? → 풀어준다
