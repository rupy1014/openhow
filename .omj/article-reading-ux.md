# article-reading-ux — 아티클 읽기 경험 고도화

## Why

공개 블로그 홈으로 유입된 독자가 아티클을 읽을 때, 읽기 경험이 좋아야 체류 시간이 늘고 다른 글로 이어진다. toss.tech는 프로그레스 바, 목차, 관련 글 추천, 시리즈 네비게이션, 피드백 위젯으로 읽기 몰입감을 만든다. openhow의 현재 아티클 페이지는 본문만 보여주는 수준이라 이 갭을 메워야 한다.

## Context

- 아티클 뷰어: DocPage.tsx → Plate.js 기반 렌더링
- 레이아웃: BlogLayout(블로그), BookLayout(북/코스) — 읽기 맥락이 다름
- 기존 TOC: MainLayout에 사이드바 TOC 존재하지만 블로그 레이아웃에는 미적용
- 댓글: CommentsSection 컴포넌트 이미 구현 완료
- sequential 워크스페이스: 이전/다음 네비게이션이 자연스러운 구조
- public-blog-home이 완성된 후 착수 — 홈에서 유입된 독자의 읽기 경험이 핵심

## What

- [ ] 스크롤 프로그레스 바 (상단 고정, 읽기 진행률 표시)
- [ ] 아티클 TOC 사이드바 (heading 기반 자동 생성, 현재 위치 하이라이트)
- [ ] 관련 글 추천 (같은 워크스페이스/카테고리 아티클, 글 하단)
- [ ] 시리즈 네비게이션 (이전 글 / 다음 글 + 시리즈 전체 목록, sequential 워크스페이스)
- [ ] 피드백 위젯 (글 하단 "도움이 되었나요?" 반응 수집)
- [ ] 공유 버튼 (URL 복사, SNS 공유)

## Not

- 댓글 시스템 재구현 (기존 CommentsSection 활용)
- BookLayout 변경 (코스/북 레이아웃은 별도)
