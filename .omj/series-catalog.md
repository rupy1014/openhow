# series-catalog — 시리즈 카탈로그 서브페이지 (카테고리별 탐색)

## Why

홈은 진입점이라 큐레이션을 4개 정도로 컷한다. 정제된 큐레이션 서비스로 가려면 "더 많은 시리즈를 카테고리로 탐색하는" 깊이 있는 발견 페이지가 필요하다. 홈에서 "전체보기"를 눌렀을 때 갈 곳이 없으면 큐레이션이 막힌다.

## Context

- **부모 의도**:
  - `public-blog-home.md` — 홈 큐레이션 (시리즈 4개 컷 + 카테고리/도메인 분류축이 빠져있음)
  - `creator-platform.md` — UGC 발행자 + 메인 큐레이션 확장
- **직전 합의 (2026-04-17 대화)**:
  - UI 라벨은 **"시리즈"** 한 단어로 통일 (course/blog/docs 모두 포괄)
  - **카테고리** = 도메인 분류축 (개발/AI/마케팅/디자인 등 — `topicTags` 활용)
  - **"강좌"** 라벨은 course 타입 + 유료 결제 붙은 항목에만 뱃지로 한정
  - 헤더 우측 actions 슬롯이 비어 있어 "시리즈" nav 진입 동선 추가 가능
- **시스템 레이어 분리**:
  - 워크스페이스 `type` (course/blog/docs/wiki/team/project) = 시스템 구조
  - `sort = 'menu'` 또는 `type = course/book` = 시리즈로 분류
  - 카테고리 = UI 표시축 (워크스페이스 메타 또는 article topicTags 집계)
- **데이터 현실**: 현재 공개 워크스페이스 5개 정도, 카테고리 분류 메타 없음. 초기엔 수동 시드/매핑.
- **카테고리 큐레이션 책임 (2026-04-17 결정)**: 작가는 콘텐츠 제작에만 집중 → 에디터(운영자)가 최종 분류. 작가는 워크스페이스 설정에서 카테고리를 추천(suggested)으로 입력, 에디터가 카탈로그 노출 전 확정. `creator-platform`의 "에디터 픽" 큐레이션 정책과 동일한 결.
- **라우팅**: 현재 `/d/{ws}/{slug}`, `/w/{ws}`, `/s/{username}`. `/series` 또는 `/curriculum` 자유.
- **공개 피드 API**: `core/packages/worker/src/routes/public-feed.ts` 가 이미 워크스페이스+아티클 합쳐 내려줌. 카테고리 필드 추가 또는 별도 카탈로그 엔드포인트 분기 필요.

## What

- [hypothesis] **Phase 0: UX 스토리보드** — 헤더 진입점 → 카탈로그 페이지 (카테고리 탭 + 시리즈 그리드) → 시리즈 클릭 → 첫 화 진입 흐름. 모바일 카테고리 칩 vs 데스크톱 사이드 필터 결정. → **metric: 와이어 1장 + 사용자 OK**
- [hypothesis] **카테고리 taxonomy 초기 시드** — 5-7개 (예: 개발 / AI · LLM / 마케팅 · CRO / 디자인 · UX / 기획 · 프로덕트 / 운영 · 비즈니스). 각 카테고리에 최소 1개 워크스페이스 매핑. → **metric: 카테고리 목록 + 매핑 테이블 확정**
- [validated] **카테고리 모델 — 작가 제안 + 에디터 확정 워크플로우** — 워크스페이스 단일 컬럼(`workspace.category` 최종값) + 작가 제안값(`workspace.suggestedCategory`). 작가는 추천만, 에디터(운영자)가 카탈로그 노출 전 확정. → **metric: 작가 입력값과 노출용 값이 분리되어 저장됨**
- [hypothesis] **에디터용 카테고리 분류 도구** — 관리자 페이지에서 워크스페이스 목록 + suggestedCategory 표시 + 일괄 카테고리 변경. 작가 알림 없이 편집 가능. → **metric: 운영자가 한 화면에서 미분류/대기 워크스페이스 처리**
- [hypothesis] **작가용 카테고리 입력 UX** — 워크스페이스 설정에 카테고리 선택(드롭다운, 사전 정의 셋). "에디터가 최종 결정한다" 안내 카피 노출. → **metric: 작가가 추천 카테고리 1개 선택 가능, 미선택도 허용**
- [hypothesis] **`/series` 라우트 + 카탈로그 페이지** — 카테고리 탭/필터 + 시리즈 카드 그리드. 강좌(course+paid)는 카드에 "강좌" 뱃지. 빈 카테고리는 자동 숨김. → **metric: 카테고리 클릭 시 해당 시리즈만 필터링**
- [hypothesis] **헤더 nav 진입점** — actions 슬롯에 "시리즈" 텍스트 링크 추가 (로그인 좌측). 모바일에서도 노출. → **metric: 데스크톱/모바일 헤더에서 클릭 가능**
- [hypothesis] **카탈로그 API 응답 형태** — `/api/public/catalog` 또는 기존 feed 확장. 카테고리별 시리즈 목록 + 강좌 여부 + 아티클 수. → **metric: 카탈로그 페이지가 단일 fetch로 렌더**

## Not
