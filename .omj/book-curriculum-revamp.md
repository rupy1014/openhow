# 책 커리큘럼 개편 — 편집자 피드백 반영

## Why
편집자로부터 4가지 방향 피드백이 왔다.
1. '챗GPT'가 도서 시장에서 지나간 트렌드로 인식 → 목차/제목에 에이전트·코덱스·오픈클로 키워드 전면 배치 필요
2. 목차만 보고 "뭘 배우는지" 직관적으로 드러나지 않음 → 학습 내용 명확화 + 매뉴얼 챕터 보완
3. 오픈클로(로컬 AI 에이전트) 비중을 전체 40% 수준으로 확대 (기존 축소 방침에서 반전)
4. 개념 설명 직후 독자가 바로 따라해볼 수 있는 작은 단위 실습 적극 추가

책 제목도 변경: "바로바로 코덱스 + 오픈클로 에이전트 자동화"
