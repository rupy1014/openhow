# Clauders Community

가입하면 누구나 글을 쓸 수 있습니다. 자기 워크플로우, 삽질 기록, subagent 설정 팁, MCP 서버 실험, 자동화 루프 — 무엇이든 좋습니다.

## 글을 쓰는 법

오른쪽 위 **새 글** 버튼을 누르면 Notion 같은 블록 에디터가 열립니다. heading, 리스트, 코드 블록, 인용, 링크를 자유롭게 섞을 수 있어요.

작성 후 **발행** 을 누르면 즉시 공개됩니다. 글마다 자체 URL 이 만들어지고 검색엔진에 인덱싱됩니다.

## 커뮤니티 규약

- 자기 경험·실험·삽질 위주로 — 단순 링크 dump 는 자제해주세요.
- 출처가 있으면 명시해주세요.
- 광고/홍보성 글은 신고 → 24시간 내 처리됩니다.
