# 문체 가이드

## 확정 톤: 구어적 경어체 (문어체 + 말하듯이)

안티그라비타 레퍼런스와 동일한 경어체(~합니다)를 기본으로 하되,
딱딱한 교과서 문체가 아니라 **강연하듯 술술 읽히는 톤**을 유지한다.

## 골든 샘플: `doc/index.md` (프롤로그)

이 책의 톤 기준은 프롤로그(`doc/index.md`)다. 모든 챕터는 이 파일의 뉘앙스를 따른다.

### 프롤로그에서 뽑은 톤 원칙

1. **저자의 실제 경험으로 시작한다** — 가상 인물이 아니라 저자 본인과 실제 수강생 이야기
2. **에피소드가 먼저, 설명이 나중** — "입술이 부르트더라고요" 같은 장면을 먼저 보여주고, 그 뒤에 의미를 붙인다
3. **독자에게 말을 건다** — "여러분 차례입니다", "한번 재밌게 해봅시다"
4. **짧은 볼드 선언 + 풀어쓰기** — `**첫째, 내 시간을 아끼고 싶다.**` 다음 줄에 부연
5. **간증(?) 같은 유머** — 진지한 내용 사이에 가벼운 말투를 섞어 긴장을 푼다
6. **실용적 연결** — "유튜브 강의는 많지만 물어볼 곳은 없거든요" 같이 독자의 현실 문제를 짚는다

### 구간별 톤 구분

| 구간 | 톤 | 예시 |
|------|-----|------|
| 도입부 (장 첫 1~2p) | 프롤로그와 동일. 에피소드 + 공감 | "수강생 중에 이런 분이 계셨습니다." |
| 개념 설명 | 비유 + 구어적 경어체 | "AI는 유능한 신입사원입니다." |
| 실습 STEP | 간결한 지시체. 군더더기 없이 | "01 터미널을 열고 아래 명령어를 입력하세요." |
| 트러블슈팅 Q&A | Q는 독자 말투, A는 친절한 경어 | "Q. 화면이 안 떠요" / "A. ~해보세요." |
| 한 줄 정리 / 마무리 | 프롤로그 톤으로 돌아옴 | "이제 ~할 수 있게 됐습니다." |

## 목표 톤 예시

### Before (현재 반말체)
> 코딩 몰라도 돼. 근데 판단은 네가 해야 해.
> AI는 유능한 신입이야. 손은 빠르고, 기본기도 있고, 밤새도 불평 안 해.
> 근데 신입은 신입이야.

### After (구어적 경어체)
> 코딩을 몰라도 됩니다. 대신 판단은 여러분이 직접 해야 합니다.
> AI는 유능한 신입사원입니다. 손이 빠르고, 기본기도 있고, 밤새도 불평하지 않습니다.
> 하지만 신입은 신입입니다.

### 핵심 감각
- **강연자가 청중에게 말하는 느낌**: "자, 여기서 중요한 건 이겁니다."
- **짧은 호흡 유지**: 한 문장이 2줄을 넘지 않도록
- **구어적 연결어 적극 사용**: "그런데", "사실은", "솔직히", "예를 들어", "왜냐하면"
- **리듬감 있는 열거**: 짧은 문장을 3개씩 나열하는 패턴 유지

## 변환 규칙

| 현재 (반말) | 변환 (구어적 경어) | 비고 |
|------------|----------------|------|
| ~야 | ~입니다 / ~입니다 | |
| ~거든 | ~기 때문입니다 / ~거든요 | "~거든요"도 OK (구어적) |
| ~지 | ~죠 / ~ㅂ니다 | "~죠"로 자연스럽게 |
| ~해 | ~하세요 / ~합니다 | 지시는 "~하세요", 서술은 "~합니다" |
| ~봐 | ~보세요 / ~보십시오 | "~보세요" 권장 |
| 너/네 | 여러분 / 독자분 | 또는 생략 |
| 나 | 필자 / 저 | "저"도 OK (구어적) |
| 근데 | 그런데 / 하지만 | "그런데"는 구어적이므로 OK |
| 진짜 | 정말 / 실제로 | |
| 걍/그냥 | 그냥 | 유지 가능 (구어적 경어에서도 자연스러움) |

## 허용/금지

### 허용 (구어적 느낌 유지)
- "~거든요", "~잖아요", "~죠" — 경어체지만 구어적 어미
- "자, 그러면", "사실", "솔직히 말하면" — 강연체 연결어
- 짧은 감탄: "됩니다.", "가능합니다.", "충분합니다."
- 질문형 전환: "왜 그럴까요?", "어떻게 해야 할까요?"

### 금지
- 반말 ("~야", "~해", "~거든", "~지")
- 평어체 ("~다", "~이다") — 건조해짐
- 과도한 존칭 ("~하시옵소서", "~이시겠습니다")
- 학술체 ("~한 바 있다", "~로 사료된다")

## 레퍼런스 톤 비교

### 1순위: 프롤로그 (`doc/index.md`) — 이 책의 기준
> "떡집 사장님도 계시고, 목공예 하시는 분도 계시고, 골프 장갑 만드시는 분도 계십니다.
> IT와는 거리가 먼, 현장에 계신 분들이 정말 많습니다."
>
> "사실 유튜브에 바이브코딩 강의는 많습니다. 그런데 '나 이런 거 하려고 하는데
> 어떻게 해요?'라고 물어볼 곳은 없거든요."

→ 경어체 + 구어적 + 리얼 에피소드 + 독자에게 말 거는 톤. **이것이 기준.**

### 2순위: 안티그라비타 (참고)
> "어제까지, 아이디어는 머릿속에만 머물렀습니다. 하지만 오늘, 모든 것이 바뀝니다."

→ 경어체 + 감성적. 구조와 STEP 세분화 참고.

### 참고만: OpenClaw
> "같은 아침이라도 시작 방식은 크게 다르다."

→ 평어체. 우리 톤과 다름. 구조만 참고.
