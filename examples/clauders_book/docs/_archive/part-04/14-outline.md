# 14장 개요 — 쓰레드와 SNS 발행 — "이것도 발행해줘"

## 장의 역할
Ch 13에서 뉴스 보고를 받은 독자가, 이번에는 OpenClaw에게 "이것도 발행해줘"라고 지시해서
콘텐츠를 SNS에 발행하는 흐름을 보여준다.
수동 소비에서 능동 지시로 넘어가는 핵심 챕터.

## 독자가 읽고 남겨야 할 변화
- "보고 받기"에서 "지시하기"로 OpenClaw 활용이 확장된다.
- 초안 → 검토 → 승인 → 발행의 단계를 이해한다.
- 채팅 한 줄로 SNS 발행을 지시하는 경험을 한다.

## 핵심 메시지
- 자동화의 핵심은 "보고 받고 → 판단하고 → 지시하는" 루프다.
- 초안은 AI가, 판단은 사람이, 실행은 다시 AI가.
- 완전 자동 발행보다 검수 단계를 남기는 게 더 안전하고 쓸모 있다.
- 피드백 루프가 있어야 품질이 올라간다.

## 소단원별 전개

### 14.1 초안에서 발행까지 — 어떤 단계가 있을까
- 콘텐츠 자동화 워크플로우: 소스 수집 → 초안 생성 → 검토 → 승인 → 발행
- 멀티 채널 개념: 같은 소스에서 Threads(짧은 글) + 뉴스(긴 글) 두 가지가 나온다
- 초안 상태 관리: "퇴고 필요" → "승인됨" 두 단계

### 14.2 "이것도 발행해줘" — OpenClaw에게 발행 지시하기
- 핵심 장면: 텔레그램으로 "3번 뉴스 Threads에 올려줘"
- OpenClaw가 초안을 만들어 보여줌 → 독자가 확인 → "좋아, 발행해" → 발행 완료
- 승인 흐름: AI가 초안 → 사람이 확인 → AI가 실행
- 이게 바로 "반자동 발행" — 완전 자동보다 안전하고 실용적

### 14.3 발행 후 — 무엇을 확인하고 무엇을 고칠까
- 발행 후 피드백: "이 글 톤이 좀 딱딱하다" → OpenClaw에게 스타일 조정 지시
- 오래된 초안 정리: 14일 넘은 미승인 초안은 자동 정리
- 반자동 → 정기 자동 발행으로 넘어가기: 익숙해지면 자동 승인 비율을 올린다

## 꼭 넣을 장면 / 사례 / 실습
- 텔레그램에서 "이것도 발행해줘"를 치는 장면
- 초안 확인 → 승인 → 발행 완료까지의 채팅 흐름 스크린샷
- 완전 자동 발행보다 검수 단계를 남기는 게 더 좋은 이유 설명
- 발행 후 피드백으로 품질을 올리는 장면
