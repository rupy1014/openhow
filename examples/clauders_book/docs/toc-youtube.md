# 유튜브 홍보 전략 & 콘텐츠 TOC

## 전략 요약

유튜브는 **인강의 쇼룸**이다. 목표는 구독자 100만이 아니라 **인강 수강생 전환**.

```
유튜브 무료 영상 (맛보기 + 검색 유입)
  → 댓글/커뮤니티에서 신뢰 쌓기
  → 인강 랜딩페이지로 유도
```

### 핵심 원칙

1. **무료 영상 = 완결된 결과물** — "더 보려면 인강에서"가 아니라, 무료만 봐도 하나는 해결된다. 그래야 신뢰가 쌓인다.
2. **인강 = 체계 + 깊이 + 후속 지원** — 무료에서 다루지 않는 구조적 이해, 트러블슈팅, 커뮤니티 접근이 인강의 가치.
3. **영상 하나당 검색 키워드 하나** — 제목이 곧 SEO. "바이브코딩이란?" 같은 모호한 제목 금지.

## 유튜브 → 인강 전환 퍼널

### 영상 내 CTA (자연스럽게)

```
"이 영상에서는 블로그 자동화 하나만 다뤘는데,
인강에서는 이 구조를 뉴스봇, 유튜브, 문서 자동화까지 확장합니다.
링크는 설명란에."
```

### 설명란 고정 템플릿

```
📘 인강 전체 보기: [인강 URL]
🔗 예제 코드: [GitHub URL]
💬 커뮤니티: [디스코드/카카오톡 URL]

⏱ 타임스탬프
00:00 인트로
01:30 ...
```

### 전환 포인트 (무료 vs 인강)

| 무료 유튜브 | 인강에서 추가로 얻는 것 |
| --- | --- |
| 결과물 하나 완성 | 왜 이렇게 만드는지 구조 설명 |
| 에러 없는 해피패스 | 트러블슈팅 + 자주 빠지는 함정 |
| 단일 유즈케이스 | 유즈케이스 간 연결 + 응용 |
| 일방향 시청 | 커뮤니티 질문 + 코드 리뷰 |
