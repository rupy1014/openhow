# 07장 개요 — 빌더로 천천히 성장하기

## 장의 역할
MVP, PMF, 피드백 루프를 통해 시행착오를 줄이는 빌더의 사고방식을 설명한다.

## 독자가 읽고 남겨야 할 변화
- 이 장을 읽고 나면 다음 장으로 넘어갈 자신감이나 프레임이 생겨야 한다.
- 설명보다 먼저 장면이 남아야 한다.

## 핵심 메시지
- 처음부터 플랫폼을 만들려 들면 망하기 쉽다.
- 창업가처럼 말해본다는 건 문제/가설/검증 언어를 쓰는 것이다.
- Scope를 줄여야 피드백 속도가 빨라진다.
- PMF 전에는 빠른 검증이 가장 중요하다.

## 소단원별 전개
### 07.1 창업가처럼 말해보기
문제, 고객, 가치제안을 말로 정리해본다.

### 07.2 프로젝트 Scope 줄이기
안 만들 것을 정하는 언어를 배운다.

### 07.3 PMF를 보기 전까지는 무엇을 빠르게 검증해야 할까?
가설과 반응을 작게 확인하는 법을 다룬다.

### 07.4 만들고, 보여주고, 피드백 받고, 다시 고치기
진짜 빌더의 반복 루프를 설명한다.

## 꼭 넣을 장면 / 사례 / 실습
- 아이디어가 커지다가 다시 줄이는 장면
- 지인에게 보여주고 반응을 받는 장면
- 기능보다 문제 정의가 중요해지는 장면
