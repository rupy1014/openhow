# 06장 개요 — 만든 서비스를 직접 배포해보기

## 장의 역할
Git과 배포를 통해 “내 컴퓨터 안”의 결과물을 “세상에서 열리는 링크”로 바꾸는 경험을 준다.

## 독자가 읽고 남겨야 할 변화
- 이 장을 읽고 나면 다음 장으로 넘어갈 자신감이나 프레임이 생겨야 한다.
- 설명보다 먼저 장면이 남아야 한다.

## 핵심 메시지
- Git은 저장과 되돌리기의 기본 장치다.
- GitHub는 협업만이 아니라 공개와 배포의 출발점이다.
- 배포 플랫폼 선택은 기술 자랑보다 운영 조건의 문제다.
- 환경변수는 서비스가 현실 세계와 연결되는 지점이다.
