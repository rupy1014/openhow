# 바로바로 자동화 with ChatGPT

> “이런 것도 되나요?”
>
> 된다. 다만 그냥 되는 게 아니라,
> **내 일에 맞게 자동화 구조를 잡을 때** 훨씬 빨리 된다.

이 책은 ChatGPT를 검색처럼만 써보던 사람이,
**Codex와 자동화 도구를 이용해 자기 일을 조금씩 줄이는 사람**으로 넘어가게 만드는 입문서다.

초반에는 한 줄 설치와 첫 실습으로 겁을 낮춘다.  
그다음에는 자동화가 어떤 식으로 돌아가는지 감을 잡고,  
중간에는 작은 서비스를 직접 만들고 배포해보며 바닥 감각을 익힌다.  
후반에는 자동화 구조를 읽고, 마지막에는 실전 유즈케이스를 자기 일로 가져오는 흐름으로 간다.

---

## 이 책은 어떻게 흘러가?

| 파트 | 독자 변화 | 중심 질문 |
|---|---|---|
| Part 1. Codex로 자동화 시작하기 | 호기심 → 첫 체감 | 자동화는 어떻게 시작되고 왜 이런 구조로 움직일까? |
| Part 2. 기초 다지기 — 바이브코딩 입문 | 체감 → 바닥 감각 | 작은 서비스를 어떻게 만들고 배포할까? |
| Part 3. 자동화 구조 읽기 | 감각 → 구조 이해 | 자동화 시스템은 어디까지 가능하고 왜 한계가 생길까? |
| Part 4. 실전 자동화 유즈케이스 | 구조 이해 → 실무 연결 | 내 일에는 어디부터 붙이면 좋을까? |
