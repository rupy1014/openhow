# 바로바로 자동화 입문 with 챗GPT + Codex + OpenClaw

> “이런 것도 되나요?”
>
> 된다. 다만 그냥 되는 게 아니라,
> **내 일에 맞게 자동화 구조를 잡을 때** 훨씬 빨리 된다.

이 책은 ChatGPT를 검색처럼만 써보던 사람이,
**Codex, OpenClaw, 자동화 도구를 이용해 자기 일을 조금씩 줄이는 사람**으로 넘어가게 만드는 입문서다.

초반에는 한 줄 설치와 첫 실습으로 겁을 낮춘다.
그다음에는 자동화가 어떤 식으로 돌아가는지 감을 잡고,
중간에는 작은 서비스를 직접 만들고 배포해보며 바닥 감각을 익힌다.
후반에는 OpenClaw를 설치하고, 자동화 구조를 읽고, 마지막에는 OpenClaw가 매일 보고하고 발행까지 해주는 실전 유즈케이스를 자기 일로 가져오는 흐름으로 간다.
