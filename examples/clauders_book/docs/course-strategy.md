# 인강 + 책 시너지 전략

## 왜 인강을 같이 해야 하는가

### 1. 책 품질이 올라간다

촬영하면서 실제로 따라하면 원고에서 놓친 디테일이 보인다.
"여기서 에러 나겠다", "이 단계 설명이 빠졌다"가 직접 체험으로 드러난다.
촬영 중 캡처한 스크린샷이 그대로 책 이미지가 된다.

현재 원고 ~185p → 인강 촬영 과정에서 step-by-step 보강하면 자연스럽게 400p 도달.

### 2. 수익 구조가 다각화된다

| 채널 | 역할 | 수익 비중 |
|------|------|---------|
| **인강** (인프런/클래스101) | 핵심 매출 | ★★★★★ |
| **책** (출판) | 브랜드 + 장기 로열티 | ★★ |
| **YouTube** (무료) | 유입 퍼널 | ★ (광고 부수입) |
| **커뮤니티** (오카톡/디코) | 리텐션 + 입소문 | ★★ |

책 인세(권당 ~2,500원)보다 인강 1건(5~15만원)이 20~60배 높다.
책은 "명함"이고 인강이 "매출"이다.

### 3. 마케팅이 자동으로 돌아간다

```
YouTube 무료 맛보기 (Ch01~03)
  → "전체 과정은 인강에서" 유도
    → 수강생이 "레퍼런스 책 있나요?" 질문
      → 책 구매
        → 커뮤니티 참여 → 입소문
```

인강 수강생 = 책 출간 시 초기 구매자.
수강생 질문/리뷰 = 책 FAQ + 추천사 소스.

### 4. 이 책의 차별점이 영상에서 더 빛난다

"OpenClaw가 텔레그램으로 뉴스 보고하는 장면"은 글로 읽는 것보다
**실제 돌아가는 데모 영상**이 100배 설득력 있다.
자동화 결과물이 실시간으로 보이는 것 = 바이럴 클립 소재.

## 실행 전략

### Phase 1. 인강 촬영 + 책 동시 업데이트 (4~6주)

| 회차 | 범위 | 촬영 내용 | 책 업데이트 |
|------|------|---------|----------|
| 1회차 | Ch01~04 (Part 1) | 설치, 첫 실행, 자동화 감잡기, 웹소설 | 스크린샷 교체 + step-by-step 보강 |
| 2회차 | Ch05~08 (Part 2) | 채팅서비스, 배포, PG, 나도만들기 | 실습 상세화 + NOTE 추가 |
| 3회차 | Ch09~12 (Part 3) | OpenClaw 설치, 구조읽기, 한계, 팀운영 | 핵심 차별화 구간 — 가장 정성 들일 것 |
| 4회차 | Ch13~17 (Part 4) | 뉴스봇, SNS, 유튜브, 문서, 비서 | 데모 장면 = 바이럴 클립 |

### Phase 2. 편집 + 출간 준비 (2~3주)

- 인강에서 쌓인 스크린샷 + 수강생 질문으로 책 최종 보강
- 프론트매터 제작 (추천사, Q&A, 진도표)
- 교정

### Phase 3. 런칭

- 인강 먼저 오픈 → 수강생 리뷰 확보
- 책 출간 시 "인강 연계 도서" 마케팅
- YouTube에서 Ch01 등 무료 공개 → 퍼널 가동

## 촬영 시 책 업데이트 워크플로우

촬영 1회가 끝나면 아래를 바로 실행한다.

```
1. OBS 녹화 파일에서 핵심 장면 스크린샷 추출
2. docs/images/에 chNN-MM.png로 저장
3. 해당 챕터 원고 열기
4. step-by-step 보강 — 촬영 중 막혔던 부분 위주
5. NOTE/트러블슈팅 추가 — 촬영 중 발견한 함정
6. 교육 구성 요소 삽입 — 워밍업, 잠깐 퀴즈, 바로 핵심 요약
7. 커밋 — "Ch09 인강 촬영 반영: step-by-step + 스크린샷 12장"
```

이렇게 하면 인강 17회 촬영 완료 시점에 **책 원고도 400p 분량으로 완성**된다.

### 무료 공개 범위

| 공개 | 내용 | 목적 |
|------|------|------|
| 무료 | Ch01 설치 + 첫 실행 | "나도 할 수 있겠다" 훅 |

### 바이럴 클립 후보

- "아침에 출근하니 텔레그램에 뉴스 요약이 와 있다" (Ch13)
- "이것도 발행해줘" 한마디에 SNS에 올라간다 (Ch14)
- "코딩 1도 모르는데 10분 만에 서비스 배포" (Ch06)
- "AI한테 웹소설 1화 쓰게 하기" (Ch04)

## 인강 플랫폼 비교

| 플랫폼 | 수수료 | 장점 | 단점 |
|--------|--------|------|------|
| **인프런** | 30% | 개발/IT 타겟 정확, 검색 유입 강함 | 비개발자 유입 약함 |
| **클래스101** | 40~50% | 비개발자 유입 강함, 마케팅 지원 | 수수료 높음 |
| **자체 (Gumroad 등)** | 5~10% | 마진 최대 | 트래픽 자체 확보 필요 |
| **복수 등록** | 각각 | 채널 다각화 | 관리 비용 |

이 책의 타겟(비개발자)을 고려하면:
- **클래스101**로 비개발자 유입 확보 + **인프런**으로 IT 관심층 커버
- YouTube는 무료 퍼널로만 사용

## 핵심 원칙

1. **인강이 매출, 책이 브랜드** — 둘 다 필요하지만 우선순위는 인강
2. **촬영이 곧 집필** — 별도로 시간 내지 않아도 인강 촬영 = 책 원고 업데이트
3. **YouTube 무료 클립은 빨리 시작할수록 유리** — 알고리즘은 시간이 자산
4. **수강생 질문 = 콘텐츠** — FAQ, 트러블슈팅, 추천사 전부 여기서 나옴
5. **OpenClaw 데모가 최강 훅** — "자동화가 실제로 돌아가는 장면"은 이 책만의 무기
