## 2. 챕터 내 교육 구성 요소 (전 챕터 공통)

현재 원고에 **전무한** 구성 요소들. 레퍼런스에서는 이것들이 전체 분량의 ~30%를 차지한다.

### 2-1. 워밍업 박스 (절 시작)

각 절(소단원) 시작 시 짧은 복습 포인트 + "미리 알아두세요!" 박스.

```markdown
:::warmup
**기억하고 있나요?**
01 OpenClaw의 스킬이란 무엇인가요?
→ 01 스킬은 AI가 수행할 수 있는 개별 작업 단위입니다.
:::
```

- 적용: 모든 절 (약 50~60개 절)
- 분량 기여: 절당 0.3p → 총 ~18p

### 2-2. NOTE 박스 (본문 중간)

주의사항, 팁, 보충 설명. 레퍼런스에서는 거의 매 2~3p마다 등장.

```markdown
:::note
실습에 필요한 자료는 모두 '독자 제공 파일'에서 내려받을 수 있습니다.
:::
```

- 적용: 챕터당 3~5개
- 분량 기여: 개당 0.2p → 총 ~15p

### 2-3. 1:1 코칭 사이드바 (심화/배경지식)

레퍼런스의 "할 수 있다! 1:1 코칭" 대응. 본문 흐름을 끊지 않으면서 심화 내용을 제공.

```markdown
:::coaching 공유하자! API 키 관리 문화
API 키는 비밀번호와 같습니다. 절대 코드에 직접 적지 마세요.
`.env` 파일에 넣고, `.gitignore`에 추가하는 습관을 들이세요.
:::
```

- 적용: 챕터당 1~2개
- 분량 기여: 개당 0.5p → 총 ~20p

### 2-4. 잠깐 퀴즈 (중간 확인)

레퍼런스의 "잠깐 퀴즈" 대응. 소단원 중간에 1~2문항으로 이해도 확인.

```markdown
:::quiz
**잠깐 퀴즈** '지금 작성한 코드의 이 부분이 무슨 뜻이야?'라고 가볍게
물어보고 싶을 때 사용하는 모드는 무엇일까요?
:::
```

- 적용: 실습 챕터에 챕터당 2~3개
- 분량 기여: 개당 0.3p → 총 ~10p

### 2-5. 바로 핵심 요약 (절 끝)

레퍼런스의 "바로 핵심 요약" 대응. 각 절 끝에 체크리스트 형태 요약.

```markdown
:::summary
**바로 핵심 요약**
✅ OpenClaw의 스킬은 하나의 작업 단위입니다.
✅ standing orders는 스킬 실행의 기본 규칙입니다.
✅ 하트비트는 정해진 주기로 스킬을 자동 실행합니다.
:::
```

- 적용: 모든 절 (약 50~60개)
- 분량 기여: 절당 0.3p → 총 ~18p

### 2-6. 총정리 퀴즈 (장 끝)

레퍼런스의 "총정리 퀴즈" 대응. 각 장 끝에 5~8문항.
빈칸 채우기, O/X, 선택형 혼합.

```markdown
## 총정리 퀴즈

1. 다음 빈칸에 알맞은 단어는 무엇인가요?
   OpenClaw에서 ______은(는) AI가 수행할 수 있는 개별 작업 단위입니다.

2. OpenClaw의 standing orders에 대한 설명으로 올바른 것은?
   ① 스킬의 실행 로그를 저장하는 기능
   ② 스킬 실행 시 항상 지켜야 할 기본 규칙
   ③ 텔레그램 채널을 관리하는 도구
```

- 적용: 17장 전체
- 분량 기여: 장당 1.5p → 총 ~25p
