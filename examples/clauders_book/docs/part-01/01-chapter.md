> "설치가 끝나면 공부의 절반이 끝난 겁니다. 나머지는 AI와 수다 떠는 일뿐이거든요."

새로운 걸 배울 때 가장 큰 고비가 언제인지 아시나요? 바로 '설치'할 때입니다. 검은 화면에 영어 문자들이 쏟아지는 걸 보면, 시작도 하기 전에 "내 길이 아닌가 봐" 하며 창을 닫게 되죠. 사실 저도 그랬습니다.

이 책을 읽는 분들은 아마 이런 분들이실 겁니다.

**윤지영 씨(32, 마케터)**는 매일 아침 경쟁사 블로그 다섯 곳을 돌며 새 글을 확인합니다. 요약해서 팀 슬랙에 올리는 데만 매일 40분. "이걸 AI가 대신해주면 좋겠는데, 어디서부터 시작해야 할지 모르겠다"가 지영 씨의 고민입니다.

**박현수 씨(41, 1인 사업자)**는 온라인 쇼핑몰을 운영합니다. 고객 문의 응대, 발주, 블로그 포스팅을 혼자 다 합니다. 직원 한 명 둘 여유는 없지만 "나를 대신할 비서" 같은 건 간절합니다.

**이도현 씨(23, 대학생)**는 유튜브 콘텐츠를 만들고 싶은데 촬영도, 편집도 혼자 해야 합니다. "대본이라도 AI가 써주면 시간이 반으로 줄 텐데"라고 생각하지만 터미널이라는 검은 화면이 겁납니다.

세 사람 모두 코딩을 모릅니다. 하지만 이 책이 끝날 때쯤이면, 지영 씨의 뉴스 모니터링은 자동으로 돌아가고, 현수 씨의 맥미니에는 AI 비서가 앉아 있고, 도현 씨는 대본부터 영상까지 파이프라인을 갖게 됩니다.

우리는 딱 '한 줄'만 복사해서 붙여넣는 것부터 시작합니다. 복잡한 환경 설정이나 수십 번의 'Next' 버튼 클릭은 필요 없습니다. 이 장이 끝나면 여러분의 컴퓨터는 여러분의 말을 알아듣고 직접 파일을 만드는 유능한 조수를 갖게 될 거예요.

자, 그러면 겁내지 말고 딱 한 걸음만 내디뎌 볼까요?

---

## 완성 기준
- [ ] 내 컴퓨터에 Codex CLI 설치 완료
- [ ] 터미널에서 `codex`를 실행하고 첫 인사 나누기
- [ ] 한 줄의 요청으로 나만의 '이력서 웹페이지' 만들기

## STEP 1. 일단 설치하기 (딱 한 줄이면 됩니다)
설치 전에는 누구나 불안합니다. "잘못 깔아서 컴퓨터 고장 나면 어떡하지?"라거나 "전문가용 프로그램 같은데 내가 써도 되나?" 하는 생각이 들죠. 솔직히 말씀드리면, 지금 우리가 설치할 도구는 전문가들도 감탄하며 쓰는 도구입니다. 하지만 설치 방법만큼은 초등학생도 할 수 있을 정도로 쉽습니다.

### 1-1. 내 컴퓨터의 '터미널' 열기
컴퓨터와 대화하는 창인 '터미널'을 먼저 열어야 합니다.

01 **Windows 사용자**: 시작 버튼을 누르고 'PowerShell'을 검색하세요. 반드시 **'관리자 권한으로 실행'**을 클릭해야 합니다.
02 **Mac 사용자**: 'Command + Space'를 누르고 'Terminal'을 입력해 실행하세요.

![윈도우와 맥 터미널 실행 화면 비교](/__content__/images/ch01-01.png)

### 1-2. 설치 명령어 복사해서 붙여넣기
아래 명령어 중 본인의 운영체제에 맞는 것을 딱 한 줄만 복사하세요. 그리고 터미널 창에 붙여넣은 뒤 'Enter'를 누르면 됩니다.

**Windows용 설치 명령어**
```bash
irm https://raw.githubusercontent.com/rupy1014/base-install/main/codex-window-install.ps1 | iex
```

**Mac용 설치 명령어**
```bash
curl -fsSL https://raw.githubusercontent.com/rupy1014/base-install/main/codex-mac-install.sh | bash
```

설치가 끝나면 `codex`와 `dscodex` 두 가지 명령어가 사용 가능합니다. 설치 스크립트가 완료되면 자동으로 새 터미널 창이 열립니다.

> **확인**: "설치 완료!"라는 메시지와 함께 사용 가능한 명령어 목록이 보이면 성공입니다. 새 터미널 창에서 `codex --version`을 입력해 확인해 보세요.

### 1-3. 첫 실행 — ChatGPT 계정으로 로그인
Codex CLI를 처음 실행하면 ChatGPT 계정 로그인이 필요합니다.

01 터미널에 `codex`를 입력하세요.
02 브라우저가 자동으로 열리면서 ChatGPT 로그인 화면이 나타납니다.
03 평소 쓰던 ChatGPT 계정으로 로그인하면 끝입니다.

> **팁**: API 키가 있다면 `codex login --with-api-key`로도 로그인할 수 있습니다. ChatGPT 무료 계정으로도 충분합니다.

## STEP 2. 방금 무엇을 설치한 걸까?
잠시 숨을 돌려볼까요? 방금 한 줄의 명령어로 여러분의 컴퓨터에는 꽤 근사한 엔진들이 설치되었습니다. 이게 정확히 뭔지 알아야 나중에 막혔을 때 당황하지 않거든요.

### 2-1. 3총사의 역할 분담
우리가 설치한 건 크게 세 가지입니다. 어려운 용어 대신 비유로 이해해 보죠.

1. **Node.js (심장)**: Codex가 돌아갈 수 있게 해주는 엔진입니다. 없으면 Codex를 설치조차 할 수 없어요.
2. **Git (기억력)**: 파일의 변경 이력을 기록하는 도구입니다. "아까 그 버전으로 돌려줘"가 가능해지죠.
3. **Codex CLI (조수)**: 터미널에서 우리 말을 알아듣고 작업을 대신 해줄 AI 조수입니다. OpenAI가 만들었어요.

그리고 이 셋을 불러내는 장소가 바로 **터미널(대화방)**입니다.

![Node, Git, Codex — 개발 환경 3총사](/__content__/images/ch01-02.png)

### 2-2. "왜 웹사이트 안 쓰고 터미널을 써요?"
"그냥 챗GPT 사이트 가서 물어보면 안 돼요?"라고 하실 수 있습니다. 좋은 질문이에요.
웹사이트에 있는 AI는 '입만 살아있는 친구'라면, 터미널의 Codex는 '손발이 달린 친구'입니다. 웹 AI는 코드만 짜주지만, 얘는 여러분의 폴더에 직접 파일을 만들고, 내용을 적고, 심지어 오타가 있으면 고치기까지 하거든요. 확장성이 비교도 안 될 만큼 좋죠.

## STEP 3. 프로젝트 바로 시작하기
자, 이제 이론은 됐고 바로 실전으로 가봅시다. 우리는 오늘 여러분의 근사한 이력서 페이지를 하나 만들 거예요.

### 3-1. 작업 폴더 만들기
AI는 '폴더' 단위로 일을 합니다. "이 폴더 안에서만 놀아!"라고 범위를 정해주는 거죠.

01 터미널에 `mkdir my-resume`라고 입력하세요. (내 이력서라는 폴더를 만드는 명령입니다)
02 `cd my-resume`를 입력해 그 폴더 안으로 들어갑니다.
03 이제 `codex`라고 입력해 보세요.

> **확인**: Codex가 실행되면서 대기 상태가 되었나요? 축하합니다. 첫 번째 대화 준비가 끝났습니다!

### 3-2. "해줘" 한 줄의 마법
이제 AI에게 미션을 줍니다. 여러분이 UX/UI 디자이너라고 가정하고 이력서 페이지를 만들어달라고 해볼게요.

01 아래 프롬프트를 복사해서 터미널에 붙여넣으세요.
`내 개인 이력서 페이지 만들어줘. 나는 3년 차 UX/UI 디자이너고, 깔끔한 스타일을 좋아해. index.html 파일로 만들어줘.`

![Codex가 파일을 생성하는 터미널 화면](/__content__/images/ch01-03.png)

02 Codex가 작업 계획을 보여주고 실행합니다. 파일이 만들어지는 과정이 터미널에 표시됩니다.
03 작업이 끝나면 폴더에 `index.html` 파일이 생겨 있을 겁니다.

### 3-3. 읽기 → 만들기 → 고치기

웹 브라우저를 열어서 방금 만든 `index.html` 파일을 드래그해 넣어보세요. 코딩 한 줄 몰랐는데, 그럴싸한 웹페이지가 눈앞에 나타날 겁니다.

![브라우저에서 열린 이력서 페이지](/__content__/images/ch01-04.png)

이제 세 가지 기본기를 확인해 봅시다. 방금 '만들기'는 해봤죠? 나머지 두 개도 바로 해봅니다.

**읽기** — 터미널에 이렇게 입력해 보세요.
```
이 폴더에 있는 파일 목록이랑 각각 뭐 하는 건지 알려줘
```
Codex가 폴더 안의 파일을 읽고 설명해 줍니다. 검색이 아니라 **직접 파일을 열어보는 겁니다.**

**고치기** — 이번엔 수정을 시켜봅니다.
```
배경색을 파스텔 톤 하늘색으로 바꾸고, 이름을 "홍길동"으로 바꿔줘
```
브라우저를 새로고침하면 바뀌어 있습니다. Codex가 코드를 직접 찾아서 수정한 거예요.

읽기, 만들기, 고치기. 이 세 가지가 터미널 AI의 기본 동작입니다.

## STEP 4. GUI와 CLI, 뭐가 다를까?

여기서 한 가지 궁금하실 겁니다. "그냥 ChatGPT 사이트에서 물어보면 안 되나요?"

웹 AI(ChatGPT, Claude.ai 등)와 터미널 AI(Codex CLI, Claude Code 등)는 결정적으로 다릅니다.

| | 웹 AI (GUI) | 터미널 AI (CLI) |
|---|---|---|
| 파일 접근 | 대화로 코드를 '알려줌' | 내 폴더에서 직접 만들고 수정 |
| 설정 유지 | 계정에 묶임 (폴더마다 다시 설명) | 폴더에 설정 파일이 붙어다님 |
| 반복 작업 | 매번 똑같이 설명해야 함 | 한번 설정하면 자동 적용 |
| 확장성 | 대화창 안에서 끝 | 자동화, 스케줄링, 연동 가능 |

GUI는 편합니다. 버튼 누르면 되니까요. 하지만 똑같은 작업을 열 번 시키려면 열 번 다 설명해야 합니다.

CLI는 처음엔 어색합니다. 하지만 한번 익숙해지면 "이것도 자동으로 시켜볼까?"로 확장됩니다. 이 책이 결국 여러분을 데려갈 곳이 바로 그 지점이거든요.

> **참고**: 터미널 AI 도구는 여러 개가 있습니다. Codex CLI(OpenAI), Claude Code(Anthropic), Gemini CLI(Google) 등이 대표적이죠. 이 책에서는 Codex CLI를 중심으로 진행하지만, 원리는 모두 같습니다.

## `codex`와 `dscodex`, 뭐가 다를까?

설치하면 두 가지 명령어가 등록됩니다.

| | `codex` | `dscodex` |
|---|---|---|
| 파일 수정 전 | "이 파일 수정해도 될까요?" 물어봄 | 바로 수정함 |
| 속도 | 느림 (매번 확인) | 빠름 (확인 생략) |
| 추천 시점 | 처음 배울 때 | 익숙해진 뒤 |

`dscodex`는 `codex --dangerously-bypass-approvals-and-sandbox`의 줄임말입니다. Codex가 뭘 하는지 직접 보면서 익숙해진 뒤에 쓰시면 됩니다. 어차피 현재 폴더 안에서만 작동하니까, 인터넷 결제를 하거나 메일을 보내는 일은 없습니다.

## 여기서 막혔나요?

**Q. 'codex'라고 쳤는데 명령어를 찾을 수 없다고 나와요.**

상황: 이런 메시지가 뜹니다.
```
zsh: command not found: codex
```
또는 Windows에서는:
```
'codex'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램, 또는 배치 파일이 아닙니다.
```

원인: 설치가 아직 시스템에 반영되지 않았거나, 경로 설정이 꼬인 경우입니다.

해결: 터미널을 완전히 껐다가 다시 켜보세요. 설치 스크립트가 끝날 때 자동으로 새 터미널 창이 열렸을 텐데, 그 창에서 시도해 보세요. 그래도 안 된다면 STEP 1의 명령어를 다시 한번 실행해 보세요.

**Q. 파일 생성 권한이 없다고 자꾸 물어봐요.**
상황: 매번 "허용하시겠습니까?"라고 물어서 귀찮습니다.
원인: 보안을 위해 AI가 함부로 파일을 못 건드리게 막혀있는 겁니다.
해결: `dscodex`라고 입력하면 묻지 않고 쿨하게 일합니다. (단, 내가 믿을 수 있는 폴더에서만 쓰세요!)

**Q. 인터넷 결제나 메일 같은 것도 조수가 대신 하나요?**
상황: AI가 제 개인정보를 건드릴까 봐 걱정돼요.
원인: Codex의 작동 범위에 대한 오해입니다.
해결: 안심하세요. 얘는 지금 여러분이 만든 폴더(`my-resume`) 안에서만 작동합니다. 인터넷 쇼핑을 대신 하거나 메일을 보내는 일은 여러분의 허락 없이는 절대 할 수 없습니다.

**Q. Windows에서 설치 스크립트가 "실행 정책" 오류로 막혀요.**

상황: 이런 메시지가 뜹니다.
```
이 시스템에서 스크립트를 실행할 수 없으므로 ... 파일을 로드할 수 없습니다.
```
원인: Windows의 기본 보안 정책이 외부 스크립트 실행을 막고 있습니다.
해결:
1. PowerShell을 **관리자 권한**으로 열었는지 다시 확인하세요.
2. `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`를 먼저 실행한 뒤, 설치 명령을 다시 시도해 보세요.

**Q. Mac에서 `Permission denied` 오류가 나요.**
상황: `curl` 명령어 실행 시 권한 거부 메시지가 뜹니다.
원인: 설치 경로에 쓰기 권한이 없는 경우입니다.
해결: 명령어 앞에 `sudo`를 붙여서 `sudo curl -fsSL ...`로 다시 실행해 보세요. 비밀번호를 물어보면 Mac 로그인 비밀번호를 입력하면 됩니다.

## 한 줄 정리
설치는 한 줄로 끝내고, 터미널에서 `codex`를 부른 뒤, 폴더 안에서 "해줘"라고 말하면 실습은 시작됩니다. CLI는 처음엔 어색해도 익숙해지면 웹보다 10배는 빠릅니다!
