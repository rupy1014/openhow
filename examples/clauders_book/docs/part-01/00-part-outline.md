# Part 1 개요 — ChatGPT 시대, Codex로 자동화 시작하기

## 이 파트의 역할
초반 4장은 설치 설명이 아니라 **자동화 감각을 심는 파트**다.

- 1장: 겁을 낮추고 바로 실행한다.
- 2장: 자동화가 어떤 식으로 굴러가는지 맛본다.
- 3장: 용어를 쉽게 다시 정리해 독자를 안심시킨다.
- 4장: 실제 사례를 따라가며 디테일과 품질 감각을 보여준다.

## 독자가 남겨야 할 변화
- 설치를 겁내지 않게 된다.
- 자동화를 “딸깍 환상”이 아니라 구조로 보기 시작한다.
- LLM, 컨텍스트, hooks, workflows 같은 말을 덜 무서워한다.
- 실제 사례를 보며 “내 일에도 이런 식으로 붙이면 되겠다”를 느낀다.

## 파트 리듬
1. 실습  
2. 감 잡기  
3. 쉬운 설명  
4. 디테일한 사례

## 꼭 지켜야 할 것
- 초반은 장황하면 안 된다.
- 2장까지는 “되는 장면”이 먼저다.
- 3장은 독자에게 용기를 주는 장이어야 한다.
- 4장은 사례를 통해 자동화 완성도가 어떻게 올라가는지 보여줘야 한다.
