# 04장 개요 — 웹소설 자동화

## 장의 역할
실제 사례를 따라가며 자동화 설계의 디테일과 품질 개선 과정을 보여준다.

## 독자가 읽고 남겨야 할 변화
- 이 장을 읽고 나면 다음 장으로 넘어갈 자신감이나 프레임이 생겨야 한다.
- 설명보다 먼저 장면이 남아야 한다.

## 핵심 메시지
- 도메인 지식 없이 자동화부터 하면 결과가 얕아진다.
- 웹소설 연재는 조사, 설정, 초안, 퇴고가 분리된 대표 사례다.
- 좋은 워크플로우는 작가의 판단을 없애지 않고 강화한다.
- 품질은 결국 얼마나 집요하게 피드백 루프를 설계하느냐에 달려 있다.

## 소단원별 전개
### 04.1 웹소설 연재는 어떻게 시작할까
플랫폼, 독자 기대치, 장르 문법, 연재 리듬을 먼저 이해한다.

### 04.2 자료 조사부터 설정까지 설계하기
조사 → 설정 → 캐릭터 → 비트 → 초안 순서로 설계한다.

### 04.3 초안, 퇴고, 피드백 루프 만들기
여러 버전 비교, 문장 가다듬기, 회차 단위 검토를 다룬다.

### 04.4 자동화 품질은 어디서 갈릴까
도메인 몰입과 반복 개선이 품질을 가른다는 메시지로 닫는다.

## 꼭 넣을 장면 / 사례 / 실습
- 연재 플랫폼을 조사하는 장면
- 캐릭터/설정 자료가 쌓이는 장면
- 초안보다 퇴고 단계가 더 중요해지는 장면
