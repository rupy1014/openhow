# 01장 개요 — 코덱스 설치하고 바로 실행하기

## 장의 역할
설치와 첫 실행의 진입장벽을 가장 낮은 형태로 넘기게 만든다. "코덱스가 뭔지"보다 "일단 켜서 뭔가 돌아가는 걸 보는 것"이 먼저다.

## 독자가 읽고 남겨야 할 변화
- 코덱스가 설치되어 있고, 첫 명령을 성공적으로 실행한 상태
- "이걸로 뭔가 만들 수 있겠다"는 자신감

## 핵심 메시지
- 설치는 짧아야 한다 — 한 줄이면 끝
- VS Code + 코덱스 조합이 개발 환경의 전부
- 프로젝트 = 폴더 하나. 특별한 게 아니다
- 첫 실습은 작아야 한다 — 파일 하나 만들기

## 소단원별 전개
### 01.1 코덱스란 무엇인가
코덱스가 뭔지 한 문단으로. AI 코딩 에이전트. 터미널에서 말로 시키면 코드를 만들어준다.

### 01.2 [실습] 터미널 열고 설치하기
npm 한 줄로 설치. 성공 화면 캡처. 설치 전 불안한 독자 독백 → 설치 후 "어? 됐네?" 감정.

### 01.3 VS Code에서 코덱스 둘러보기
VS Code 열기 → 코덱스 패널 확인. GUI의 편함과 CLI의 확장성 간단 비교.

### 01.4 프로젝트란 — 폴더 하나가 프로젝트
폴더를 만들고 그 안에서 코덱스를 시작하는 것이 프로젝트. AGENTS.md 파일의 역할.

### 01.5 [실습] 코덱스에게 첫 번째 일 시키기
"index.html 만들어줘" 한 줄 → 결과 확인. 첫 성공 경험.

## 꼭 넣을 장면 / 사례 / 실습
- 터미널에 첫 명령을 치는 장면
- 설치 완료 후 "어? 됐네?" 순간
- 첫 파일 생성 실습
