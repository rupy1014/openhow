# 13장 개요 — 뉴스봇 자동화 — OpenClaw가 매일 아침 보고합니다

## 장의 역할
RSS 수집, 키워드 필터링, 초안 생성, cron 정기 실행, 채널 보고를 하나의 자동화 유즈케이스로 보여준다.
OpenClaw가 매일 아침 자동으로 뉴스를 수집하고 텔레그램으로 리포트를 보내는 장면이 핵심.

## 독자가 읽고 남겨야 할 변화
- RSS 수집 → 필터링 → 요약 → 보고의 파이프라인을 이해한다.
- OpenClaw에 cron을 걸어 자동 실행하는 방법을 익힌다.
- "아침에 눈 뜨면 뉴스 요약이 와 있다"는 경험을 직접 설정한다.

## 핵심 메시지
- 뉴스봇은 자동화의 대표적인 첫 실전 예시다.
- 소스 수집과 선별이 결과물 품질을 좌우한다.
- OpenClaw + cron이 만나면 "매일 돌아가는 시스템"이 된다.
- 사람은 보고를 받고, 판단만 하면 된다.

## 소단원별 전개

### 13.1 소스를 모으고 고르기 — RSS 파이프라인의 뼈대
- 뉴스봇이 좋은 첫 자동화인 이유: 가져온다 → 고른다 → 요약한다 → 보낸다
- RSS가 뭔지 한 줄 설명
- 시작은 3-5개 소스면 충분하다 (Hacker News, TechCrunch, AI 관련 블로그)
- 키워드 기반 필터링: 관심 키워드에 맞는 글만 추리기

### 13.2 요약하고 초안 만들기 — AI가 쓰고, 사람이 고른다
- AI가 수집된 글을 요약해서 초안을 만든다
- "[퇴고 필요]" 개념: AI가 쓴 건 항상 검토가 필요하다
- 초안 포맷: 제목 + 한 줄 요약 + 핵심 포인트 2-3개
- 결과물은 파일로 쌓인다 — 매일의 기록

### 13.3 OpenClaw에 cron 걸기 — 매일 아침 자동 실행
- `openclaw cron add "매일 아침 7시에 뉴스 수집해서 보고해줘"`
- 파이프라인이 OpenClaw workspace 안에서 돌아가는 구조
- cron이 뭔지 한 줄 설명: "정해진 시간에 자동으로 실행되는 예약"
- 설정 후 확인: `openclaw cron list`

### 13.4 보고 받기 — "오늘은 뭐가 있지?"
- 텔레그램 알림이 온다: "오늘 뉴스 초안 5건 / 주요 키워드: AI, 자동화"
- 대화형 확인: "오늘 뉴스 요약해줘" → OpenClaw가 정리해서 보여줌
- "3번째 뉴스 자세히 보여줘" → 상세 내용 확인
- 이게 바로 "OpenClaw한테 보고 받는" 장면

## 꼭 넣을 장면 / 사례 / 실습
- RSS 소스 3-5개를 직접 설정하는 장면
- cron 등록 후 "내일 아침 확인해보세요" 마무리
- 텔레그램으로 뉴스 보고를 받는 스크린샷
- 대화형으로 "자세히 보여줘"를 쳐보는 장면
