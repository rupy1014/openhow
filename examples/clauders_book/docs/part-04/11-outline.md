# 11장 개요 — 쓰레드 자동화와 뉴스봇 만들기

## 장의 역할
콘텐츠 수집, 정리, 재구성, 정기 실행을 하나의 자동화 유즈케이스로 보여준다.

## 독자가 읽고 남겨야 할 변화
- 이 장을 읽고 나면 다음 장으로 넘어갈 자신감이나 프레임이 생겨야 한다.
- 설명보다 먼저 장면이 남아야 한다.

## 핵심 메시지
- 뉴스봇은 자동화의 대표적인 실전 예시다.
- 소스 수집과 선별이 결과물 품질을 좌우한다.
- 반자동 발행에서 정기 실행으로 가는 단계가 있다.

## 소단원별 전개
### 11.1 소스를 모으고 고르는 단계 자동화하기
수집과 선별 기준을 다룬다.

### 11.2 요약, 재구성, 쓰레드 초안 작성 자동화하기
콘텐츠 재가공 흐름을 설명한다.

### 11.3 반자동 발행에서 뉴스봇형 정기 실행으로 넘어가기
정기 실행과 검수 단계를 연결한다.

## 꼭 넣을 장면 / 사례 / 실습
- 원자료가 쌓이는 장면
- 쓰레드 초안이 빠르게 여러 개 나오는 장면
- 완전 자동 발행보다 검수 단계를 남기는 장면
