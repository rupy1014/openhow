# Part 1 — 설치하고 바로 만들기 — 바이브코딩 입문

> "해줘." — 이 한마디가 마법의 시작입니다.

---

## ChatGPT, 다들 써보셨죠?

여러분도 한 번쯤은 ChatGPT를 써보셨을 겁니다.
브라우저를 열고, 질문을 하면, 답변이 나옵니다. 편리하죠.

그런데 써보다 보면 좀 답답할 때가 있습니다.

ChatGPT가 만들어준 코드를 복사해서 파일에 붙여넣고, 또 다른 걸 물어보고, 또 복사하고. ChatGPT도 이미지나 코드를 생성해주긴 합니다. 하지만 **내 컴퓨터의 파일을 직접 만져주지는 못합니다.** 결국 복사-붙여넣기는 여러분 몫이거든요.

질문에는 정말 잘 답합니다.
그런데 실행은, 아직 여러분 손을 빌려야 합니다.

그래서 이 책에서는 다른 도구를 씁니다.

---

## Codex — "해줘"라고 시키는 도구

이 책에서 우리가 쓸 도구는 **Codex**입니다.

Codex는 ChatGPT처럼 브라우저에서 동작하지 않습니다. **터미널**이라는 곳에서 동작합니다.

터미널이 뭐냐면 — 개발자들이 쓰는 그 검은 화면입니다.
영화에서 해커가 뭔가 막 타이핑하는 그 화면이요.
좀 무섭게 생겼죠.

그런데 걱정하지 마세요. 거기서 하는 일은 채팅이랑 크게 다르지 않습니다.

ChatGPT에게는 "이거 어떻게 해?"라고 **물어봅니다.**
Codex에게는 "이거 해줘."라고 **시킵니다.**

이 차이가 핵심입니다.

"해줘"라고 하면 파일을 만들어줍니다.
홈페이지도 만들어줍니다.
서비스도 만들어줍니다.
스크립트도 짜주고, 일정에 맞춰 자동으로 돌아가는 프로그램도 만들어줍니다.

전부 내 컴퓨터 안에서, 내 파일로 직접 만들어줍니다.

---

## 왜 굳이 터미널일까요?

여기서 중요한 건 검은 화면 자체가 아닙니다.
**작업 방식이 다르다**는 겁니다.

브라우저 화면처럼 버튼을 누르고 메뉴를 고르는 방식은 **GUI**라고 합니다.
사람이 보기 쉽고, 클릭하기 쉽습니다.

반대로 터미널처럼 글자로 명령을 내리는 방식은 **CLI**라고 합니다.
처음엔 낯설지만, 한 번 말하면 바로 실행되고, 같은 작업을 다시 시키기도 쉽습니다.

Codex가 터미널에서 강한 이유도 여기 있습니다.
프로젝트 전체를 읽고, 파일을 만들고, 수정하고, 실행하고, 다시 고치는 일을 **한 흐름으로 이어서** 할 수 있기 때문입니다.

> GUI는 사람이 쓰기 좋은 화면이고, CLI는 AI가 일하기 좋은 작업대입니다.

<!-- IMG: 왼쪽은 브라우저의 ChatGPT 화면, 오른쪽은 터미널의 Codex 화면. 왼쪽에는 '질문 → 답변', 오른쪽에는 '지시 → 실행'이라는 큰 화살표가 들어간 비교 삽화 -->

그래서 이 책에서 배우는 건 단순히 "AI에게 질문하는 법"이 아닙니다.
**AI에게 일을 맡기는 법**입니다.

---

## 검은 화면이 무섭다면

솔직히 말하면, 검은 화면이 낯설 수 있습니다.
마우스로 클릭하는 게 아니라 키보드로 타이핑해야 하니까요.

그런데 여기서 여러분이 타이핑할 건 어려운 주문이 아닙니다.
대부분 이런 말들입니다.

```
이거 좀 설치해줘
```

```
홈페이지 하나 만들어줘
```

```
이 파일 정리해서 보고서로 만들어줘
```

```
이 폴더 안 문서들 읽고 발표용으로 요약해줘
```

한국어로, 채팅하듯이 말하면 됩니다.
그러면 Codex가 파일도 만들고, 폴더도 정리하고, 필요한 설정까지 알아서 해줍니다.

여러분이 해야 할 일은 생각보다 단순합니다.
원하는 걸 말하고, 나온 결과를 보고, 마음에 안 들면 다시 시키는 것.
딱 그겁니다.

---

## 한눈에 비교하면

| | ChatGPT | Codex |
|---|---------|-------|
| 어디서 쓰나 | 브라우저 | 터미널 (검은 화면) |
| 인터페이스 | GUI — 보고 클릭 | CLI — 말하고 실행 |
| 하는 일 | 질문하면 답변 | 시키면 실행 |
| 결과물 | 답변 생성 | 내 컴퓨터에 파일을 직접 생성·수정 |
| 잘하는 것 | 설명, 아이디어, 초안 | 만들기, 수정하기, 반복 작업 |
| 한마디로 | 대화형 도우미 | 실행형 비서 |

ChatGPT만 써보셨다면, 여러분은 아직 AI의 절반만 본 겁니다.
나머지 절반 — **시키면 직접 해주는 AI** — 이 책의 주인공입니다.

---

## 이 파트에서 하는 일

Part 1은 네 개의 장으로 되어 있습니다.

**1장**, 일단 설치합니다. 겁낼 거 없이, 짧게 끝냅니다.

**2장**, 캐릭터 AI 챗을 30분 만에 만들어봅니다. 이미지 두 장 주고 "이대로 만들어줘"라고 시키면, 진짜 서비스가 나옵니다.

**3장**, 만든 걸 배포합니다. 링크가 생기고, 다른 사람도 쓸 수 있게 됩니다.

**4장**, 여기까지 해보셨으면 감이 잡히셨을 겁니다. 이제 내가 풀고 싶은 문제를 찾고, 바이브코딩의 감각을 정리합니다.

---

"해줘" 한마디에서 시작해서, 내 서비스를 세상에 보여주는 곳까지.

그러면, 시작하겠습니다.
