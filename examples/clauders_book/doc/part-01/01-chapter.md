# 1장 — 한 줄 설치, 바로 실습

> "설치가 끝나면 공부의 절반이 끝난 겁니다. 나머지는 AI와 수다 떠는 일뿐이거든요."

---

## 설치가 제일 어렵습니다

솔직히 말씀드리면, 이 장이 이 책에서 제일 어렵습니다.

설치만 끝나면 **박사급 인력이 여러분의 컴퓨터에 상주하게 됩니다.** 그때부터는 모든 게 쉬워집니다. 그냥 시키면 되거든요.

그런데 그 설치가 문제입니다. 검은 화면에 영어 문자들이 쏟아지는 걸 보면, 시작도 하기 전에 "내 길이 아닌가 봐" 하고 창을 닫게 되죠. 사실 저도 그랬습니다.

스터디를 운영하면서 이걸 뼈저리게 느꼈습니다. Codex 공식 홈페이지에 가이드가 잘 되어 있거든요. 그대로 따라 하면 됩니다. 그런데 비개발자분들한테는 그 "따라 하기"가 쉽지 않았습니다.

터미널을 찾는 것부터 어려워하시는 분도 계셨고, 명령어를 복사해서 붙여넣으라고 해도 그 과정 자체가 생소한 분도 계셨습니다.

그래서 상당히 고민을 많이 했습니다. 어떻게 하면 설치를 좀 더 쉽게 할 수 있을까.

결론은 이랬습니다. **타이핑을 줄이자. 과정을 줄이자.**

그래서 설치 스크립트를 한 줄로 만들었습니다. 딱 한 줄만 복사해서 붙여넣으면 끝납니다.

---

## STEP 1. 터미널 열기

먼저 컴퓨터의 '터미널'을 열어야 합니다. 터미널이 뭐냐면 — 저번 장에서 말한 그 검은 화면입니다. 컴퓨터와 글자로 대화하는 창이라고 생각하시면 됩니다.

**Windows 사용자**
시작 버튼을 누르고 'PowerShell'을 검색하세요. **'관리자 권한으로 실행'**을 눌러야 합니다.

**Mac 사용자**
'Command + Space'를 누르고 'Terminal'을 입력해 실행하세요.

<!-- IMG: 윈도우와 맥 터미널 실행 화면 비교 -->

## STEP 2. 한 줄 복사, 붙여넣기

아래 명령어 중 본인 컴퓨터에 맞는 걸 딱 한 줄만 복사하세요.
터미널 창에 붙여넣고 'Enter'를 누르면 됩니다.

**Windows**
```bash
irm https://raw.githubusercontent.com/rupy1014/base-install/main/codex-window-install.ps1 | iex
```

**Mac**
```bash
curl -fsSL https://raw.githubusercontent.com/rupy1014/base-install/main/codex-mac-install.sh | bash
```

이 한 줄이 실행되면 필요한 것들이 자동으로 설치됩니다. 끝나면 새 터미널 창이 자동으로 열립니다.

> **확인 방법**: 새 터미널 창에서 `codex --version`을 입력해 보세요. 버전 번호가 나오면 성공입니다.

## STEP 3. VS Code 설치하기

Codex가 만들어주는 파일을 눈으로 확인하려면 **VS Code**라는 프로그램이 필요합니다. 개발자들이 쓰는 작업대라고 생각하시면 됩니다.

메모장으로도 코드를 열 수 있긴 합니다. 그런데 그건 요리사가 식칼 대신 커터칼을 쓰는 것과 같습니다.

01 인터넷 브라우저에서 **code.visualstudio.com**에 접속하세요. (또는 구글에서 vs code로 검색하세요)
02 파란색 **Download** 버튼을 누르세요.
03 다운로드된 파일을 실행하고, '다음', '다음', '완료'를 누르면 끝입니다.

## STEP 4. VS Code 둘러보기

VS Code를 처음 열면 좀 복잡해 보입니다. 그런데 알아야 할 곳은 딱 세 군데뿐입니다.

<!-- IMG: VS Code 화면에 왼쪽/가운데/오른쪽 영역 표시 -->

**왼쪽 패널 — Explorer (탐색기)**

여기가 파일과 폴더를 보는 곳입니다. 윈도우 탐색기나 맥 Finder랑 비슷합니다. 여기서 폴더를 만들 수도 있고, 파일을 만들 수도 있습니다. 마우스 오른쪽 버튼을 누르면 '새 파일', '새 폴더' 메뉴가 나옵니다.

**가운데 패널 — 에디터**

왼쪽에서 파일을 클릭하면 가운데에 그 파일의 내용이 열립니다. 여기서 내용을 보고, 필요하면 직접 수정할 수도 있습니다.

**오른쪽 패널 — Copilot (닫으세요)**

처음 열면 오른쪽에 Copilot이라는 패널이 보일 수 있습니다. 이건 우리가 쓸 게 아니니까 **X 버튼을 눌러서 닫아주세요.** 우리는 Codex를 쓸 겁니다.

## STEP 5. 터미널 열고 Codex 실행하기

자, 여기가 중요합니다.

VS Code 상단 메뉴에서 **터미널 → 새 터미널**을 눌러보세요.

> **메뉴가 안 보이면?** Windows에서는 상단 메뉴가 숨겨져 있을 수 있습니다. VS Code 왼쪽 위에 **≡** (가로줄 세 개) 버튼이 보이면 그걸 누르세요. 거기서 **터미널 → 새 터미널**을 찾을 수 있습니다. 아니면 키보드에서 `` Ctrl + ` `` (숫자 1 왼쪽의 물결 키)을 눌러도 됩니다.

<!-- IMG: VS Code 메뉴에서 터미널 → 새 터미널 선택하는 화면 (≡ 메뉴 포함) -->

화면 아래쪽에 검은 창이 하나 뜹니다. 이게 터미널입니다.

여기서 주의할 점이 하나 있습니다. **터미널이 뜬다고 해서 Codex가 실행된 게 아닙니다.** 터미널은 그냥 빈 대화창이에요. 여기에 `codex` 또는 `dscodex`라고 직접 쳐야 Codex가 켜집니다.

01 터미널에 `codex`를 입력하고 Enter를 누르세요.
02 처음 실행하면 브라우저가 자동으로 열리면서 ChatGPT 로그인 화면이 나타납니다.
03 평소 쓰던 ChatGPT 계정으로 로그인하면 끝입니다.

ChatGPT 계정이 있으면 일단 시작할 수 있습니다.

> **🙋 질문이요! 요금제 뭘 써야 해요?**
>
> 저는 Pro 요금제(월 200달러)를 권장합니다. 가장 비싸지만 그만큼 좋거든요.
>
> 다만 입문 단계에서 월 200달러는 부담스러울 수 있습니다. 그래서 이 책에서는 **Plus 요금제(월 20달러, 약 2만 9천 원)**로 진행합니다. 책에 나오는 실습은 Plus로 전부 따라 할 수 있습니다.
>
> 무료 계정은 추천하지 않습니다. 한시적 프로모션이라 언제 막힐지 모르고, 사용량 제한이 너무 빡빡합니다.
>
> Plus를 쓰다 보면 사용량이 막히는 순간이 올 겁니다. 당황하지 마세요. 잠깐 쉬었다가 나중에 다시 하면 됩니다. 그리고 나중에 Codex를 잘 활용하게 됐다 싶으면 그때 Pro로 올리세요. 그때는 값어치를 하거든요.

## `codex`와 `dscodex`, 뭐가 다를까?

설치하면 두 가지 명령어가 등록됩니다.

`codex`로 실행해도 되고, `dscodex`로 실행해도 됩니다.

차이가 뭐냐면 — `codex`는 뭔가 할 때마다 물어봅니다.

"이 파일 수정해도 될까요?" "이거 실행해도 될까요?"

처음에는 안전하니까 좋습니다. 그런데 좀 쓰다 보면 솔직히 귀찮습니다.

`dscodex`는 그런 질문 없이 바로 실행합니다. 원래 명령어는 `codex --dangerously-bypass-approvals-and-sandbox`인데, 이걸 매번 치기엔 너무 기니까 `dscodex`라는 짧은 이름으로 만들어 둔 겁니다.

| | `codex` | `dscodex` |
|---|---|---|
| 파일 수정 전 | "이거 해도 될까요?" 물어봄 | 바로 실행 |
| 속도 | 느림 (매번 확인) | 빠름 (확인 생략) |
| 추천 시점 | 처음 배울 때 | 익숙해진 뒤 |

저 같은 경우에는 처음부터 `dscodex`를 씁니다. 어차피 지정한 폴더 안에서만 작동하니까, 인터넷 결제를 하거나 메일을 보내는 일은 없습니다. 안심하셔도 됩니다.

## STEP 6. 프로젝트란 뭘까?

자, 설치도 끝났고 VS Code도 둘러봤으니 이제 직접 해봅시다.

그 전에 하나만 알고 갑시다. 앞으로 '프로젝트'라는 말이 자주 나옵니다. 거창하게 들리지만 별거 아닙니다.

**프로젝트 = 폴더 하나**입니다.

그 폴더 안에 파일이 들어가고, 그 파일들이 모여서 하나의 결과물이 되는 겁니다. 홈페이지든, 앱이든, 자동화 도구든 다 마찬가지입니다. 폴더 하나가 곧 프로젝트 하나입니다.

그러면 지금 바로 프로젝트를 하나 만들어 봅시다.

### 6-1. 폴더 만들고 VS Code에서 열기

01 바탕화면에서 마우스 오른쪽 버튼을 클릭하세요.
02 **'새 폴더'**를 눌러 폴더를 하나 만드세요.
03 이름을 `my-first-project`로 바꿔주세요.

<!-- IMG: 바탕화면에서 폴더 만드는 화면 -->

04 VS Code를 열고, 왼쪽 위 **파일 → 폴더 열기**를 누르세요.
05 방금 바탕화면에 만든 `my-first-project` 폴더를 선택하세요.

왼쪽 Explorer에 폴더 이름이 보이면 성공입니다. 아직 비어 있으니까 아무것도 없는 게 정상이에요. 이게 여러분의 첫 번째 프로젝트입니다.

### 6-2. Codex한테 파일 만들어달라고 하기

이제 터미널에서 `dscodex`를 실행하고, 이렇게 말해보세요.

```
자기소개.md 파일을 만들어줘. 이름은 홍길동, 직업은 떡집 사장님, 취미는 등산이야.
```

<!-- IMG: Codex가 자기소개.md를 만드는 터미널 화면 -->

Codex가 파일을 만들면 왼쪽 Explorer에 `자기소개.md`가 나타납니다. 클릭해 보세요. 가운데 에디터에 내용이 보이죠.

한 번 더 해볼까요?

```
오늘할일.md 파일을 만들어줘. 내용은 체크리스트로 해줘. 1. 재료 주문하기, 2. 블로그 글 쓰기, 3. 택배 보내기.
```

왼쪽을 보세요. `자기소개.md`, `오늘할일.md` — 파일이 두 개 생겼습니다.

<!-- IMG: VS Code Explorer에 자기소개.md, 오늘할일.md가 보이는 화면 -->

폴더 안에 파일이 하나씩 쌓여가는 거, 이게 프로젝트입니다.

### 6-3. 수정도 시켜보기

이번엔 방금 만든 파일을 고쳐달라고 해봅시다.

```
자기소개.md에 "좋아하는 음식: 김치찌개"를 추가해줘.
```

왼쪽에서 `자기소개.md`를 클릭해 보세요. 내용이 바뀌어 있습니다. Codex가 파일을 직접 열어서 수정한 겁니다.

만들기, 수정하기. 이 두 가지만 할 줄 알면 나머지는 전부 응용입니다.

### 6-4. 이제는 AI한테 시킵니다

사실 파일을 만들고, 내용을 적고, 수정하는 것 — 원래는 전부 직접 타이핑하는 일이었습니다. 코드 한 줄 한 줄을요.

이제는 다릅니다. 개발자도, 비개발자도 **AI한테 시킵니다.**

"이런 파일 만들어줘." "이 내용 바꿔줘." "이거 정리해줘."

말로 설명하면 Codex가 알아서 파일을 만들고, 내용을 채우고, 수정까지 해줍니다. 코드를 몰라도 됩니다.

앞으로 이 책에서 하는 일은 전부 이 방식입니다. **여러분은 시키는 사람, Codex는 일하는 사람.**

여러분은 이제 팀장처럼 일하면 됩니다. 내가 원하는 걸 잘 설명하고, 일을 시키고, 결과물이 오면 검수하고, 마음에 안 들면 피드백해서 다시 시키고. 이 사이클을 반복하는 겁니다.

코드를 직접 짜는 게 아니라, **의도를 전달하고, 결과를 판단하는 사람**이 되는 겁니다.

## 여기서 막혔나요?

**Q. `codex`라고 쳤는데 "command not found"가 나와요.**

터미널을 완전히 껐다가 다시 열어보세요. 설치 스크립트가 끝날 때 새 터미널 창이 자동으로 열렸을 텐데, 그 창에서 시도해 보세요. 그래도 안 되면 STEP 2의 설치 명령어를 다시 한번 실행해 보세요.

**Q. Windows에서 "실행 정책" 오류가 나요.**

PowerShell을 **관리자 권한**으로 열었는지 확인하세요. 그래도 안 되면 아래 명령어를 먼저 실행한 뒤 다시 시도해 보세요.
```
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Q. 매번 "허용하시겠습니까?"라고 물어봐서 귀찮아요.**

`dscodex`를 쓰세요. 묻지 않고 바로 실행합니다. 위에서 설명한 것처럼, 지정한 폴더 안에서만 작동하니까 안전합니다.

---

## 한 줄 정리

설치는 한 줄로 끝내고, VS Code를 열고, 터미널에서 Codex를 부른 뒤, "해줘"라고 말하면 실습은 시작됩니다.

여러분의 컴퓨터에는 이제 말을 알아듣는 조수가 앉아 있습니다.
