# [EP3] 읽기용 대본 — AI 작업 환경, 5분이면 끝나요 (설치 따라하기)

> 단계 1 "시작하기" 첫 영상. 설치 ~ 첫 실행까지 손잡고 가는 완성 대본. 약 10~12분.
> 톤: 친절·쉬움·완전 초보 배려. "몰라도 돼요, 천천히." 겁주기·하이프·과장 금지.
> 킬러 장면: 검은 창에 한 줄 → 세션이 시작되는 순간.
> docs 근거: getting-started/02-install, 05-terminal-vs-extension. 명령어는 docs 그대로, 지어내지 않음.
> `//` = 살짝 쉬는 지점. 그 외엔 자연스럽게 이어서.

## 1. 시작 — 오늘은 드디어 깔아봐요

지난 영상에서 우리가 이런 얘기 했었죠. //

챗GPT는 물어보는 상담 창구 같은 거고, 클로드 코드는 내 책상에서 같이 일하는 직원 같은 거다. //

그럼 그 "같이 일하는 직원"을, 대체 어떻게 내 컴퓨터로 데려오느냐. 오늘 그걸 해요. //

자리 하나 깔아주는 거예요. 그게 바로 '설치'고요. //

미리 말씀드리면, 진짜 5분이면 돼요. 우리가 할 건 딱 세 가지예요. 창 하나 열고, 한 줄 붙여넣고, 한 번 켜보기. 그게 다예요. 같이 천천히 갈게요.

## 2. 먼저, 안심부터 시켜드릴게요

본론 들어가기 전에, 제가 제일 하고 싶은 말부터요. //

많은 분들이 'AI 시작하기'에서 제일 먼저 무서워하시는 게 바로 이 설치예요. //

까만 창이 뜨고, 영어가 막 지나가고, "이거 잘못 누르면 컴퓨터 고장 나는 거 아냐?" 싶고. //

그 마음 너무 잘 알아요. 근데요, 그런 일 안 생겨요. //

오늘 우리가 하는 건, 그냥 **남이 다 만들어 놓은 한 줄을 복사해서 붙여넣는 것**뿐이에요. 내가 뭘 만들어내거나, 어려운 걸 외우는 게 전혀 아니에요. //

그리고 화면에 나오는 영어, 지금 하나도 몰라도 돼요. 천천히 따라만 오시면 돼요. 읽어야 할 건 제가 다 짚어드릴게요. //

자, 그럼 진짜 시작해 볼게요.

## 3. 1단계 — 검은 창(터미널) 열기

제일 먼저 할 일은, 창 하나를 여는 거예요. 이걸 '터미널'이라고 불러요. //

터미널이 뭐냐. 어렵게 생각하지 마세요. 그냥 **검은 창에 글자를 입력하는 프로그램**이에요. 그게 다예요. //

우리가 평소에 쓰는 메모장 같은 건데, 여기에 명령어를 적으면 컴퓨터가 그걸 듣고 움직여요. //

여는 방법은 컴퓨터에 따라 달라요. //

**윈도우 쓰시는 분.** 화면 왼쪽 아래 시작 버튼 누르고, `PowerShell`이라고 검색하세요. 그리고 그냥 누르지 말고, **'관리자 권한으로 실행'**을 눌러주세요. 이게 중요해요. 그냥 열면 나중에 설치가 중간에 막힐 수 있거든요. //

**맥 쓰시는 분.** 키보드에서 커맨드 키랑 스페이스바를 같이 누르세요. 그럼 검색창이 뜨는데, 거기다 `터미널`이라고 치고 엔터. //

자, 검은 창 하나 떴죠? // 지금 우리가 한 건, 그냥 **복사해서 붙여넣을 창 하나를 연 것**뿐이에요. 아직 아무것도 안 했어요. 겁먹을 거 하나도 없어요.

---

## 4. 2단계 — 딱 한 줄, 복사해서 붙여넣기

이제 진짜 설치예요. 그리고 이게 오늘의 핵심이에요. //

우리는 명령어를 딱 **한 줄** 붙여넣을 거예요. //

이 한 줄이 알아서, 클로드 코드가 돌아가는 데 필요한 걸 전부 깔아줘요. //

원래 이거, 사람이 직접 하면 프로그램을 여러 개 따로따로 설치해야 해서 30분도 넘게 걸려요. 그걸 한 줄로 묶어둔 거예요. //

화면 보시면, 본인 컴퓨터에 맞는 한 줄이 있어요. 이걸 복사하세요.

**윈도우는 이거예요.**

```powershell
irm https://raw.githubusercontent.com/rupy1014/base-install/main/window-install.ps1 | iex
```

**맥은 이거예요.**

```bash
curl -fsSL https://raw.githubusercontent.com/rupy1014/base-install/main/mac-install.sh | bash
```

이 글자들 무슨 뜻인지 하나도 몰라도 돼요. 그냥 본인 거 하나를 통째로 복사해서, 아까 연 검은 창에 붙여넣고, 엔터만 누르세요. //

자, 엔터 누르면요. // 화면에 글자가 막 올라가기 시작할 거예요. 뭔가 길게 설치되는 게 좌르륵 지나가요. //

이거 보고 놀라지 마세요. **정상이에요.** 컴퓨터가 지금 필요한 걸 하나씩 받아서 깔고 있는 거예요. //

여기서 제일 중요한 거 하나. **끝까지 기다리세요.** 중간에 멈춘 것처럼 보여도, 창 끄지 말고 그냥 두세요. 다 끝나면 멈춰요.

## 5. 에러가 나도, 진짜 괜찮아요 (초보 구조대)

자, 근데 솔직하게 말씀드릴게요. //

가끔 중간에 빨간 글씨가 뜨거나, 설치가 끝까지 안 가고 멈출 때가 있어요. //

처음 보면 "아 나 망했다, 역시 난 안 되나 봐" 싶죠. // 아니에요. 전혀 망한 거 아니에요. //

이럴 때 쓰는 마법의 방법이 있어요. 이거 오늘 딱 하나만 기억하셔도 돼요. //

**화면에 뜬 그 에러 문구를, 그대로 복사하세요.** 한 글자도 고치지 말고, 그냥 통째로요. //

그리고 그걸 저한테, 아니면 AI한테 그대로 붙여넣고 "이거 왜 이래?" 하고 물어보면 돼요. //

영어라서 무섭다고요? 안 읽으셔도 돼요. 읽을 필요가 없어요. 그냥 복사해서 넘기면, 그쪽이 알아서 무슨 문제인지 알려줘요. //

이게 사실 개발자들도 평생 쓰는 방법이에요. 에러는 혼나는 게 아니라, **그냥 단서**예요. "여기 이게 좀 안 맞아요" 하고 알려주는 쪽지 같은 거죠. //

그러니까 에러 떠도 당황하지 마세요. 복사, 붙여넣기, 물어보기. 끝.

---

## 6. 3단계 — 한 줄 치면, 세션이 시작돼요 (오늘의 킬러 장면)

설치가 다 끝났으면, 이제 진짜 켜볼 차례예요. //

검은 창에, 이렇게만 치세요.

```bash
claude
```

c, l, a, u, d, e. 여섯 글자. 그리고 엔터. //

자, 보세요. // 화면에 뭔가 뜨죠? 클로드가 인사를 하거나, 로그인하라거나, 뭔가 진행되는 게 보일 거예요. //

이 순간이에요. 방금 그 검은 창이, **AI랑 대화하는 작업실로 바뀐 거예요.** //

조금 전까지 아무것도 없던 까만 화면에, 한 줄 쳤더니 클로드가 깨어났죠. 이게 오늘 우리가 보려던 장면이에요. //

여기서 두 가지만 알려드릴게요. //

하나. 로그인 화면이나, Pro 결제 안내 같은 게 떠도 **놀라지 마세요.** 설치가 실패한 거 절대 아니에요. 설치는 이미 끝났고, 이제 "쓰려면 로그인하세요" 하고 안내가 뜬 것뿐이에요. //

둘. 테마 고르라거나, 뭔가 초기 설정을 물어볼 수도 있어요. 영어로요. 그냥 쓱 보고 아무거나 골라도 돼요. 나중에 다 바꿀 수 있어요. //

지금 이 단계에서 우리 목표는 딱 하나예요. **"설치가 됐구나, 켜지는구나"를 확인하는 것.** 그거만 됐으면 오늘 제일 큰 산은 넘은 거예요.

## 7. `claude`랑 `dsclaude`, 이건 뭐예요?

설치가 끝나면, `claude` 말고 `dsclaude`라는 것도 같이 깔려 있을 거예요. //

이거 제가 만들어둔 단축 명령어예요. 둘이 거의 같은데, 딱 하나 차이가 있어요. //

`claude`는, 파일을 고치기 전에 매번 "이거 고쳐도 돼요?" 하고 한 번씩 물어봐요. 처음 익힐 땐 안심되죠. //

`dsclaude`는, 그걸 안 묻고 바로 척척 해줘요. 그래서 더 빨라요. //

처음 시작하는 분이라면, 솔직히 저는 `dsclaude`를 추천해요. 클로드 쓰다 보면 자꾸 이것저것 확인을 요청하는데, 그게 은근히 귀찮거든요. 매번 엔터 안 눌러도 되니까 편해요. //

근데요, **지금 `dsclaude`가 안 돼도 전혀 괜찮아요.** 지금은 `claude`만 켜지면 충분해요. 이건 나중에 익숙해진 다음에 챙겨도 되는 거예요. 오늘은 그냥 "아, 이런 게 하나 더 있구나" 정도만 알고 넘어가세요.

## 8. 방금 뭐가 같이 깔린 거예요?

궁금하신 분들 있을 거예요. "그 한 줄이 대체 뭘 깐 거야?" //

크게 세 가지가 같이 깔렸어요. 이름만 가볍게 알고 가세요. 외울 필요 전혀 없어요. //

**첫째, Node.js.** 클로드 코드가 돌아가려면 필요한 기반이에요. 무대 바닥 같은 거라고 생각하세요. //

**둘째, Git.** 파일이 어떻게 바뀌었는지 기록을 남겨주는 도구예요. 이건 나중 영상에서 '게임 세이브'에 비유해서 제대로 다룰 거예요. 지금은 이름만요. //

**셋째, Claude Code.** 우리가 실제로 일을 시킬, 오늘의 주인공이에요. //

원래 이 세 개를 하나씩 따로 깔려면 머리 아프거든요. 근데 아까 그 한 줄이 순서대로 알아서 다 해줬어요. 그래서 우리가 편하게 넘어온 거예요.

## 9. VS Code로 쓰면 더 편해요 (터미널 vs 익스텐션)

여기까지 오셨으면 설치는 끝이에요. 마지막으로, 좀 더 편하게 쓰는 길 하나만 알려드릴게요. //

지금은 그냥 검은 터미널 창에서 `claude`를 쳤죠. 이걸 'VS Code'라는 프로그램 안에서도 똑같이 쓸 수 있어요. //

VS Code는, 쉽게 말하면 작업하기 좋은 큰 책상 같은 프로그램이에요. 그 안에서 클로드 코드를 부르는 길이 두 개 있어요. //

하나는, 아래쪽에 있는 까만 터미널 칸에 똑같이 `claude`라고 치기. //

하나는, 옆에 채팅 화면을 띄우는 '익스텐션'이라는 거예요. 별 모양 아이콘을 누르면 옆에 클로드랑 대화하는 창이 떠요. //

여기서 헷갈리지 마실 거 하나. **둘 다 똑같은 클로드예요.** 똑똑함은 차이가 1도 없어요. 다른 건 그냥 '생긴 거'뿐이에요. //

화면 보면서 마우스로 천천히 하고 싶으면, 익스텐션이 편해요. 코드 바뀔 때 빨강 초록으로 나란히 보여주고, 버튼만 누르면 적용되거든요. //

명령어 다 쓰고 기능 하나도 안 빠뜨리고 싶으면, 터미널이에요. 슬래시 명령어 같은 게 전부 다 되거든요. //

근데 사실 제일 많이들 쓰는 건요, **VS Code를 켜고, 그 안의 터미널에서 `claude` 치기**예요. 이게 제일 좋아요. 기능은 다 쓰면서, 코드 바뀌는 건 화면으로 보거든요. 양쪽 좋은 점만 가져가는 거죠. //

이것도 지금 다 안 외워도 돼요. "아, 나중엔 VS Code 안에서 쓰면 더 편하구나" 정도만요.

## 10. 마무리 + 다음 영상

자, 오늘 한 거 정리할게요. //

우리, 클로드 코드를 진짜로 깔았어요. 그리고 켜봤어요. //

세 가지였죠. 검은 창 열기, 한 줄 붙여넣기, `claude` 치기. // 그게 다였어요. 5분짜리, 맞죠? //

그리고 오늘 꼭 들고 가셨으면 하는 거 하나. **에러 나면 그 문구 그대로 복사해서 물어보기.** 이거 하나면 앞으로 뭐가 막혀도 빠져나올 수 있어요. //

혹시 오늘 설치하다 막히신 분 있어도 괜찮아요. 천천히 다시 해보시고, 그래도 안 되면 그 화면 그대로 들고 오세요. 같이 풀어요. //

다음 영상에서는요. 이제 '프로젝트'라는 말을 풀어볼 거예요. 다들 한 번씩 들어봤는데 정확히 뭔지는 아리송한 그 단어요. //

그리고 드디어, 클로드한테 첫 일을 시켜볼 거예요. 빈 폴더 하나에 한 줄 시켰더니, 진짜 파일이 딱 생기는 순간. // 그거 직접 보면 좀 신기하실 거예요. //

설치라는 제일 큰 산, 오늘 같이 넘었어요. 여기까지 오신 것만으로 이미 잘하고 계신 거예요. 다음 영상에서 첫 파일 만들러 가요.
