# [EP2] 읽기용 대본 — 챗GPT·클로드·클로드 코드, 뭐가 다른 거예요?

> "AI 입문 정주행" 2편. 완전 초보가 제일 먼저 헷갈리는 이름·종류 정리. 카메라 보고 처음부터 끝까지 읽는 완성 대본. 약 9~12분.
> 톤: 친절·쉬움·완전 초보 배려. "몰라도 돼요, 천천히." 겁주기·하이프·과장 금지. 비유로 풀어주기.
> docs 근거: getting-started/03-why-cli, claude-code-intro/01-model-choice.
> 경계: '일 시키는 법 / 신입사원 감각'은 EP5·EP6. 여기선 "뭐가 다른지"까지만.
> `//` = 살짝 쉬는 지점. 그 외엔 자연스럽게 이어서.

## 1. 시작 — 이름이 너무 많아서 헷갈리셨죠?

지난 영상에서, AI를 어떤 순서로 배우면 되는지 다섯 칸짜리 지도를 같이 그렸어요. 환경 만들기, 감 잡기, 자동화, 만들기, 보여주기. 기억나시죠? //

그 첫 칸 '환경 만들기'로 들어가기 직전에, 제가 가르치면서 제일 많이 받은 질문 하나를 먼저 풀고 갈게요. //

이런 거예요. //

"챗GPT는 들어봤는데, 클로드는 또 뭐예요?" //

"클로드랑 클로드 코드는 같은 거예요, 다른 거예요?" //

"GPT랑 챗GPT는 또 무슨 차이예요?" //

이름이 비슷비슷하게 막 쏟아지니까, 시작도 하기 전에 머리가 복잡해지죠. //

오늘은 딱 이거 하나만 할게요. 이 헷갈리는 이름들이 각각 뭔지, 그리고 뭐가 다른지. 그것만 정리하면, 다음부터 훨씬 마음이 편해지실 거예요.

---

## 2. 먼저, 이거 다 외울 필요 없어요

본론 들어가기 전에 한 가지만 안심시켜 드릴게요. //

오늘 나오는 이름들, 하나도 안 외우셔도 돼요. //

진짜예요. 시험 보는 거 아니거든요. //

이름이 헷갈리는 건 머리가 나빠서가 아니에요. 그냥 이 동네가 원래 이름을 너무 많이, 너무 빨리 만들어내서 그래요. 매년 새 이름이 나오고, 있던 이름도 자꾸 바뀌어요. 저도 다 못 외워요. //

그러니까 오늘은 '외우기'가 목표가 아니라, '큰 그림 한 장' 그리는 게 목표예요. //

큰 그림만 있으면, 나중에 모르는 이름이 튀어나와도 "아, 이건 이 칸에 들어가는 애구나" 하고 척 넣을 수 있거든요. 그거면 충분해요. 천천히 갈게요.

---

## 3. 회사 / 제품 / 모델, 세 칸으로 나눠보세요

자, 첫 번째 헷갈림부터요. "챗GPT랑 GPT가 뭐가 달라요?" //

이건요, 세 칸으로 나눠서 보면 한 번에 풀려요. **회사, 제품, 모델.** 이 세 칸이에요. //

쉽게 비유할게요. //

**회사**는 만드는 곳이에요. 물건을 만들어내는 제조사요. //

**제품**은 우리가 실제로 손에 들고 쓰는 거예요. 우리가 접속해서 쓰는 서비스 이름이요. //

**모델**은 그 제품 안에 들어 있는 엔진이에요. 겉에서는 잘 안 보이지만, 실제로 일을 해내는 속 알맹이요. //

자동차로 생각하면 쉬워요. 자동차를 만드는 회사가 있고, 우리가 타는 차 이름이 있고, 그 안에 엔진이 있잖아요. 딱 그 구조예요. //

이 틀로 아까 그 이름들을 넣어볼게요. //

챗GPT를 예로 들면. 만든 회사는 '오픈에이아이'예요. 우리가 접속해서 쓰는 제품 이름이 '챗GPT'고요. 그 챗GPT 안에서 실제로 답을 만들어내는 엔진이 'GPT'예요. //

그러니까 챗GPT랑 GPT가 헷갈렸던 이유가 여기 있어요. 하나는 우리가 쓰는 제품 이름이고, 하나는 그 속에 든 엔진 이름이었던 거예요. 같은 식구인데 자리가 다른 거죠. //

클로드도 똑같이 넣어볼게요. //

만든 회사는 '앤트로픽'이에요. 우리가 쓰는 제품 이름은 '클로드'고요. 그 안에 든 엔진, 그러니까 모델은 '오퍼스', '소네트', '하이쿠' 이런 이름들이에요. //

그래서 우리가 평소에 "나 챗GPT 써", "나 클로드 써" 할 때는요. 거의 다 '제품' 이름을 말하는 거예요. 그 속에 어떤 엔진이 돌아가는지는, 지금은 몰라도 전혀 상관없어요. //

엔진, 그러니까 모델을 뭘 고를지는 이 시리즈 뒤쪽 영상에서 따로 다룰 거예요. 지금은 "아, 회사가 있고, 제품이 있고, 그 안에 엔진이 있구나" 이 세 칸만 머리에 들어오면 100점이에요.

## 4. 챗봇은 상담원, 클로드 코드는 같이 일하는 직원

자, 이제 두 번째 헷갈림. 제일 중요한 거예요. //

"클로드는 알겠는데, 그럼 클로드 코드는 또 뭐예요? 클로드랑 다른 거예요?" //

네, 좀 달라요. 그리고 이 차이를 잡으면 오늘 영상의 절반은 끝나요. //

이렇게 생각해 보세요. //

우리가 흔히 쓰는 챗GPT나 클로드 같은 거 있죠. 채팅창에 질문을 타이핑하면 답을 주는 거. 이런 걸 보통 '챗봇'이라고 불러요. 대화하는 AI라는 뜻이에요. //

챗봇은 **상담 창구의 상담원** 같은 거예요. //

내가 뭘 물어보면 친절하게 답을 해줘요. "이 글 좀 요약해줘" 하면 요약해 주고, "메일 하나 써줘" 하면 써주고, "이거 표로 정리해줘" 하면 정리해 줘요. //

근데 딱 거기까지예요. 상담원은 창구 너머에 앉아서 '말로' 도와주는 사람이에요. 내 책상으로 건너와서 내 서랍을 직접 열고, 내 파일을 직접 꺼내서 고쳐주진 않아요. //

그게 챗봇이에요. 아주 똑똑한 상담원. 물어보면 답을 주지만, 내 컴퓨터 안으로 직접 들어와서 일하진 않아요. //

그럼 **클로드 코드**는요? //

클로드 코드는 그 상담원을, 아예 내 책상 옆자리에 앉혀놓은 거예요. //

내 컴퓨터 안에 있는 진짜 폴더, 진짜 파일들 있잖아요. 클로드 코드는 그걸 직접 열어보고, 새로 만들고, 고치고, 정리해요. 말로만 알려주는 게 아니라, 내 작업을 같이 손으로 해주는 거예요. //

그래서 저는 이렇게 비유해요. //

챗봇은 **창구 너머 상담원.** 물어보면 답해줘요. //

클로드 코드는 **내 책상에서 같이 일하는 직원.** 내 폴더 안에서 실제로 결과물을 만들어줘요. //

둘 다 같은 클로드라는 AI예요. 머리는 같아요. 근데 한쪽은 '대화'를 하고, 한쪽은 '내 폴더에서 일'을 해요. 그 자리 차이라고 보시면 딱 맞아요. //

참, 이 직원한테 일을 '어떻게' 시키는지는요. 조금 뒤 영상에서 제대로 다룰 거예요. 오늘은 "둘이 자리가 다르구나"까지만 알면 돼요. 거기까지만 가요.

## 5. 근데 클로드 코드는 왜 검은 창에서 써요?

여기서 많은 분들이 한 번 멈칫하세요. //

클로드 코드를 처음 켜면, 화면이 우리가 아는 그 예쁜 채팅 화면이 아니거든요. 글자만 빽빽한 검은 창이 떠요. //

"어우, 저 검은 창 뭐예요. 해커들이 쓰는 거 아니에요?" //

이 반응, 진짜 많아요. 그래서 짚고 갈게요. 겁먹으실 거 하나도 없어요. //

용어부터 천천히 풀게요. 딱 두 단어만요. //

그 검은 창, 그걸 **터미널**이라고 불러요. 그냥 '명령을 입력하는 창'이에요. 별거 아니에요. 컴퓨터한테 글로 말을 거는 창문이라고 보시면 돼요. //

그리고 그 창에 글자로 명령을 치는 '방식', 그걸 **씨엘아이**라고 해요. 영어 알파벳 C, L, I. 풀어 쓰면 '글자로 명령하는 방식'이라는 뜻이에요. //

정리하면 이래요. //

터미널은 **창**이에요. 검은 창문. //

씨엘아이는 **그 창에서 글자로 일하는 방식**이고요. //

클로드 코드는 **그 방식으로 내 파일을 다뤄주는 AI**예요. //

자, 그럼 진짜 궁금한 거. "예쁜 채팅 화면 놔두고, 왜 굳이 저 검은 창을 써요?" //

이유는 딱 한 줄이에요. //

**앱은 시작이 쉽고, 검은 창은 결과물을 끝까지 만들기 쉬워요.** //

조금만 더 풀어 드릴게요. 채팅 앱은 처음이 편해요. 브라우저 열고 질문 타이핑하면 답이 오니까요. 근데 거기서 더 나아가서, 내 폴더 안에서 진짜 결과물을 만들고, 그걸 계속 고치고 쌓아가는 일. 그건 검은 창 쪽이 훨씬 잘 맞아요. //

왜냐면 검은 창에서는 내 폴더 자체가 작업장이 되거든요. //

파일을 읽고, 새 파일을 만들고, 고치고, 그 상태를 계속 이어가요. 설명만 듣고 끝나는 게 아니라, 작업한 결과가 내 폴더 안에 차곡차곡 쌓여요. //

그리고 "이 문서 읽어줘, 요약본 만들어줘, 이 부분 고쳐줘" 이런 게 한 흐름으로 자연스럽게 이어져요. 말한 게 바로 실행으로 연결되는 거죠. //

그래서 우리가 이 채널에서 검은 창을 쓰는 거예요. 멋있어 보이려고가 절대 아니고요. //

겁내실 것도 없어요. 우리는 외울 명령어가 산더미인 그런 걸 배우는 게 아니에요. 그냥 "내 폴더 안에서 AI랑 같이 일한다", 이 감각 하나만 잡으면 돼요. 막상 해보면, 생각보다 안 어려워요. 이건 다음 영상에서 직접 같이 켜볼 거예요.

## 6. 그럼 나는 뭘 써야 하나요?

여기까지 들으면 이런 생각 드실 수 있어요. "그럼 챗GPT나 클로드 앱은 안 좋은 거예요? 검은 창만 쓰면 돼요?" //

아니요. 그거 아니에요. 오해하시면 안 돼요. //

둘 다 좋아요. 그냥 잘하는 일이 달라요. //

이렇게 나눠보세요. //

빠르게 뭔가 물어보고 답 받고 싶을 때. 글 초안 잡고, 아이디어 정리하고 싶을 때. 이럴 땐 챗GPT나 클로드 같은 **채팅 앱**이 편하고 좋아요. 시작이 제일 쉽거든요. //

반대로, 내 컴퓨터 폴더 안에서 진짜 결과물을 만들고 싶을 때. 파일을 만들고 고치고, 그걸 계속 이어서 관리하고 싶을 때. 이럴 땐 **클로드 코드**가 훨씬 강해요. //

그래서 사실 정답은 "둘 다 쓰면 돼요"예요. //

다만, 이 채널은 결국 여러분이 직접 뭔가를 '만들어서' 진짜 주소로 내보내는 데까지 가는 게 목표잖아요. 지난 영상 다섯 칸 지도 기억하시죠. 그 끝이 '내 걸 만들어서 보여주기'였어요. //

그 길은 클로드 코드, 그러니까 검은 창 쪽이 훨씬 잘 맞아요. 그래서 우리는 시작부터 클로드 코드로 가는 거예요. //

"무조건 검은 창이 더 좋다"가 아니에요. 우리가 가려는 목적지가 '직접 만들기'라서, 거기에 맞는 도구를 고른 것뿐이에요. //

이 차이만 알고 가셔도, 앞으로 영상 볼 때 "어, 왜 이걸 쓰지?" 하는 답답함이 확 줄어들 거예요.

## 7. 마무리 + 다음 영상

자, 오늘 거 한 번에 정리할게요. //

첫째, 이름은 세 칸이에요. **회사, 제품, 모델.** 회사가 만들고, 우리는 제품을 쓰고, 그 안엔 엔진 같은 모델이 들어 있어요. 챗GPT는 제품, GPT는 그 안의 엔진. 클로드는 제품, 오퍼스 같은 건 그 안의 모델. //

둘째, 챗봇은 **창구 너머 상담원**, 클로드 코드는 **내 책상에서 같이 일하는 직원.** 한쪽은 대화로 답해주고, 한쪽은 내 폴더에서 직접 일해줘요. //

셋째, 그 검은 창은 무서운 게 아니라 그냥 **명령 창**이고요. 우리는 진짜 결과물을 끝까지 만들 거라서 그걸 쓰는 거예요. //

이거 세 개만 챙기셨으면 오늘은 완벽해요. 다시 말하지만, 이름 하나하나는 안 외우셔도 돼요. //

자, 그럼 이제 말로만 듣는 건 그만하고요. //

다음 영상에서는, 드디어 지도 첫 칸. 그 작업 환경을 진짜로 깔아볼 거예요. //

"설치"라는 말부터 벌써 어렵게 들리시죠? 걱정 마세요. 손잡고 같이, 5분이면 끝나요. 에러 나면 어떻게 넘기는지까지 다 알려드릴게요. //

이름은 오늘로 충분히 정리됐어요. 다음엔 말로만 듣던 그 작업 환경을, 드디어 손으로 직접 깔아봐요. 손잡고 같이 가요.
