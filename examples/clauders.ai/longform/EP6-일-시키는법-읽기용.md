# [EP6] 읽기용 대본 — AI한테 일 제대로 시키는 법 (맥락 = 인수인계)

> "감 잡기" 단계 두 번째 영상. 카메라 보고 처음부터 끝까지 읽는 완성 대본. 약 12~14분.
> 핵심: AI가 헛소리하는 건 머리가 나빠서가 아니라 맥락을 안 줘서. 신입사원한테 인수인계하듯 — 뭘/왜/어떤 모양으로. 반복 설명은 CLAUDE.md로 고정.
> 톤: 친절·쉬움·완전 초보 배려. "몰라도 돼요, 천천히." 겁주기·하이프·과장 금지. 비유로 풀어주기.
> docs 근거: claude-code-intro/03-good-prompts, getting-started/04-create-project(CLAUDE.md).
> 연결: EP5(AI=똑똑한 신입사원) 한 줄 받기 → EP7(반복 업무를 명령어 하나로 — 자동화 입문) 예고.
> `//` = 살짝 쉬는 지점. 그 외엔 자연스럽게 이어서.

## 1. 시작 — 신입사원은 데려왔는데

지난 영상에서 우리가 이런 얘기를 했어요. //

AI는 마법사가 아니라, 아주 똑똑한 신입사원이라고요. 머리는 좋은데, 우리 사정은 아직 하나도 모르는 사람. //

그래서 한 번에 완벽한 게 안 나오고, 주고받으면서 맞춰가는 거다. 거기까지 감을 잡았어요. //

그런데 막상 일을 시켜보면, 이런 순간이 와요. //

분명히 똑똑하다는데, 결과물을 보면 "이게 뭐지?" 싶은 거예요. 내가 원한 거랑 영 딴판이고, 어디서 본 듯한 뻔한 답만 주고. //

그러면 이런 생각이 들죠. "어, 얘 생각보다 별론데?" 아니면 "역시 AI는 아직 멀었네." //

오늘은 바로 그 이야기예요. 그 신입사원이 헛소리하는 진짜 이유, 그리고 어떻게 말을 걸어야 일을 제대로 하는지. //

미리 말씀드리면, 이거 어려운 기술 아니에요. 우리가 사람한테 일 맡길 때 자연스럽게 하는 걸, AI한테도 똑같이 해주면 되는 거예요. 천천히 같이 가볼게요.

---

## 2. AI가 헛소리하는 건, 머리가 나빠서가 아니에요

자, 먼저 오해 하나부터 풀고 갈게요. //

AI가 엉뚱한 답을 줄 때, 우리는 보통 "얘가 멍청하네" 하고 생각해요. //

근데 대부분은 그게 아니에요. AI가 부족해서 일반적인 답을 주는 게 아니라, **내가 하는 일의 배경을 아직 모르기 때문에** 평균적인 답을 주는 거예요. //

이걸 신입사원으로 다시 생각해볼게요. //

오늘 출근한 신입한테, 아무 설명도 없이 "이번 주 안내 메일 좀 써줘" 하고 던졌다고 해봐요. //

이 친구가 머리가 나빠서 못 쓰는 게 아니에요. 우리 회사가 뭐 하는 데인지, 누구한테 보내는 메일인지, 뭘 꼭 알려야 하는지를 모르니까, 일단 어디서나 통할 법한 무난한 메일을 쓰는 거예요. //

AI도 똑같아요. //

AI한테 우리가 보내는 말, 이걸 '프롬프트'라고 부르는데요. // 어려운 말 아니에요. 그냥 **AI한테 시키는 메시지, 내가 거는 말** 정도로 생각하면 돼요. //

이 프롬프트에 내 일의 배경이 안 들어 있으면, AI는 평균적인 답을 줄 수밖에 없어요. 정보가 그것밖에 없으니까요. //

그러니까 결론은 간단해요. AI를 똑똑하게 만드는 게 아니라, **내 상황을 알려주는 게** 우리가 할 일이에요. //

이걸 한마디로 하면, 인수인계예요. 일 잘하는 신입한테 일을 넘길 때처럼, 배경을 넘겨주는 거죠.

---

## 3. 진짜 그런지, 한번 같이 볼게요

말로만 하면 와닿지 않으니까, 같은 요청을 두 번 해볼게요. 맥락 없을 때 한 번, 줬을 때 한 번. //

예시는 누구나 한 번쯤 해봤을 법한 걸로 가져올게요. 거래처에 보내는 안내 메일이요. //

먼저, 맥락 없이 이렇게만 시켜봐요. //

```text
추석 휴무 안내 메일 써줘.
```

이러면 AI는 답을 주긴 줘요. 그럴듯한 메일이 한 장 나와요. //

근데 열어보면, 어느 회사에 갖다 붙여도 될 것 같은 메일이에요. //

"안녕하세요, 고객님. 저희 회사는 이번 추석 연휴를 맞아..." 이런 식으로요. 회사 이름 들어갈 자리는 비어 있거나, AI가 아무 이름이나 지어 넣고. 우리가 진짜 알려야 할 게 뭔지는 AI가 모르니까, 그냥 일반적인 인사말로 채워요. //

이거 보고 "에이, 역시 안 되네" 하기 쉬워요. //

근데 AI 잘못이 아니에요. 우리가 정보를 안 줬으니까, AI는 빈칸을 평균값으로 채운 것뿐이에요. //

자, 그럼 이번엔 인수인계를 해볼게요. 뭐가 달라지는지 보세요.

---

## 4. 인수인계는 딱 세 가지면 돼요 — 뭘 / 왜 / 어떤 모양으로

맥락을 준다니까 막막하게 느껴질 수 있는데요. 외울 거 하나도 없어요. //

신입한테 일 넘길 때 자연스럽게 말하는 세 가지, 그게 전부예요. //

**첫째, 뭘 시키는 건지.** // 이건 다들 해요. "메일 써줘", "표 정리해줘." 근데 보통 여기서 끝내요. 그게 문제예요. //

**둘째, 왜 하는 건지, 그리고 지금 상황이 어떤지.** // 이 메일을 누구한테 보내는지, 뭘 꼭 알려야 하는지, 우리는 평소에 어떤 말투를 쓰는지. 신입한테라면 당연히 해줄 설명이에요. //

**셋째, 결과물이 어떤 모양이면 좋겠는지.** // 길게 말고 짧게, 첫 줄에 뭘 먼저 넣고, 표로 정리할지 줄글로 쓸지. 완성본의 모양을 미리 그려주는 거예요. //

이 세 개를 다시 한 줄로 묶으면 이래요. **뭘 / 왜 / 어떤 모양으로.** //

요거 하나만 기억하셔도 오늘 영상은 다 가져가신 거예요. 뭘 시키는지, 왜 하는지, 어떤 모양으로 받고 싶은지. //

이거 몰라도 돼요, 천천히. 처음엔 세 개 다 못 챙겨도 괜찮아요. 둘째 칸, 그러니까 '왜·누구한테' 한 줄만 더 붙여도 결과가 확 달라지거든요. 거기서부터 늘려가면 돼요.

---

## 5. 같은 요청, 이번엔 맥락을 줘볼게요

자, 아까 그 추석 휴무 메일을 다시 시켜볼게요. 이번엔 세 가지를 넣어서요. //

```text
거래처에 보낼 추석 휴무 안내 메일을 써줘.

맥락:
- 나는 작은 식자재 유통 회사에서 일해.
- 이 메일은 우리랑 거래하는 식당 사장님들한테 보낼 거야.
- 이번에 꼭 알릴 건, 추석 연휴 동안 배송이 멈춘다는 거야.
- 우리는 딱딱한 공문체보다, 정중하지만 친근한 말투를 써.

이런 모양이면 좋겠어:
- 첫 줄에 휴무 기간을 바로 알려줘.
- 그다음에 주문은 언제까지 넣어야 하는지 안내해줘.
- 너무 길지 않게, 다섯 문장 안쪽으로.
```

자, 길어 보이죠? 근데 잘 보면 별거 없어요. //

윗부분은 그냥 신입한테 할 설명이에요. 우리 회사가 뭐 하는 덴지, 누구한테 보내는지, 뭘 꼭 알려야 하는지, 말투는 어떤지. //

아랫부분은 완성본의 모양이에요. 첫 줄엔 뭐, 그다음엔 뭐, 길이는 어느 정도. //

이렇게 주면 결과가 완전히 달라져요. //

이번엔 식당 사장님한테 보내는, 우리 회사 말투로 된, 휴무 기간이 첫 줄에 딱 박힌 짧은 메일이 나와요. 빈칸을 평균값으로 채운 게 아니라, 내 상황에 맞춰 쓴 거예요. //

같은 AI, 같은 요청이에요. 달라진 건 딱 하나, **내가 배경을 넘겨줬다는 것.** //

그래서 프롬프트를 잘 쓴다는 건, 무슨 마법 주문을 외우는 게 아니에요. 정해진 공식이 있는 것도 아니고요. //

그냥 **내 일을 알아들을 수 있게 맥락을 넘기는 것.** 그게 다예요.

## 6. 복붙용 — 이 틀 하나만 옆에 두세요

자, 이제 따라 쓰실 수 있게 틀을 하나 드릴게요. 복사해서 쓰시면 돼요. //

빈칸만 본인 상황으로 바꾸면 끝이에요. //

```text
[무슨 일인지 한 줄] 을(를) 해줘.

맥락:
- 나는 ___ 일을 해. (내가 누군지, 무슨 일을 하는지)
- 이건 ___ 한테 줄 거야. (누가 볼 결과물인지)
- 이번에 제일 중요한 건 ___ 야. (꼭 들어가야 할 핵심)
- 우리는 ___ 말투를 써. (좋아하는/싫어하는 표현)

이런 모양이면 좋겠어:
- 첫 줄에 ___ 를 먼저 넣어줘.
- ___ 는 표로(또는 줄글로) 정리해줘.
- 길이는 ___ 정도로.
```

이게 끝이에요. //

다시 보면 결국 아까 그 세 칸이에요. 맨 윗줄은 '뭘', 맥락 칸은 '왜·누구한테·어떤 상황', 모양 칸은 '어떤 모양으로'. //

이거 외우지 마세요. 외울 필요 없어요. 그냥 메모장에 복사해두고, 일 시킬 때마다 빈칸만 채우면 돼요. //

그리고 한 가지만 더요. 이 틀, 처음부터 다 채우려고 끙끙대지 마세요. //

회사 양식이 있거나 예전에 잘 나온 결과물이 있으면, 그걸 보여주면서 "이런 식으로 써줘" 하는 게 설명 열 줄보다 나아요. // 좋은 샘플 하나가 긴 설명을 이겨요. //

그래도 마음에 안 들면요? 그게 실패가 아니에요. //

"여기는 우리 방식이랑 다른데, 이렇게 바꿔줘" 하고 한 번 더 알려주는 것까지가 일 시키기예요. 신입이 가져온 초안 보고 빨간펜 들듯이, 그렇게 주고받으면 돼요.

## 7. 근데 매번 이렇게 쓰긴 귀찮잖아요

여기까지 오면 이런 생각이 들 거예요. //

"좋은 건 알겠는데, 일 시킬 때마다 매번 이 맥락을 다 써야 해? 그럴 거면 그냥 내가 하지." //

맞아요. 그 마음 당연해요. //

메일 쓸 때도 우리 회사가 어떤 덴지 설명하고, 표 정리할 때도 또 설명하고, 매번 같은 말을 반복하면 진짜 지쳐요. //

그래서 좋은 방법이 있어요. //

한두 번 하는 설명은 그냥 프롬프트에 넣으면 돼요. 근데 **계속 반복되는 설명**, 그러니까 "나는 식자재 유통 회사야", "정중하지만 친근하게 써", "없는 내용 지어내지 마" 이런 거요. //

이건 매번 입력할 게 아니라, **한 번 적어두고 고정하는** 거예요. //

신입사원한테 매일 아침 "우리 회사는 한국어로 문서 써", "거래처엔 존댓말 써" 이걸 반복하느니, 그냥 **수칙 한 장**을 책상에 붙여주는 거랑 똑같아요. //

AI 세계에서 그 수칙 한 장이, 바로 `CLAUDE.md`라는 파일이에요. //

이름이 좀 낯설죠? 풀어볼게요. // 그냥 프로젝트 폴더 안에 두는 **메모 파일** 하나예요. //

뒤에 붙은 점 엠디, `.md`는 그냥 메모장 같은 글자 파일이라는 뜻이에요. 사람도 읽기 쉽고 AI도 읽기 쉬운 형식. 깊게 안 들어가도 돼요. //

중요한 건 이거예요. 이 파일을 프로젝트 폴더에 딱 넣어두면, **AI가 일을 시작할 때마다 이 메모를 제일 먼저 읽어요.** //

그래서 매번 "나는 식자재 회사고, 거래처는 식당이고, 말투는 이렇고…"를 다시 안 적어도, AI가 이미 알고 시작하는 거예요. 한 번 적어두면 계속 따라오는 거죠.

## 8. 그럼 거기엔 뭘 적냐

이름 들으면 뭔가 거창할 것 같은데, 전혀 아니에요. //

처음엔 네다섯 줄이면 충분해요. 아까 그 인수인계 세 가지를, 매번 반복되는 것만 골라서 적어두면 돼요. //

예를 들면 이런 식이에요. //

```text
# 내 프로젝트 규칙

## 기본 맥락
- 나는 작은 식자재 유통 회사를 해.
- 거래처(식당 사장님)에게 보낼 안내문과 메일을 자주 써.

## 말투
- 정중하지만 친근하게. 딱딱한 공문체는 피해줘.

## 작업 방식
- 안내문은 다섯 문장 안쪽으로 짧게.
- 다 쓰면 어떤 점을 신경 썼는지 한 줄로 알려줘.

## 금지 사항
- 없는 내용은 지어내지 마. 날짜나 숫자는 내가 준 것만 써.
```

보세요. 어려운 거 하나도 없죠? // 내가 누군지, 어떤 말투를 쓰는지, 어떻게 일해주면 좋은지, 하지 말아야 할 게 뭔지. 딱 그것만요. //

이것도 직접 다 안 쳐도 돼요. AI한테 "이런 내용으로 `CLAUDE.md` 만들어줘" 하고 말로 시켜도 만들어줘요. //

그리고 처음부터 완벽하게 채우려고 하지 마세요. //

여기서 제일 마음 편한 얘기 하나 할게요. // **파일이 있다는 것 자체가 일단 1차 완료예요.** //

처음엔 세 줄짜리여도 괜찮아요. 일을 시키다가 "어, 이 말을 또 하고 있네?" 싶은 게 보이면, 그때 한 줄씩 추가하면 돼요. //

그렇게 한 달쯤 쓰다 보면, 내 일을 알아듣는 작업 공간이 저절로 만들어져요. 거창하게 시작 안 해도 돼요.

## 9. 마무리 + 다음 영상

자, 오늘 거 정리할게요. //

AI가 헛소리하는 건 머리가 나빠서가 아니라, 내 사정을 몰라서예요. 그러니까 우리가 할 일은 AI를 똑똑하게 만드는 게 아니라, **배경을 넘겨주는 것.** //

넘겨줄 땐 세 가지만요. 뭘 시키는지, 왜 하는지, 어떤 모양으로 받고 싶은지. //

그리고 매번 반복되는 설명은, `CLAUDE.md`라는 메모 한 장에 적어두면 AI가 알아서 챙겨 읽어요. //

오늘도 보기만 하면 안 바뀌어요. 영상 끄고 나면, 평소에 AI한테 시키던 거 아무거나 하나 골라서, '왜·누구한테' 한 줄만 더 붙여서 다시 시켜보세요. 결과가 달라지는 거 직접 한 번 느껴보시는 게 제일 빨라요. //

자, 그런데요. 여기까지 오면 이런 게 보이기 시작해요. //

매주 똑같이 시키는 일, 매번 비슷하게 넘기는 인수인계. "이거 매번 하지 말고, 그냥 한 방에 안 되나?" //

돼요. 다음 영상에서 그걸 해볼 거예요. 제목은 "반복 업무를 명령어 하나로 — 자동화 입문"이에요. 매번 길게 시키던 걸, 짧은 명령어 하나로 바꾸는 거요. //

이거 보시면 다들 "오?" 하세요. 다음 영상에서 같이 해봐요. //

맥락 한 줄 더 얹는 습관, 이게 오늘 챙겨가실 진짜 선물이에요. 다음엔 그 반복을 명령어 하나로 줄여보는, 재밌는 걸 해볼게요. 기대하셔도 좋아요.
