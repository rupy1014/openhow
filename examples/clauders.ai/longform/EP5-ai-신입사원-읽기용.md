# [EP5] 읽기용 대본 — AI는 똑똑한 신입사원이에요 (다루는 감)

> 단계 2 "감 잡기" 첫 영상. AI를 어떻게 대해야 하는지 멘탈모델을 잡아주는 편. 카메라 보고 처음부터 끝까지 읽는 완성 대본. 약 10~13분.
> 톤: 친절·쉬움·완전 초보 배려. "몰라도 돼요, 천천히." 겁주기·하이프·과장·"A가 아니라 B"·사기훅·날조 금지. 비유로 풀어주기.
> docs 근거: claude-code-intro/01-model-choice, 02-direction.
> 경계: '맥락 주는 법/인수인계'는 EP6 본편 — 여기선 '감·마음가짐'까지만. 챗봇 vs 클로드 코드 도구 차이는 EP2가 했으니 반복 안 함.
> `//` = 살짝 쉬는 지점. 그 외엔 자연스럽게 이어서.

## 1. 시작 — 첫 파일은 만들었는데, 그래서 이걸 어떻게 대하죠?

지난 영상에서 우리, 빈 폴더 하나 놓고 AI한테 한 줄 시켜서 파일을 딱 만들어봤죠. //

"어? 진짜 만들어지네?" 그 순간, 저는 그게 제일 중요한 첫걸음이라고 생각해요. //

그런데 거기서 딱 멈춰서, 이런 생각 드신 분 많을 거예요. //

"그래서… 이걸 앞으로 어떻게 대해야 하는 거지?" //

뭘 시켜야 할지도 모르겠고, 어떻게 말해야 잘 알아듣는지도 모르겠고. 괜히 어려운 거 시켰다가 이상한 답 나오면 어쩌나 싶고요. //

오늘은 그 막막함을 풀어드릴게요. AI를 머릿속에 어떻게 그려두면 편한지, 그 '감'을 잡는 시간이에요. //

이거 하나만 잡아두면, 앞으로 AI랑 일하는 게 훨씬 마음 편해질 거예요.

---

## 2. AI는 아주 똑똑한 신입사원이에요

오늘 딱 하나만 가져가셔도 돼요. 이거예요. //

**AI는, 우리 회사에 막 들어온 아주 똑똑한 신입사원이에요.** //

이 한 문장만 머릿속에 두면, 나머지는 자연스럽게 따라와요. //

상상을 한번 해볼게요. //

어느 날 우리 사무실에 신입사원 한 명이 들어왔어요. 그런데 이력서를 보니 좀 대단해요. 공부도 엄청 많이 했고, 머리는 진짜 좋아요. 박사급이라고 해도 될 정도예요. //

글도 잘 쓰고, 자료 정리도 빠르고, 복잡한 것도 척척 이해해요. 어려운 영어 문서를 줘도 술술 읽고요. //

능력만 보면, 진짜 일 잘하게 생긴 사람이 들어온 거예요. //

그런데 말이죠. 이 친구한테 딱 하나, 없는 게 있어요. //

오늘이 첫 출근이라는 거예요.

---

## 3. 실력은 박사급인데, 우리 사정은 백지예요

이 신입사원, 능력은 박사급인데 우리 회사 사정은 하나도 몰라요. //

생각해보면 당연하죠. 오늘 처음 왔으니까요. //

이 친구는 이런 걸 몰라요. //

우리 회사가 정확히 뭘 하는 곳인지. 내가 어떤 일을 맡고 있는지. 내가 뭘 중요하게 생각하는지. 보고서를 어떤 모양으로 좋아하는지. 우리 팀이 평소에 어떤 식으로 일해왔는지. //

이게 다 백지예요. //

그래서 첫날부터 "알아서 잘 좀 해놔" 하고 툭 던지면, 이 친구가 알아서 할 수가 없어요. 능력이 없어서가 아니라, 우리 사정을 아직 모르니까요. //

AI가 딱 이래요. //

실력은 박사급인데, 내 맥락은 제로. //

그러니까 가끔 AI가 엉뚱한 답을 내놔도, 너무 실망하지 마세요. 그건 보통 이 친구가 멍청해서가 아니라, 우리 사정을 아직 못 들어서예요. //

이 감각 하나가, 앞으로 진짜 많은 걸 편하게 만들어줘요.

---

## 4. 가끔은 앵무새 같기도 해요 (그래서 확인은 해줘요)

신입사원 비유에 딱 하나만 더 얹을게요. //

이 똑똑한 친구, 가끔은 앵무새 같은 면도 있어요. //

무슨 말이냐면요. AI는 세상에 있는 엄청나게 많은 글을 보고 배운 친구예요. 그래서 말을 참 그럴듯하게, 자신 있게 잘해요. //

그런데 그렇게 자신 있게 말한다고 해서, 그게 항상 100% 맞는 건 아니에요. //

회사에도 가끔 그런 신입 있잖아요. 너무 당당하게 말해서 "오, 맞나 보다" 했는데, 나중에 보니 살짝 틀렸던 거. 나쁜 뜻이 아니라, 본인은 정말 맞다고 생각하고 말한 거예요. //

AI도 비슷해요. 아주 그럴듯하게 말하는데, 사실이 아닐 때가 종종 있어요. //

그래서 우리가 할 일은 딱 하나예요. 중요한 건 한 번 확인해주는 거. //

이거 어렵게 들리지만, 별거 아니에요. 사람이 시킨 일도 결과물은 한번 훑어보잖아요. AI도 똑같이, 받은 걸 한번 슥 봐주면 돼요. //

겁먹을 일은 전혀 아니에요. "이 친구는 똑똑하지만, 가끔 틀릴 수도 있으니 내가 한번 봐준다." 딱 이 정도 마음이면 충분해요.

---

## 5. 첫날엔 작은 일부터 툭툭 던져보세요

자, 그럼 이 신입사원이랑 어떻게 친해지냐. //

방법은 회사에서랑 똑같아요. //

신입이 첫 출근한 날, 큰 프로젝트를 통째로 맡기진 않잖아요. 작은 일부터 시켜보죠. "이것 좀 정리해줄래?" "이거 한번 찾아봐줄래?" //

그러면서 자연스럽게 감을 잡아요. "아, 이 친구 이런 건 잘하네. 이런 건 내가 한 번 더 봐줘야겠네." //

AI도 똑같이 하면 돼요. 첫날엔 거창한 거 말고, 작은 일부터 이것저것 툭툭 던져보는 거예요. //

예를 들면 이런 거요. //

"이 폴더에 뭐가 들어 있는지 설명해줄래?" //

"이 문장 좀 더 자연스럽게 바꿔줄 수 있어?" //

"이 긴 글, 세 줄로 요약해줄래?" //

"오늘 할 일 목록 좀 깔끔하게 정리해줘." //

여기서 핵심이 하나 있어요. //

이때는 멋진 결과물을 뽑는 게 목적이 아니에요. 이 친구가 어디까지 해주는지, 어떤 식으로 답하는지, 그 감을 잡는 게 목적이에요. //

이렇게 툭툭 던지다 보면, 신기하게 이런 게 보이기 시작해요. //

"아, '초보자도 알게' 라고 하면 설명이 쉬워지는구나." //

"아, '짧게' 라고 하면 답이 확 줄어드는구나." //

"아, 마음에 안 드는 부분을 콕 집어 말하면, 바로 고쳐주는구나." //

이게 바로 '감'이에요. 책으로 외우는 게 아니라, 직접 던져보면서 몸으로 붙는 거예요.

---

## 6. 좋은 결과는 한 번에 안 나와요 — 주고받는 거예요

여기서 초보분들이 제일 많이 오해하는 게 하나 있어요. 이거 풀고 갈게요. //

"AI한테 시켰는데 한 번에 마음에 쏙 들게 안 나왔어. 역시 AI 별로네." //

아니에요. 그게 원래 정상이에요. //

생각해보세요. 신입사원한테 보고서 처음 시켰을 때, 한 번에 완벽하게 가져오던가요? //

보통은 가져온 걸 보고 이러죠. "오, 좋은데? 근데 이 부분은 좀 더 자세히. 그리고 이건 빼고." //

그렇게 한두 번 주고받으면, 점점 내가 원하던 모양에 가까워져요. //

AI도 똑같아요. 한 번에 완성되는 게 아니라, 같이 주고받으면서 만들어가는 거예요. //

받은 게 좀 별로다 싶으면, 그냥 솔직하게 이어서 말하면 돼요. //

"좋아. 근데 이건 너무 딱딱해. 좀 더 친근하게 바꿔줘." //

"이 부분은 마음에 들어. 근데 여기는 더 쉽게 가자." //

"방금 그건 내 상황이랑 안 맞아. 다시 해줄래?" //

이렇게 말한다고 AI가 기분 상하지 않아요. 오히려 이렇게 콕콕 짚어줄수록 결과가 좋아져요. //

그러니까 한 번에 안 나왔다고 "내가 못하나" 하고 위축되지 마세요. 주고받는 게 원래 정상이고, 그게 AI를 잘 쓰는 사람들의 진짜 모습이에요.

---

## 7. 아 맞다, 모델 고민은 일단 접어두세요

여기까지 들으면, 꼭 누가 이렇게 물어봐요. //

"근데 AI 모델이 여러 개라던데요? 뭐 골라야 돼요?" //

이 얘기, 잠깐만 하고 넘어갈게요. 몰라도 되는 거니까 편하게 들으세요. //

먼저 '모델'이 뭔지부터요. 쉽게 말하면, AI 안에서 실제로 답을 만들어내는 엔진 같은 거예요. //

그리고 이 엔진이 종류가 좀 있어요. 더 똑똑하고 신중한 엔진이 있고, 더 빠르고 가벼운 엔진이 있고요. //

이름까지 외울 필요는 전혀 없어요. 그냥 "성능이 다른 엔진이 몇 개 있구나" 정도면 충분해요. //

자, 그래서 초보분들은 어떻게 하면 되냐. 답은 아주 단순해요. //

**그냥 제일 똑똑한 걸로 하나 골라서 시작하세요.** //

이유가 있어요. //

처음엔 결과가 이상하게 나왔을 때, 이게 내가 말을 잘 못해서 그런 건지, 아니면 엔진이 약해서 그런 건지 구분이 안 돼요. //

그런데 제일 똑똑한 걸로 시작하면, 그 헷갈림 하나가 딱 사라져요. "엔진 탓은 아니구나, 내 설명을 더 챙기면 되겠구나." 이렇게 깔끔해지는 거예요. //

비싼 거 무조건 쓰자는 얘기가 아니에요. 초보 단계에서 헷갈릴 거리를 하나 줄이자는 거예요. //

나중에 익숙해지면, 그때 가벼운 거랑 똑똑한 거를 일에 따라 나눠 쓰면 돼요. 그건 한참 뒤의 일이에요. //

지금은 딱 이거 하나만요. "초보는 제일 똑똑한 걸로 시작한다." 끝이에요.

## 8. 그래서, 어떤 마음으로 대하면 되냐면요

오늘 얘기를 마음가짐 한 줄로 정리해볼게요. //

AI를 마법 상자처럼 보면, 자꾸 실망하게 돼요. 버튼 누르면 완성품 나오는 게 아니거든요. //

대신 이렇게 보세요. //

**내 옆자리에 앉은, 아주 똑똑한 신입사원.** //

능력은 충분한데 우리 사정은 아직 모르는 친구. 작은 일부터 같이 해보면서 손발을 맞춰가는 친구. 한 번에 완벽하진 않아도, 주고받다 보면 점점 좋아지는 친구. //

이 마음으로 대하면, AI가 갑자기 편해져요. //

이상한 답이 나와도 "에이 별로네" 하고 창 닫는 게 아니라, "아 내가 이건 말 안 했구나" 하면서 한 번 더 말해보게 되거든요. //

그 한 번 더가, 진짜 실력이 붙는 순간이에요. //

오늘 영상 다 보시면, 딱 하나만 해보세요. 거창한 거 말고요. //

AI한테 작은 일 하나, 가볍게 툭 던져보세요. "오늘 할 일 정리해줘"도 좋고, "이 문장 자연스럽게 바꿔줘"도 좋아요. //

그리고 마음에 안 들면, 한 번 더 말 걸어보세요. 그 주고받는 느낌을 한 번만 경험해보시면, 오늘 얘기가 확 와닿을 거예요.

## 9. 마무리 + 다음 영상

자, 오늘 거 정리할게요. //

AI는 아주 똑똑한 신입사원이에요. 실력은 박사급인데, 우리 사정은 아직 백지인 친구. //

그러니까 첫날엔 작은 일부터 툭툭 던져보면서 감을 잡고, 한 번에 안 나와도 주고받으면서 같이 만들어가면 돼요. //

모델 고민은 접어두고, 일단 제일 똑똑한 걸로 시작. //

여기까지가 'AI를 어떻게 대할까' 하는 마음가짐이었어요. //

그런데 한 가지, 오늘 계속 걸리는 게 있었죠. "우리 사정을 모른다"는 거. //

그럼 그 사정을, 이 신입사원한테 어떻게 알려주면 좋을까요? //

다음 영상이 바로 그 얘기예요. AI한테 일을 제대로 시키는 법. //

회사로 치면 인수인계 같은 거예요. 똑같은 일을 시켜도, 우리 사정을 잘 넘겨준 신입사원은 결과가 확 달라지거든요. //

그 '제대로 시키는 법'을, 다음 영상에서 손에 잡히게 풀어드릴게요. //

오늘은 기술 하나 없이, 마음가짐만 챙기는 날이었어요. 그 한 끗이 앞으로 AI랑 일하는 걸 통째로 편하게 만들어줄 거예요. 다음 영상에서 또 만나요.
