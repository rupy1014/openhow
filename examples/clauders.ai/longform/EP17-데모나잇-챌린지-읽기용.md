# [EP17] 읽기용 대본 — 만든 거 사람들 앞에 선보이기 (데모나잇) + 다음은 챌린지 〔시즌1 마지막〕

> 시즌1 정주행의 마지막 영상. 시즌 전체를 닫고, 유일하게 챌린지를 담백하게 안내하는 지점. 카메라 보고 처음부터 끝까지 읽는 완성 대본. 약 10~12분.
> 톤: 친절·따뜻·완전 초보 배려. "몰라도 돼요, 천천히." 겁주기·하이프·과장·노골적 판매(가격·"지금 결제") 금지. 챌린지는 담백하게 딱 1회만.

## 1. 시작 — 여기까지 온 거, 진짜 대단해요

자, 드디어 시즌1 마지막 영상이에요. //

지난 영상까지 우리가 뭘 했는지 한번 떠올려볼게요. //

AI 작업 환경을 만들고, AI한테 일 시키는 감을 잡고, 명령어 한 줄로 자동화를 맛보고, 작은 서비스를 직접 만들어서 진짜 주소로 배포까지 했어요. //

바로 직전 영상에서는, 만든 걸 사람들한테 알리고 첫 천 원을 받아보는 것까지 갔고요. //

혹시 지금 영상으로만 쭉 따라온 분도 계실 거고, 진짜로 손으로 하나씩 해보신 분도 계실 거예요. 어느 쪽이든요. //

여기 마지막 영상까지 온 것만으로, 저는 진심으로 박수 쳐드리고 싶어요. //

오늘은 두 가지만 할게요. 첫째, 만든 걸 사람들 앞에서 선보이는 '데모나잇'이 뭔지. 둘째, 여기까지 혼자 온 당신한테 제가 꼭 하고 싶은 말. //

마지막이니까, 더 천천히 갈게요. 편하게 들어주세요.

## 2. 시즌의 마지막 칸은 '보여주기'예요

EP1 기억하시나요? 제가 다섯 칸을 그려드렸잖아요. //

환경 만들기, 감 잡기, 자동화, 만들기, 그리고 마지막이 '보여주기'였어요. //

오늘이 바로 그 마지막 칸이에요. //

만들기까지는 사실 나랑 AI, 둘이서 한 일이에요. 근데 마지막 칸은 좀 달라요. 내가 만든 걸 다른 사람들 앞에 꺼내놓는 거거든요. //

이걸 '데모나잇'이라고 불러요. 데모, 그러니까 시연을 하는 밤이라는 뜻이에요. //

이름은 거창한데, 겁먹을 거 하나도 없어요. 천천히 풀어드릴게요.

## 3. 데모나잇이 정확히 뭐냐면요

데모나잇은요, 한마디로 작은 축제예요. //

내가 어떤 사람을 위해, 어떤 문제를 풀고 싶었고, 그래서 뭘 만들었는지. 그걸 사람들 앞에서 한 5분 동안 보여주는 자리예요. //

여기서 제일 먼저 안심시켜드릴게요. //

**완성을 못 했어도 괜찮아요.** //

"저는 이런 문제를 이렇게 풀고 싶었어요. 여기까지 만들어봤고요. 다음엔 이렇게 더 해보려고요." 딱 이만큼만 말해도 충분해요. //

중요한 건 결과물이 얼마나 완벽하냐가 아니에요. 사람들 앞에서 내 걸 5분 동안 말해보는 그 경험, 그 자체예요. //

왜 이게 그렇게 중요하냐면요. //

혼자 만들고 끝나면, 그냥 "나 AI로 뭐 하나 만들어봤어"에서 멈춰요. //

근데 사람들 앞에서 한번 말해보면, 그게 "내가 만든 걸 사람들한테 선보였다"로 바뀌어요. 이 둘은 느낌이 완전히 달라요. //

그리고 이렇게 5분 안에 내 문제와 해결책을 말하는 연습은요, 나중에 어디 가서 내 일을 소개할 때도 그대로 써먹게 돼요. 한번 해두면 두고두고 남는 경험이에요.

## 4. 5분 안에 뭘 말하냐면요 (문제 → 보여주기 → 부탁)

자, 그럼 5분 동안 대체 뭘 말하느냐. //

복잡하게 생각 안 해도 돼요. 딱 세 덩어리만 기억하시면 돼요. //

**첫째, 문제.** 내가 누구를 위해, 무슨 문제를 풀려고 했는지. //

**둘째, 보여주기.** 그래서 만든 걸 화면으로 직접 보여주는 거예요. //

**셋째, 부탁.** 앞으로 어떻게 더 할 거고, 듣는 분들한테 뭘 부탁하고 싶은지. //

영어로는 이걸 프라블럼, 데모, 애스크라고 불러요. 문제, 보여주기, 부탁. 이 영어 단어는 몰라도 전혀 상관없어요. 그냥 순서만 기억하시면 돼요. //

예를 하나 들어볼게요. 동네 카페 사장님을 위한 '단골노트'라는 앱을 만들었다고 쳐요. //

먼저 문제를 말해요. "동네 카페 사장님들은 단골손님 얼굴이랑 취향을 머릿속에만 기억해요. 근데 한두 달만 지나면 잊어버려요." //

그다음 보여줘요. "그래서 손님을 등록하고, 방문 기록이랑 취향을 한 줄로 메모하는 앱을 만들었어요." 하면서 실제 화면을 띄워요. //

마지막에 부탁해요. "다음엔 단골손님한테 안부 문자 보내는 기능을 붙여보려고요. 써보시고 의견 주시면 정말 감사하겠습니다." //

시간은 대충 이렇게 나눠요. 문제까지 1분 반, 직접 보여주는 데 2분 반, 마지막 부탁에 1분. 합쳐서 5분. //

그리고 발표가 끝났을 때, 듣던 사람이 내 걸 '한 문장으로' 말할 수 있으면 성공이에요. //

"쟤 그냥 AI로 뭐 만들었대"가 아니라, "동네 카페 사장님이 단골 안 잊어버리게 도와주는 앱"이라고요. 이렇게 한 문장으로 남으면, 그 5분은 잘한 거예요.

## 5. 화면이 멈추면 어떡해요? (백업 영상)

여기서 초보분들이 제일 걱정하는 거 하나 짚고 갈게요. //

"발표 중에 내가 만든 거 보여주려고 눌렀는데, 안 돌아가면 어떡해요?" //

이거, 진짜 자주 있는 일이에요. 그러니까 미리 대비만 해두면 돼요. 겁낼 일 전혀 아니에요. //

방법은 이래요. //

**먼저, 발표 전에 내 화면을 한 번 녹화해두세요.** 잘 돌아가는 모습을 미리 영상으로 찍어두는 거예요. 이게 '백업 영상'이에요. //

발표하다가 화면이 멈추면요. 일단 10초 정도만 기다려봐요. 인터넷이 잠깐 느린 거면 대부분 이 안에 풀려요. //

10초 넘어가도 안 되면, 당황하지 말고 한마디 하세요. "아, 잠깐만요. 미리 녹화해둔 영상으로 보여드릴게요." //

그리고 아까 찍어둔 백업 영상을 틀면 돼요. 끝나면 다시 고치려고 끙끙대지 말고, 바로 마지막 '부탁' 부분으로 넘어가면 되고요. //

또 하나 꿀팁. 로그인 화면 같은 데서 멈추는 일이 많거든요. 그래서 '둘러보기' 버튼이나 '샘플 데이터 채우기' 버튼을 미리 만들어두면 좋아요. 로그인 없이도 핵심이 한눈에 보이게요. //

이런 건 다 클로드한테 "샘플 데이터 채우는 버튼 하나 만들어줘" 하고 부탁하면 돼요. //

정리하면요. 멈춰도 괜찮아요. 백업 영상 한 벌만 챙겨두면, 무대 위에서 패닉 올 일이 없어요.

## 6. 사실 데모보다 중요한 게 있어요 — 이야기

화면 보여주는 것도 중요한데요. 그것만큼 중요한 게 하나 더 있어요. //

바로 '이야기'예요. //

같은 앱을 보여줘도, 이야기가 있으면 사람들이 훅 따라와요. //

세 줄만 깔면 돼요. //

**누구를 위해 만들었는지.** //

**왜 만들었는지.** //

**그리고 만들기 전이랑 후가 어떻게 달라졌는지.** //

아까 단골노트로 돌아가볼게요. //

"전에는 단골손님 취향을 머릿속에만 담아두니까 자꾸 까먹었어요. 이제는 손님이 들어오면 폰으로 슥 검색해서, '아 이분 연하게 드시지' 하고 바로 챙겨요." //

이게 만들기 전과 후예요. 이 한 토막이 들어가면, 듣는 사람이 "아, 진짜 필요했겠다" 하고 고개를 끄덕여요. //

기능을 줄줄 나열하는 것보다, 이 작은 이야기 하나가 훨씬 오래 남아요. //

그러니까 발표 준비할 때, 멋진 말 찾으려고 애쓰지 마세요. 그냥 내가 왜 이걸 만들고 싶었는지, 그 솔직한 마음 한 줄이면 충분해요.

## 7. 잠깐, 여기까지 온 당신께

자, 데모나잇 얘기는 여기까지예요. //

이제 잠깐, 제가 진짜 하고 싶었던 말을 할게요. //

EP1부터 여기까지, 혼자 쭉 따라온 분. //

생각해보면 이거 진짜 쉬운 일 아니에요. //

처음엔 검은 창만 봐도 무서웠을 거예요. 설치하다 에러 떠서 멈칫했을 거고, 만든 게 안 돌아가서 한숨 쉰 날도 있었을 거예요. //

그걸 다 지나서 마지막 영상까지 온 거예요. 정말 대단한 거예요. //

근데 여기서 제가 솔직하게 한 가지 말씀드릴게요. 겁주려는 거 절대 아니에요. //

여기까지 온 우리는요, 사실 이제 막 '입문'을 끝낸 거예요. //

환경 만들고, 만들어보고, 배포하고, 보여주는 것까지. 정해진 길을 한 바퀴 돈 거죠. //

진짜는 이제부터예요. 내 일에, 내 프로젝트에, 이 감각을 매일 한 번씩 굴려보는 거. //

그래서 데모나잇은 끝이 아니에요. 오히려 진짜 시작점이에요. //

여기서 익힌 그 감각, "어? AI한테 시키니까 되네?" 하던 그 감각. 그게 다음 프로젝트로 넘어가는 게, 진짜 졸업이에요. //

그러니까 오늘 이 영상 보고 나서요. 거창한 거 말고, 그냥 내 일에 하나만 더 시켜보세요. 그거면 돼요.

## 8. 또 혼자 작심삼일 할 것 같으면요

여기까지 듣고 이런 분도 계실 거예요. //

"좋은 건 알겠는데… 나 또 혼자 하면 작심삼일 할 것 같아." //

너무 솔직한 마음이고, 전혀 부끄러운 거 아니에요. 혼자 끝까지 가는 거, 원래 어려워요. //

그래서 이 얘기만 딱 한 번 담백하게 드릴게요. 부담 가지실 거 없어요. //

혼자 정주행만 해도 충분해요. 진짜예요. 이 영상들 순서대로 따라오시면 다 하실 수 있어요. //

근데 "혼자는 자꾸 미루게 되더라" 하는 분들을 위해서, 마감 걸고 같이 하는 챌린지를 따로 열어두고 있어요. //

4주 동안, 줌으로 모이고 커뮤니티에서 같이 가요. //

매주 미션이 하나씩 있어요. 첫 주는 자동화 한 번 돌려보기, 그다음은 작은 서비스 만들기, 그다음은 내 서비스 이름이랑 모양 다듬기, 마지막 주는 데모나잇. 오늘 얘기한 그 5분 무대요. //

여기서 솔직하게 말씀드릴게요. 이 챌린지가 드리는 건 무슨 비밀 정보 같은 게 아니에요. 사실 내용은 이 유튜브에 거의 다 있어요. //

대신 세 가지를 드려요. 매주 돌아오는 마감. 같이 가는 동료들. 그리고 마지막에 설 무대. //

혼자선 자꾸 미뤄지던 게, 옆에 같이 하는 사람이 있으면 신기하게 굴러가거든요. //

자세한 건 더보기란에 링크 하나 걸어둘게요. 궁금하면 그냥 구경만 하셔도 돼요. 억지로 권하는 거 아니니까요. //

이 얘기는 여기까지. 약속대로 딱 한 번만 할게요.

## 9. 시즌1, 여기서 닫을게요

자, 이제 진짜 마지막이에요. 시즌1 전체를 한 번만 같이 돌아볼게요. //

우리 처음에, "AI 뭐부터 해야 돼요?" 하는 막막함에서 출발했어요. //

챗GPT랑 클로드 코드가 뭐가 다른지 알았고, 5분 만에 작업 환경을 깔았어요. //

AI를 똑똑한 신입사원처럼 다루는 법을 배웠고, 맥락을 주면 일을 훨씬 잘한다는 걸 알았어요. //

명령어 한 줄로 블로그 글이 뚝딱 나오는 자동화도 봤고요. //

내 아이디어를 가설로 바꿔서 첫 화면을 만들고, 망쳐도 되돌리는 법, 에러를 단서로 읽는 법, 진짜 주소로 배포하는 법까지 갔어요. //

그리고 5명한테 보여주고, 알리고, 첫 천 원을 받고, 오늘 사람들 앞에 선보이는 것까지 왔어요. //

쭉 적어놓고 보니까, 우리 진짜 멀리 왔죠? //

이 모든 걸, 코딩 한 줄 몰랐던 상태에서 시작했다는 거. 그걸 꼭 기억해주셨으면 좋겠어요. //

이거 재능이 아니었어요. EP1에서 말씀드렸죠. 순서랑, 마음먹기였어요. 그 순서를, 우리가 같이 한 바퀴 돈 거예요. //

저는 이 채널에서, 그리고 같이 하고 싶은 분이면 챌린지에서, 계속 옆에 있을게요. 답을 다 주는 사람은 아니어도, 같이 보고 있는 동료로요. //

여기까지 와주셔서, 정말 고맙습니다. //

이제 영상 끄고, AI한테 뭐든 하나만 더 시켜보세요. 그게 시즌2의 시작이에요. //

수고하셨어요. 또 만나요.
