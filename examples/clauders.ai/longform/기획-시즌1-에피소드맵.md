## 단계 0 — 오리엔테이션

### EP1. AI 완전 처음인데, 뭐부터 해야 돼요? (비개발자 로드맵) 〔채널 간판〕
- docs: getting-started/00-welcome, 01-what-ai-can-do, 후기.md
- 목표: "AI 어떻게 시작해?"에 대한 완전 초보용 지도 한 장. + 이 채널/재생목록이 그 답임을 보여줌.
- 킬러 장면: 떡집 사장님 같은 비개발자가 만든 결과물 짧게 티저 → "이걸 당신도, 이 순서대로."
- 친절 포인트: "코딩 몰라도 돼요" "AI가 다 해주는 건 아니지만, 겁낼 것도 없어요" 안심.
- 역할: 검색·입소문 유입 → 정주행 입구. 길이 8~12분.

### EP2. 챗GPT·클로드·클로드 코드… 뭐가 다른 거예요?
- docs: getting-started/03-why-cli, claude-code-intro/01-model-choice
- 목표: 제일 흔한 첫 질문 해소. 대화 AI vs 폴더에서 일하는 AI.
- 비유: "챗봇은 상담원, 클로드 코드는 내 책상에서 같이 일하는 직원."
- 친절: 용어(CLI·터미널) 풀어주기. "왜 굳이 검은 창?"까지 납득. 길이 8~10분.

## 단계 1 — 시작하기 (환경·첫 손맛)

### EP3. AI 작업 환경, 5분이면 끝나요 (설치 따라하기)
- docs: getting-started/02-install, 05-terminal-vs-extension
- 목표: 설치~첫 실행. 막힘 포인트(에러) 미리 안심.
- 킬러 장면: 검은 창에 한 줄 → 세션 시작되는 순간.
- 친절: "에러 나면 그 문구 그대로 복사" 같은 초보 구조대 팁. 길이 10~12분.

### EP4. "프로젝트"가 뭐예요? + AI한테 첫 일 시키기
- docs: getting-started/04-create-project
- 목표: 프로젝트=폴더 개념 + "README 만들어줘" 첫 결과물.
- 킬러 장면: 빈 폴더 → 한 줄 → 파일이 생기는 순간.
- 비유: "프로젝트 = AI가 일할 작업실." CLAUDE.md 맛보기("신입 수칙"). 길이 10~12분.

## 단계 2 — 감 잡기 (AI 다루는 법)

### EP5. AI는 똑똑한 신입사원이에요 (다루는 감)
- docs: claude-code-intro/01-model-choice, 02-direction
- 목표: AI 멘탈모델. "박사급인데 우리 사정은 백지." 작은 일부터 툭툭 던져보기.
- 비유: 앵무새 / 박사급 신입. "한 번에 완벽 안 나와요, 주고받는 거예요."
- 친절: 모델 고르기 고민 덜어줌("초보는 그냥 제일 똑똑한 거"). 길이 10~12분.

### EP6. AI한테 일 제대로 시키는 법 (맥락 = 인수인계)
- docs: claude-code-intro/03-good-prompts (+ CLAUDE.md 제대로)
- 목표: "왜 헛소리하나" = 맥락 안 줘서. 뭘/왜/어떤 모양으로. CLAUDE.md로 맥락 고정.
- 킬러 장면: 같은 요청, 맥락 없을 때 vs 줬을 때 결과 비교.
- 친절: 복붙용 프롬프트 틀 제공. 길이 12~15분.

## 단계 3 — 자동화 입문 (한 줄의 마법)

### EP7. 반복 업무를 명령어 하나로 (커맨드·에이전트·스킬·훅 쉽게)
- docs: automation/01-four-features
- 목표: 4가지 장치를 비유로 한 번에. "자동화는 흐름을 미리 박아두는 것."
- 비유: 커맨드=단축키 / 에이전트=담당자 / 스킬=알아서 꺼내 쓰는 능력 / 훅=자동. 길이 12~15분.

### EP8. 명령어 한 줄로 블로그 글이 완성됩니다 (`/write` 전 과정 공개) 〔매직〕
- docs: automation/02-delegate-blog
- 목표: `/write` 셋업~실행 전 과정. 담당자(에이전트) 파이프라인이 도는 걸 보여줌.
- 킬러 장면: `/write 1화` → 2~3분 뒤 `drafts/1화.md` 완성본.
- 친절: "이 한 줄이 방금 뭘 한 거냐면요…" 차근차근. 길이 15~20분.

### EP9. 이런 것도 자동화돼요 (패턴 + 내 일에 적용하기)
- docs: automation/03-patterns, 04-homework
- 목표: 자동화 5패턴(체인/분류/동시/지휘/반복개선)을 쉽게 + "네 일 1건 자동화" 숙제.
- 친절: "거창한 거 말고 네 귀찮은 일 하나부터." 길이 10~12분.

## 단계 4 — 만들기 (0 → 배포 → 피드백)

### EP10. 내 아이디어를 '가설'로 바꾸고 1장으로 정리 (기획·PRD)
- docs: build-service/00-overview, 01-idea, 02-lean-plan, 03-prd
- 목표: 대박 아이디어 X, "누가/무슨 문제/어떻게" 가설 + PRD 1장. AI랑 대화로.
- 비유: 린 스타트업 루프(작게 만들고 반응 보고 고치기). 길이 12~15분.

### EP11. 코딩 몰라도 첫 화면 만들기 (프론트엔드, 식당 비유)
- docs: build-service/04-tech, 05-build-frontend
- 목표: 프론트만으로 시작. 화면=손님석, 서버=주방. 상태 개념 쉽게.
- 킬러 장면: "자기소개 페이지 만들어줘" → 5분 뒤 화면에. 길이 15~18분.

### EP12. 망쳐도 괜찮아요: Git으로 되돌리기 (게임 세이브)
- docs: build-service/06-git
- 목표: commit=세이브, 되돌리기. 초보 안전망.
- 비유: 게임 세이브/불러오기. 친절: "되돌리면 뭐 사라지는지 먼저 물어봐." 길이 10~12분.

### EP13. 에러 떴다고 망한 거 아니에요 (AI랑 디버깅)
- docs: build-service/07-fix
- 목표: 에러=단서. 통째 복사→AI한테→WHAT/WHERE/WHEN→3번 룰.
- 킬러 장면: 빨간 에러 → 복사 → AI가 원인+수정 → 해결.
- 친절: "영어 무서워 마세요, 그대로 복사" 안심. 길이 12~15분.

### EP14. 1시간 만에 진짜 주소로 배포하기 (Vercel 전 과정) 〔킬러〕
- docs: build-service/08-deploy
- 목표: 내 컴퓨터 밖, 진짜 URL로. 환경변수 함정까지.
- 킬러 장면: `vercel` → URL → 친구한테 카톡 → 진짜 열림.
- 친절: 요금 걱정·env 같은 초보 공포 미리 해소. 길이 15~18분.

### EP15. 5명한테 보여주고 피드백 받기 (+ PMF 감)
- docs: build-service/09-feedback, 10-pmf
- 목표: "어때?" 말고 "또 쓸 것 같아?" 5명(모르는 2명). 돌아오나로 PMF.
- 친절: "기능 추가는 도망, 먼저 다듬기." 길이 12~15분.

### EP16. (심화) 만든 거 알리고 첫 1,000원 받기 (모객·결제)
- docs: build-service/11-distribution, 12-pg-bootpay
- 목표: 오디언스 퍼스트, 10번 유용 1번 알림, 첫 판매=1:1 제안, 부트페이.
- 위치: 입문 사다리 끝 보너스(원하는 사람만). 길이 12~15분.

## 제작·운영 메모

- **정주행 재생목록** "AI 입문 정주행"으로 EP1~17 묶기. 채널 핵심 자산.
- **콜드 스타트(촬영 우선순위)**: EP1(간판) → EP2 → EP4(첫 손맛) → EP8(/write 매직) → EP14(배포 킬러). 발견·임팩트 큰 것부터 찍어 채널 채우고, 나머지로 사다리 메움.
- **쇼츠 104개**(`shorts/`)는 각 EP의 미끼: 단답 쇼츠로 발견 → 해당 EP/재생목록으로.
- **길이**: 입문 8~12분, 빌드얼롱 15~20분. 빌드얼롱은 실제 화면녹화 중심(대본 부담↓).
- **funnel**: 전부 무료. EP17 + 각 영상 더보기란에 챌린지 신청만 담백하게.
- 톤 사수: 매 영상 "이거 몰라도 돼요/천천히" 1회 이상. 비유 1개 이상. 겁주기·하이프 0.
