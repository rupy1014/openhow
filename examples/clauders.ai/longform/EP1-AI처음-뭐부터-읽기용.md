# [EP1] 읽기용 대본 — AI 완전 처음인데, 뭐부터 해야 돼요? (비개발자 로드맵)

## 1. 시작 — 막막하셨죠?

혹시 이런 적 있으세요? //

"나도 AI 좀 해봐야 하는데" 싶어서 유튜브에 검색을 해봐요. 그랬더니 영상은 수백 개고, 다들 어려운 말만 쏟아내고. //

결국 "그래서 나는 뭐부터 봐야 하는데?" 하고 더 헷갈린 채로 창을 닫은 적. //

저도 그랬어요. 그래서 이 영상 하나를 만들었어요. //

AI 완전 처음인 분, 컴퓨터랑 안 친한 분, "나는 문과라서요" 하는 분. 딱 그런 분들 기준으로요. //

오늘 이거 하나만 보시면, "아, 나는 이 순서로 가면 되는구나" 하고 길이 딱 보일 거예요. 천천히 갈 테니까, 편하게 들어주세요.

---

## 2. 먼저, 안심부터 시켜드릴게요

본론 들어가기 전에, 제가 제일 하고 싶은 말부터 할게요. //

AI 처음이어도 괜찮아요. 코딩 하나도 몰라도 괜찮아요. 컴퓨터 좀 무서워해도, 진짜 괜찮아요. //

제가 이걸 비개발자분들한테 직접 가르쳐봤거든요. 떡집 사장님, 노인복지센터에서 일하시는 분, 공장 하시는 분. 평소에 컴퓨터로는 카톡밖에 안 하시던 분들이요. //

그런 분들도 다 하셨어요. 그러니까 "나 같은 사람이 되겠어?" 하는 그 걱정, 일단 내려놓으셔도 돼요. //

이거, 재능 문제 아니에요. 순서랑, 마음먹기예요. 오늘은 그 '순서'를 알려드릴게요.

---

## 3. 어떻게 가르쳤냐면요 (인강이 아니에요)

근데 제가 '가르쳤다'고 하면, 보통 인강 같은 걸 떠올리시죠. 영상 쭉 찍어서 "자, 보세요" 하고 던져주는 거. //

아니에요. 그렇게 했으면 떡집 사장님은 절대 못 따라오셨을 거예요. //

저는 기수로, 그러니까 한 번에 같이 시작하는 팀으로 모았어요. 매주 만나서 같이 진도 나가고, 막히는 건 그때그때 질문받고, 따로 시간 잡아서 한 분 한 분 화면 같이 보면서 봐드리는 시간도 가졌어요. 오피스아워라고 부르는데, 거의 옆에서 컨설팅하듯이요. //

그리고 이게 제일 중요한데요. 저마다 만들고 싶은 게 다 달랐어요. 누구는 가게 주문 정리, 누구는 본인 업무 자동화, 누구는 작은 앱. 그 각자의 걸 끝까지 만들어서, 진짜로 세상에 내놓는 데까지 같이 갔어요. //

그래서 결과물이, "AI로 이런 것도 되는구나" 싶은 실제 사례가 정말 많아요. 그 이야기들, 이 채널에서 차차 보여드릴게요. //

재밌는 게 하나 있어요. 이렇게 기수가 쌓이니까, 분야별로 사례가 차곡차곡 모이더라고요. 카페 하는 분, 쇼핑몰 하는 분, 학원 하는 분. 그래서 새로 오신 분이 "저는 이런 걸 만들고 싶어요" 하면, 알고 보면 앞 기수 누군가가 이미 한 번 부딪혀 본 거인 경우가 많아요. 그럼 서로 연결해드리고, "저는 이렇게 풀었어요" 하고 조언도 주고받고요. 혼자 끙끙대는 것보다 훨씬 빨라지죠. //

오늘부터는 그 4주짜리 과정을, 이 채널에 순서대로 다 풀어놓을 거예요. 혼자서도 따라올 수 있게요. 그 첫걸음이 지금부터예요.

## 4. 제일 흔한 오해부터 풀고 갈게요

시작하기 전에, 오해 하나만 풀고 갈게요. 이거 알고 시작하면 나중에 덜 실망하시거든요. //

요즘 "AI가 다 해준다"는 말, 진짜 많이 들으시죠? //

이거, 반은 맞고 반은 틀려요. //

AI, 진짜 엄청난 도구 맞아요. 글도 써주고, 자료 정리도 해주고, 간단한 프로그램도 만들어줘요. 처음 보면 좀 신기할 정도예요. //

근데 'AI가 알아서 다' 해주진 않아요. 뭘 해달라고, 어떻게 해달라고 방향을 잡아주는 건, 결국 사람이거든요. //

이걸 미리 알면, 나중에 "어, 생각보다 안 되네?" 하고 실망하는 일이 없어요. //

그러니까 이렇게 생각하시면 돼요. AI는 마법이 아니라, 아주 쉽고 강력한 도구다. 겁먹을 건 전혀 없고, 그냥 쓰는 법만 익히면 된다.

## 5. 그래서 AI로 뭘 할 수 있는데요?

자, 그럼 이 도구로 대체 뭘 할 수 있느냐. 크게 두 가지로만 생각하시면 쉬워요. //

**첫째, 내 시간을 아끼는 거예요.** //

매일 반복하는 귀찮은 일들 있잖아요. 똑같은 메일 쓰기, 자료 정리하기, 표 만들기. 그런 걸 AI한테 맡겨서 확 줄이는 거예요. //

실제로 어떤 떡집 사장님은, 매일 새벽에 손으로 하던 주문 정리를 AI한테 맡겨서, 자동으로 착착 정리되게 만드셨어요. 새벽 시간이 확 비었죠. //

**둘째, 내가 필요한 걸 직접 만드는 거예요.** //

간단한 웹사이트나, 작은 앱이나, 나만 쓰는 도구 같은 거요. 예전 같으면 개발자한테 돈 주고 부탁해야 했던 걸, 이제 내가 직접 만들어요. //

거창하게 안 들려도 괜찮아요. 시작은 "내 귀찮은 일 하나 줄이기"면 충분하거든요. 거기서부터 천천히 커지는 거예요.

---

## 6. 그럼, 뭐부터 봐야 하나요? (로드맵)

자, 이제 진짜 본론. "그래서 뭐부터?" //

제가 가르쳐보면서 정리한 순서가 있어요. 딱 다섯 칸이에요. 이 채널 재생목록도 정확히 이 순서로 돼 있고요. //

**첫째, 작업 환경 만들기.** AI한테 일을 시킬 수 있는 '작업대'를 차리는 거예요. 어려울 것 같죠? 5분이면 돼요. 다음 영상들에서 손잡고 같이 할게요. //

**둘째, AI 다루는 감 잡기.** AI를 아주 똑똑한 신입사원이라고 생각하고, 일을 어떻게 시키는지 익히는 단계예요. 이 감만 잡으면 절반은 끝나요. //

**셋째, 자동화 한 번 맛보기.** 명령어 한 줄로 반복되는 일이 자동으로 처리되는 걸, 직접 한 번 경험해보는 거예요. 이거 보면 다들 "오?" 하세요. //

**넷째, 내 걸 만들어서 진짜 주소로 내보내기.** 작은 거 하나 만들어서, 친구한테 링크로 보내보는 단계예요. 내가 만든 게 진짜 인터넷에 뜨는 순간, 좀 짜릿해요. //

**다섯째, 보여주기.** 만든 걸 사람들한테 선보이고, 피드백을 받아보는 거예요. //

한 번에 다 하려고 절대 하지 마세요. 한 칸씩만 가요. 한 칸을 넘으면, 신기하게 다음 칸이 훨씬 쉬워지거든요.

---

## 7. 딱 하나만 기억해 주세요

마지막으로, 제일 중요한 거 하나만 말씀드릴게요. //

이 영상도, 앞으로 나올 영상들도, '보기만' 하면 아무것도 안 바뀌어요. //

이거 잔소리하려는 거 아니에요. 제가 100명 가르쳐보고 제일 확실하게 본 거예요. //

영상 백 개를 보는 사람보다, 딱 한 번 직접 시켜본 사람이 훨씬 빨리 늘더라고요. //

그러니까 오늘, 이 영상 다 보고 나면요. 거창한 거 말고, 그냥 AI한테 뭐든 하나만 시켜보세요. "오늘 할 일 좀 정리해줘"도 좋아요. //

그 "어? 이게 되네?" 한 번이, 진짜 시작이에요.

---

## 8. 마무리 + 다음 영상

자, 오늘 거 정리할게요. //

AI는 마법이 아니라 도구고, 생각보다 훨씬 쉽고, 비개발자도 충분히 할 수 있어요. //

순서는 다섯 칸. 환경 만들기, 감 잡기, 자동화, 만들기, 보여주기. //

그리고 보기만 하지 말고, 딱 한 번 직접 해보기. //

다음 영상에서는, 제일 많이들 물어보시는 것부터 풀게요. "챗GPT랑 클로드, 그리고 클로드 코드는 대체 뭐가 다른 거예요?" //

이 재생목록을 순서대로 천천히만 따라오시면, 한 달 뒤엔 분명히 달라져 있을 거예요. 제가 옆에서 같이 갈게요. //

봐주셔서 고맙습니다. 다음 영상에서 봬요.
