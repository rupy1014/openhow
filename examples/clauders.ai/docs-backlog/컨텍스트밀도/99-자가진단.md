**5분 안에 내 프로젝트가 어느 단계까지 왔는지 측정.**

:::success 이 페이지가 끝나면
- 이 시리즈에서 다음에 어디를 봐야 할지 명확해져
- 미완 영역의 우선순위가 잡혀
:::

**사람이 하는 것**: 체크리스트 따라가기
**AI 가 하는 것**: (없음 — 사람의 자기 점검)
**해결 방식**: 점검
**걸리는 시간**: 5분

---

## 단계 1 — 위생

- [ ] `CLAUDE.md` 200줄 이하
- [ ] `AGENTS.md` 가 CLAUDE.md 와 중복 아님 (또는 심볼릭 링크)
- [ ] `.claude/commands/*.md` 중 200줄 넘는 거 없음
- [ ] `docs/` 루트에 ARCHIVED/DEPRECATED 안 섞여있음
- [ ] LLM 이 자동 생성한 요약 문서 없음

전부 ☑ 안 되면 → [03. 청소](./03-청소-자르고-합치기).

---

## 단계 2 — 반복 제거

- [ ] 같은 경고("DO NOT ...")가 3 곳 이상 복붙된 거 없음
- [ ] 반복되는 shell prefix(`source ~/.zshrc`)는 래퍼 스크립트로
- [ ] 여러 명령 MD 에 복사된 공통 블록은 단일 출처 + 참조

→ [03. 청소](./03-청소-자르고-합치기).

---

## 단계 3 — 경계 분류

- [ ] 4가지 판단 질문을 알고 있음
- [ ] "추론은 자유, 입출력만 구조화" 원칙을 이해
- [ ] 어떤 규칙이 엔지니어링 영역인지 분류함

→ [04. 경계](./04-경계-엔지니어링이냐-프롬프트냐).

---

## 단계 4 — 스키마화

- [ ] MD 에 박힌 enum/상수가 단일 출처(SSOT) 로 옮겨짐
- [ ] 검증 스크립트가 SSOT 를 읽도록 작성됨
- [ ] MD 에는 "스키마 참조" 한 줄만 남음
- [ ] 잘못된 값을 넣어 검증 동작 확인됨

→ [05. 스키마로 옮기기](./05-스키마로-옮기기).

---

## 단계 5 — 조립

- [ ] 정책 카탈로그(`policies/`) 디렉토리 존재
- [ ] 1주제 1파일 원칙 지킴
- [ ] 호출 인터페이스(YAML/JSON) 가 키만 사용
- [ ] 조립 엔진(키 → 자연어 변환) 동작
- [ ] 정책별 회귀 테스트(Golden Eval) 있음

→ [06. 정책 카탈로그](./06-정책-카탈로그).

---

## 단계 6 — 자기관리

- [ ] `MEMORY.md` 인덱스/리프 분리
- [ ] 세션 종료 자동 회고 훅 존재
- [ ] 정책 카탈로그 자동 제안 워크플로우 있음 (사람 검토 거침)
- [ ] 30일 이상 안 쓴 메모리 정기 정리

→ [07. AI 가 자기 기억 관리](./07-AI가-자기-기억-관리).

## 우선순위 원칙

미완 단계가 여러 개면 항상 **낮은 단계부터**:

```
1 → 2 → 3 → 4 → 5 → 6
```

5번이 시작 전인데 6번부터 도전하지 마. 정책이 없는데 자동 회고할 게 없음.
