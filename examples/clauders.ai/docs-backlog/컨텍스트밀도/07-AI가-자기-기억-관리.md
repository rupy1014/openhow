**최종 단계는 사람이 빠지는 것. AI 가 자기 메모리를 스스로 큐레이션해.**

:::success 이 페이지가 끝나면
- `MEMORY.md` 인덱스/리프 패턴을 알아
- 세션 종료 시 자기 회고가 어떻게 작동하는지 알아
- 어디까지 자동화하고 어디부터 사람이 봐야 하는지 알아
:::

**사람이 하는 것**: 자동화 트리거 결정, 회고 결과 정기 검토
**AI 가 하는 것**: 세션 분석, MEMORY.md 업데이트, 정책 카탈로그 진화
**해결 방식**: 엔지니어링 + 프롬프트
**걸리는 시간**: 초기 셋업 1\~2시간, 이후 자동

---

## 왜 자동화? — ROI 먼저

자동화 안 하면 사람이 매 세션마다 이걸 함:
- 이번에 새로 알게 된 사실 정리
- 사용자가 정정한 가정 추적
- 미해결 이슈 기록

주 5세션 × 5분 정리 = 주 25분. 1년이면 20시간. 자동화 셋업 2시간 ÷ 20시간 = **ROI 10배**.

단, [06. 정책 카탈로그](./06-정책-카탈로그) 가 끝난 다음에 의미 있어. 정책이 없으면 자동 회고도 쓸 데가 없어.

---

## 사실 확인 — 이미 있는 도구들

이건 미래 이야기가 아니야:

- **Claude Code Auto-dream** (2025): 세션 기록을 분석해서 MEMORY.md 를 자동 업데이트하는 백그라운드 서브에이전트
- **claude-mem 플러그인**: 오픈소스 구현체
- **Letta (MemGPT)**: OS 수준 메모리 가상화 — Core/Archival 분리

## 1. 인덱스 + 리프 분리

Claude Code 의 실제 메모리 아키텍처:

```
MEMORY.md (포인터 인덱스, 거의 안 바뀜, 항상 in-context)
  ↓ 참조
memory-{topic}.md (자주 업데이트, lazy load)
  ↓ 참조
archival (파일시스템, 검색해서 가져옴)
```

**인덱스는 안정, 리프는 가변.**

---

## 2. 세션 종료 자동 회고

`/build` 같은 명령이 끝나면 훅으로 자동 분석:

```bash
# .claude/hooks/post-build.sh
claude --headless "방금 build 세션을 분석해줘:
- 새로 발견한 사실/제약이 있나? → memory 에 추가
- 사용자가 정정한 가정이 있나? → feedback memory 로 저장
- 미해결 이슈가 있나? → project memory 로
- 이미 있는 메모리와 중복이면 업데이트, 아니면 신규
"
```

`settings.json`:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Skill\\(build.*\\)",
        "command": ".claude/hooks/post-build.sh"
      }
    ]
  }
}
```

→ 세션이 끝날 때마다 AI 가 자기 메모리를 정리. 사람은 안 끼어듦.

---

## 3. 정기 정리 (사람의 역할)

자동 회고가 쌓이면 메모리도 늘어나. 주 1회 사람이 점검:

```bash
du -sh ~/.claude/projects/-Users-.../memory/
ls -lat ~/.claude/projects/-Users-.../memory/ | head -20
```

체크 항목:
- **30일 이상 참조 안 된** 메모리 → 삭제 후보
- **상충하는** 메모리 → 통합
- **너무 자세한** 메모리 → 요약

이 단계는 자동화 못 해. 사람이 "이 메모리가 아직 유효한가" 판단해야 함.

---

## 4. 정책 카탈로그의 진화

[06](./06-정책-카탈로그) 에서 만든 `policies/` 도 자동으로 진화 가능:

```
세션 끝 →
  AI 가 "이번 세션에서 새로 발견한 가드레일이 있나?" 자체 검토 →
  있으면 policies/guardrail/ 에 신규 파일 제안 →
  사람이 PR 리뷰
```

**자동 추가가 아니라 자동 제안**. 정책 신규 등록은 사람의 검토를 거쳐.

---

## 흔한 실수

### 실수 A: 모든 걸 자동 메모리로

세션마다 무차별 저장 → 메모리가 트래시통이 됨. AI 가 매 세션 쓰레기 더미를 읽음.

→ **저장 기준을 명시**. "사용자가 정정했다", "예상치 못한 사실 발견했다" 같은 트리거 조건만.

### 실수 B: 자동 정책 추가

AI 가 "이거 가드레일로 추가했어요!" 하고 policies/ 에 PR 도 안 거치고 자동 commit → 정책이 오염됨.

→ **인간 검토는 필수**. 자동 제안 OK, 자동 머지 NO.

### 실수 C: 회고를 인덱스에 넣기

`MEMORY.md` 인덱스에 회고 결과를 직접 기록 → 인덱스가 부풀어. Anthropic 권장은 인덱스 200줄 이하.

→ **회고는 리프 파일에**. 인덱스에는 한 줄 포인터.
