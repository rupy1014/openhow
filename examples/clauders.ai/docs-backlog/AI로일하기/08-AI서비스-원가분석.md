**사주 리포트 하나 생성하는 데 270원.**

AI 서비스를 만들면 제일 먼저 드는 생각이 "이거 돈 얼마나 나가지?"야.

실제로 운영 중인 사주 서비스(운세냥, jeommyo.com)의 원가를 까볼게.

---

## 뭘 만드는 서비스야?

생년월일시를 입력하면 AI가 **13개 장짜리 프리미엄 사주 리포트**를 생성하는 서비스야.

나의 본캐, 숨겨진 속마음, 대운, 연애, 재물, 건강 — 장마다 AI가 글을 써서 하나로 합쳐줘.

```
사용자 입력: 1991년 2월 16일 0시 30분, 여성
    ↓
맥미니 워커가 13장을 병렬 생성 (LLM 25~35회 호출)
    ↓
프리미엄 리포트 완성 (약 3~5분)
```

---

## 비용 구조가 어떻게 돼?

크게 두 가지야. **LLM 호출 비용** + **인프라 비용**.

### LLM 호출 (변동비 — 건당 발생)

| 항목 | 수치 |
|------|------|
| 모델 | `gpt-4.1-mini` (OpenRouter 경유) |
| 호출당 평균 토큰 | ~7,000 (입력 4,000 + 출력 3,000) |
| 호출당 비용 | **~9원** |
| 총 LLM 호출 수 | **25~35회** (평균 30회) |
| **리포트 1건 합계** | **~270원** |

호출 내역을 뜯어보면 이래:

| 단계 | 호출 수 | 설명 |
|------|---------|------|
| 단일패스 장 생성 | 9회 | 짧은 장은 한 번에 |
| 멀티패스 서브파트 | 8회 | 긴 장은 쪼개서 병렬 생성 |
| 확장 재시도 | 0~6회 | 분량 70% 미만이면 재생성 |
| 하이라이트 보충 | 0~13회 | 하이라이트 3개 미만이면 보충 |
| PRD 커버리지 보충 | 0~13회 | 커버리지 75% 미만이면 보충 |

OpenRouter 기준 토큰 단가는 이래:

| 구분 | $/1M tokens | 원/1K tokens |
|------|------------|-------------|
| Input | $0.40 | 0.56원 |
| Output | $1.60 | 2.24원 |

입력 4,000토큰(2.24원) + 출력 3,000토큰(6.72원) = **호출당 ~9원**.

### RAG (벡터 검색 — 거의 공짜)

| 항목 | 수치 |
|------|------|
| 임베딩 모델 | `text-embedding-3-small` (OpenAI) |
| **리포트 1건 합계** | **~0.2원** |

사주 지식을 벡터 DB(Qdrant)에 넣어놓고, 장마다 관련 지식을 검색해서 프롬프트에 넣어줘.
임베딩 비용이 워낙 싸서($0.02/1M tokens) 사실상 무시할 수준이야.

### 인프라 (고정비 — 월 단위)

| 항목 | 비용 |
|------|------|
| 맥미니 (이미 보유) | $0 |
| 전기세 + 회선 | 월 ~2만원 |
| Cloudflare Tunnel | 무료 |
| Vercel (프론트엔드) | 무료 티어 |
| Supabase (DB, 인증) | 무료 티어 |
| **월 고정비** | **~2만원** |

맥미니 하나에 워커 + Qdrant + 오케스트레이터 다 올라가.
프론트는 Vercel, DB는 Supabase 무료 티어. Cloudflare Tunnel로 외부 접속을 뚫어.

## 중국 리셀러를 쓰면 얼마나 싸져?

중국 LLM 리셀러(12ai 등)를 경유하면 리포트당 **270원 → 50원**으로 떨어져.

| 구분 | OpenRouter (gpt-4.1-mini) | 12ai (gemini-2.5-flash) |
|------|--------------------------|------------------------|
| 호출당 비용 | ~9원 | ~1.7원 |
| 프리미엄 30콜 | **~270원** | **~50원** |

OpenAI 호환 API라서 `baseUrl`만 바꾸면 돼. 코드 수정 없이 게이트웨이만 갈아끼울 수 있어. 자세한 연동 방법은 [LLM 게이트웨이](../레시피/LLM-게이트웨이/01-llm-mux) 참고.

**단, 폴백 구조는 필수야.** 실제로 BitexingAI는 2026년 4월에 서버가 먹통이 됐어. 메인이 죽으면 자동으로 다음 게이트웨이로 넘어가게 해야 해.

## 수익성은 어때?

원가를 알았으니까 마진을 볼 수 있어.

| 상품 | 판매가 | LLM 원가 (OpenRouter) | LLM 원가 (12ai) | 마진율 |
|------|--------|----------------------|-----------------|--------|
| 프리미엄 13장 | 19,800원 | ~270원 | ~50원 | **98.6~99.7%** |
| 라이트 7장 | 9,900원 | ~135원 | ~25원 | **98.6~99.7%** |
| 딥다이브 1장 | 5,900원 | ~36원 | ~7원 | **99.4~99.9%** |

**LLM API 비용은 판매가의 1~2%도 안 돼.**

진짜 비용은 뭐냐? 개발 시간이야.
프롬프트 설계, RAG 파이프라인, 결제 연동, 리포트 뷰어 — 이런 걸 만드는 데 시간이 들어.

한번 만들어놓으면 변동비가 거의 없으니까, **소량으로도 수익이 나.**

---

## 비용을 줄이려면 어떻게 해?

네 가지 레버가 있어.

**1. 게이트웨이를 바꿔라**

OpenRouter → 중국 리셀러로 바꾸면 5배 이상 싸져.
단, 폴백 구조를 반드시 만들어. 하나 죽으면 다음으로 넘어가게.

**2. 모델을 바꿔라**

`gpt-4.1-mini` 대신 `gemini-2.5-flash` 같은 모델로 바꾸면 더 싸.
장별로 "싼 모델로 충분한 장"과 "비싼 모델이 필요한 장"을 나눌 수도 있어.

**3. 캐싱을 써라**

같은 생년월일이면 원국 분석이 동일하잖아.
한 번 생성하고 캐싱하면 재생성 비용이 0원이야.

**4. RAG로 프롬프트를 줄여라**

프롬프트에 사주 지식을 다 넣으면 입력 토큰이 많아져서 비싸.
RAG로 필요한 지식만 뽑아서 넣으면 입력 토큰이 줄어들어.
**품질을 올리면서 동시에 비용을 낮춰.**

## 월 비용 시뮬레이션

| 월 생성량 | OpenRouter 원가 | 12ai 원가 | 차이 |
|----------|----------------|-----------|------|
| 100건 | 27,000원 | 5,000원 | -22,000원 |
| 500건 | 135,000원 | 25,000원 | -110,000원 |
| 1,000건 | 270,000원 | 50,000원 | -220,000원 |

월 500건이면 OpenRouter로도 13만 5천원이야.
12ai 쓰면 2만 5천원. **인프라 고정비(2만원)보다 싸.**

## 한 줄 정리

AI 서비스 원가의 핵심은 LLM API 호출인데, 그것도 판매가의 1~2%야. 중국 리셀러까지 쓰면 0.3% 이하로 떨어져. **270원으로 2만원짜리 상품을 만들 수 있다** — 이게 AI 서비스의 원가 구조야.
