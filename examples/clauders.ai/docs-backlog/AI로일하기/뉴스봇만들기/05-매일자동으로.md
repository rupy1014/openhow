**지금까지는 내가 `/news` 쳐야 돌아갔어. 이제 매일 아침 알아서 돌아가게 만들어.**

근데 전부 다 자동은 아니야. **무료로 자동화되는 것**과 **API 요금이 드는 것**이 나뉘어.

```
무료 자동화 (GitHub Actions):
  → 뉴스 수집 (RSS 긁기)        ← 무료
  → 발송 (웹훅/카톡)            ← 무료

유료 자동화 (LLM API 필요):
  → AI 리뷰 생성                ← 토큰 과금
  → 퇴고                       ← 토큰 과금
```

---

## 뭐가 무료고 뭐가 유료냐

파이프라인 6단계 중에서 돈이 드는 건 **AI가 글을 읽고 쓰는 단계**뿐이야.

| 단계 | 자동화 | 비용 |
|------|--------|------|
| 모으기 (RSS 수집) | GitHub Actions로 가능 | **무료** |
| 분류 + 리뷰 생성 | LLM API 호출 필요 | **토큰 과금** |
| 퇴고 | LLM API 호출 필요 | **토큰 과금** |
| 발송 (슬랙/카톡) | GitHub Actions로 가능 | **무료** |

RSS를 긁어오는 건 그냥 웹 페이지를 읽는 거라 무료야. 슬랙 웹훅으로 메시지 보내는 것도 무료야.

근데 "이 기사를 읽고 한국어 리뷰를 써줘"는 LLM API를 호출해야 해. 이때 토큰(글자 수)에 따라 과금돼.

---

## 리뷰 생성을 자동화하려면 어떡하냐

2장에서 세 가지 방법을 봤어. 자동화 관점에서 다시 정리하면:

| 방법 | 자동화 가능? | 월 비용 (기사 10개/일 기준) |
|------|-----------|--------------------------|
| Claude Code `/news` | 수동 (내가 쳐야 함) | Claude Code 구독료에 포함 |
| **OpenRouter API** | **완전 자동** | **~$3~10/월** |
| Antigravity 워크플로우 | 수동 | 무료 플랜 있음 |

**완전 자동화하려면 OpenRouter 같은 LLM API를 써야 해.**

OpenRouter는 여러 AI 모델을 하나의 API로 쓸 수 있는 서비스야. Gemini, Claude, GPT 중에서 가격 대비 성능이 좋은 모델을 골라서 쓸 수 있어.

```
OpenRouter API 호출 흐름:
  GitHub Actions가 매일 아침 실행
    → npm run fetch (수집 — 무료)
    → 스크립트가 OpenRouter API 호출 (리뷰 생성 — 유료)
    → 결과를 슬랙으로 발송 (— 무료)
```

:::info OpenRouter가 뭐야?
여러 AI 모델(Gemini, Claude, GPT 등)을 **하나의 API 키**로 쓸 수 있는 서비스야. 모델마다 가격이 다르니까 용도에 맞게 골라 쓸 수 있어. [openrouter.ai](https://openrouter.ai)에서 가입하면 돼.
:::

### 비용이 얼마나 드냐

기사 하나당 리뷰를 생성하는 데 보통 2,000~5,000토큰을 써.

| 모델 | 기사 1개당 비용 | 하루 10개 | 월 비용 |
|------|---------------|----------|---------|
| Gemini Flash | ~$0.001 | ~$0.01 | ~$0.3 |
| GPT-4o mini | ~$0.003 | ~$0.03 | ~$1 |
| Claude Haiku | ~$0.005 | ~$0.05 | ~$1.5 |
| GPT-4o | ~$0.01 | ~$0.1 | ~$3 |
| Claude Sonnet | ~$0.015 | ~$0.15 | ~$5 |

**Gemini Flash면 월 300원 수준이야.** 품질을 올리고 싶으면 더 비싼 모델을 쓰면 돼. 어차피 월 몇천 원이야.

## cron이 뭐냐

**프로그램의 알람시계야.**

알람이 울리면 네가 일어나듯이, cron이 울리면 프로그램이 실행돼.

```
알람:  매일 아침 8시 → 나를 깨워
cron:  매일 아침 8시 → 이 스크립트를 실행해
```

cron 시간 표기법은 이렇게 생겼어:

```
0 8 * * *
│ │ │ │ │
│ │ │ │ └── 요일 (무관)
│ │ │ └──── 월 (무관)
│ │ └────── 일 (무관)
│ └──────── 시 (8시)
└────────── 분 (0분)
```

`0 8 * * *` = 매일 아침 8시 0분.

외울 필요 없어. Claude Code한테 "매일 아침 8시에 실행해줘"라고 하면 알아서 cron 표현을 만들어줘.

---

## 서버가 꼭 필요하냐

cron은 **누군가가 24시간 켜져 있어야** 돌아가. 세 가지 방법이 있어:

| 방법 | 특징 | 비용 | 추천 |
|------|------|------|------|
| 내 컴퓨터 cron | 컴퓨터 켜져 있을 때만 동작 | 무료 | 테스트용 |
| **GitHub Actions** | **24시간 동작, 설정 간단** | **무료** | **가장 추천** |
| VPS 서버 | 완전한 자유도 | 월 $5~ | 고급 |

## GitHub Actions가 뭐냐

**GitHub에서 코드를 대신 실행해주는 서비스야.**

바이브코딩에서 GitHub에 코드 올려봤잖아. GitHub Actions는 거기에 "이 코드를 **언제** 실행해줘"를 설정하는 거야.

설정은 `.github/workflows/` 폴더에 `.yml` 파일 하나로 해. 이 파일이 "작업 지시서"야:

```yaml
name: 매일 뉴스 수집
on:
  schedule:
    - cron: '0 23 * * *'  # UTC 23시 = 한국시간 8시

jobs:
  fetch-news:
    runs-on: ubuntu-latest
    env:
      OPENROUTER_API_KEY: ${{ secrets.OPENROUTER_API_KEY }}
      SLACK_WEBHOOK_URL: ${{ secrets.SLACK_WEBHOOK_URL }}
    steps:
      - uses: actions/checkout@v4
      - run: npm install
      - run: npm run fetch              # 수집 (무료)
      - run: npm run review             # 리뷰 생성 (OpenRouter API)
      - run: npm run send               # 발송 (무료)
```

"매일 한국시간 8시에 수집하고, AI 리뷰 만들고, 슬랙으로 보내줘."

이걸 코드로 적은 거야.

:::info 환경변수는 어디에 넣어?
바이브코딩에서 Vercel에 환경변수 넣었잖아. GitHub Actions도 같아. GitHub 리포 Settings → Secrets에 `OPENROUTER_API_KEY`랑 `SLACK_WEBHOOK_URL`을 넣으면 돼.
:::

## 어떻게 설정하냐

**Step 1.** Claude Code에게 시키기

```
> GitHub Actions로 매일 아침 8시(한국시간)에
> 콘텐츠 수집 → OpenRouter API로 리뷰 생성 → 슬랙 발송하는 워크플로우 만들어줘.
> OpenRouter API 키는 Secrets에 넣을게.
```

**Step 2.** `.github/workflows/daily-news.yml` 파일이 생겨

**Step 3.** GitHub에 push

```bash
git add .github/workflows/daily-news.yml
git commit -m "매일 뉴스 수집 자동화"
git push
```

push하면 GitHub이 매일 아침 자동으로 돌려줘.

## 정리: 자동화 단계별 선택지

처음부터 완전 자동화 안 해도 돼. 단계별로 올라가면 돼.

```
레벨 1: 수동
  Claude Code에서 /news 치기 (추가 비용 없음)

레벨 2: 수집만 자동
  GitHub Actions로 수집 → 내가 /news로 리뷰 생성 (추가 비용 없음)

레벨 3: 완전 자동
  GitHub Actions로 수집 + OpenRouter API로 리뷰 생성 + 발송 (월 ~$3~10)
```

**추천: 레벨 1부터 시작해.** `/news` 한 번 치는 게 그렇게 힘든 일은 아니니까. 매일 치기 귀찮아지면 그때 레벨 3으로 올려.

## 한 줄 정리

수집과 발송은 무료로 자동화돼. AI 리뷰 생성만 API 요금이 들어 — 월 몇천 원이면 완전 자동화 가능해. 다음은 이 파이프라인을 다른 용도로 바꾸는 법.
