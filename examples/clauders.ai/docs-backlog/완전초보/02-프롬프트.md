**AI한테 뭘 시키든, 시키는 방법이 결과를 결정해.**

---

## 좋은 지시문이 뭐야?

세 가지만 기억해.

1. **명확함** — 뭘 해달라는 건지 한눈에
2. **구체적** — 범위, 조건, 형식을 명시
3. **예시 포함** — "이런 식으로 해줘"

| 구분 | 예시 |
|------|------|
| 나쁜 예 | "좋은 글 써줘" |
| 좋은 예 | "20대 직장인 대상, 친근한 말투로, 월요병 극복 팁 3가지 알려줘" |
| 나쁜 예 | "코드 짜줘" |
| 좋은 예 | "Python으로 1~10 출력하는 코드 짜줘. 주석도 달아줘" |

---

## 뭘 넣어야 해?

필요에 따라 조합해서 써. 매번 다 넣을 필요 없어.

| 요소 | 설명 | 예시 |
|------|------|------|
| 페르소나 | AI 역할 | "너는 10년차 마케터야" |
| 목적 | 뭘 해달라는 건지 | "블로그 글 써줘" |
| 배경 | 왜 필요한지 | "신제품 출시 홍보용" |
| 형식 | 결과물 모양 | "3문단, 각 100자 내외" |
| 제약사항 | 하면 안 되는 것 | "전문용어 쓰지 마" |

---

## 시스템 프롬프트가 뭐야?

AI의 "역할"을 미리 정해주는 거야.

```
너는 친절한 요리 선생님이야.
초보자도 이해할 수 있게 쉽게 설명해줘.
```

이렇게 정해두면 AI가 모든 대답을 그 느낌으로 해.

구체적인 페르소나를 주면 더 전문적인 답이 나와.

```
너는 2번의 엑싯 경험이 있는 실리콘밸리 연쇄창업가야.
{첨부한 문서}를 분석하고, 스타트업 초기 전략과 투자 유치 조언을 해줘.
```

---

## 왜 질문부터 시켜?

답부터 내놓으라 하지 마. AI한테 질문을 먼저 시켜봐.

```
나: 블로그 글 써줘
AI: (대충 아무 글이나 씀)

vs

나: 블로그 글 쓰려는데, 뭘 알아야 잘 써줄 수 있는지 물어봐
AI: 어떤 주제야? 대상 독자는? 글 길이는? 말투는?
나: (하나씩 답해줌)
AI: (맞춤형 좋은 글)
```

이걸 **소크라테스식 질문법**이라고 해.

> 답을 주는 게 아니라, 질문으로 스스로 답에 닿게 하는 방식이야.

---

## 아예 대화로 풀어봐

한 걸음 더 나가보자. 처음부터 완벽하게 지시하려 애쓰지 마.

뭘 만들지 흐릿할 땐 그냥 대화해. 이렇게.

```
나: 블로그 하나 만들고 싶은데 감이 안 와.
AI: 누구한테 읽히고 싶어?
나: 개발 시작한 지 얼마 안 된 사람.
AI: 그 사람이 지금 뭐가 제일 답답해?
나: ...설치하다 막히는 거?
AI: 그럼 "설치 에러 모음집"부터 써보면 어때?
나: 아, 그거네.
```

왜 이게 통해? 명령하려면 네가 이미 답을 알아야 해. 근데 대부분은 답을 모른 채 시작하거든.

흐릿하던 게 대화를 거치면서 또렷해져.

## 한 줄 정리

잘 시키는 게 핵심이야. 답 말고 질문부터 시켜봐.
