**AI한테 기술적으로 지시하고, 결과를 판단할 수 있는 바이브 코더가 되는 법.**

> 코딩 문법이 아니라, AI한테 "잘 시키는 법"을 배우는 30편짜리 시리즈야.

이 시리즈를 마치면 이런 대화가 가능해져:

```
나: "이 프로젝트에 맞는 아키텍처 추천해봐"
AI: "1. 레이어드 - 단순하고... 2. 클린 - 확장성..."
나: "우리는 규모가 작으니까 1번으로 가자.
    근데 서비스 레이어는 분리해줘."
```

AI가 추천하면, 뭐가 왜 좋은지 판단할 수 있는 수준.
기술 용어로 방향을 지시할 수 있는 수준.

---

## 구성

| 파트 | 편 | 배우는 것 |
|------|-----|----------|
| 시작하기 | 0~2 | 바이브 코딩이 뭔지, AI한테 어떻게 시키는지 |
| 도구 세팅 | 3~5 | Claude Code, 터미널, VS Code, Git |
| 큰 그림 | 6~9 | 프론트/백엔드, DB, API, 프로젝트 구조 |
| 할 일 앱 | 10~13 | 첫 프로젝트 만들고 배포까지 |
| 에러와 디버깅 | 14~15 | 에러 읽기, AI와 디버깅하기 |
| AI 서비스 | 16~19 | AI API 연결, 챗봇, 분석 서비스, 카카오톡 봇 |
| 자동화 | 20~22 | 뉴스 요약 봇, 정기 실행, 외부 API |
| 데이터 서비스 | 23~26 | DB 설계, CRUD, 대시보드, 설계 레벨업 |
| 다음 단계 | 27~29 | 고도화 가이드, 치트시트, 앞으로의 여정 |
