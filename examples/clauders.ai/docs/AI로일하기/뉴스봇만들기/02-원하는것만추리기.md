**수집된 기사가 들어오면, AI가 유형을 분류하고 전문 리뷰어가 한국어 리뷰를 써.**

```
hacker-news-agent-safehouse.md → dev_reviewer    → ✅ 리뷰 생성
hackernoon-ai-startups.md      → story_reviewer  → ✅ 리뷰 생성
producthunt-new-saas.md        → product_reviewer → ✅ 리뷰 생성
```

편집장이 기사를 읽고 담당 기자한테 넘기는 거야. 편집장도 AI고, 기자도 AI야.

---

## 콘텐츠 라우터가 뭐냐

**"이 기사는 누가 리뷰할지" 결정하는 AI**야.

기사를 읽고 키워드를 보고 유형을 판별해:

| 이런 게 보이면 | 이 리뷰어한테 보내 |
|---------------|------------------|
| GitHub URL, `npm install`, 코드 블록 | `dev_reviewer` (개발 도구) |
| Product Hunt, 가격표, "출시" | `product_reviewer` (서비스 리뷰) |
| MRR 숫자, "어떻게 ~했는가", 인터뷰 | `story_reviewer` (성공 사례) |

"Show HN: I built an open-source Notion alternative"라는 기사가 오면? GitHub URL이 있고, npm install이 있으니 → `dev_reviewer`로 보내.

---

## 리뷰어마다 뭘 다르게 쓰냐

각 리뷰어는 **전문 분야가 다르고, 리뷰 형식도 달라.**

| 리뷰어 | 뭘 쓰냐 |
|--------|---------|
| `dev_reviewer` | 설치법 + Claude Code 활용 프롬프트 + 사이드 프로젝트 아이디어 |
| `product_reviewer` | 활용 팁 + 비즈니스 기회 (개발 권장은 안 해) |
| `story_reviewer` | 핵심 교훈 + 내 상황에 적용법 + 생존자 편향 주의 |

`product_reviewer`가 "이거 Claude로 클론 코딩해봐!"라고 쓰면? 안 돼. 서비스 소개에 개발 권장은 맥락에 안 맞아. 이런 규칙이 각 리뷰어한테 있어.

---

## 리뷰는 누가 쓰냐 — LLM이 쓰고, 요금이 나와

여기서 중요한 게 하나 있어. **리뷰를 쓰는 건 LLM(대규모 언어 모델)이야.** 그리고 LLM은 공짜가 아니야.

1장에서 `npm run fetch`로 기사를 수집하는 건 **무료**야. RSS를 긁어오는 거니까.

근데 수집된 기사를 읽고 한국어 리뷰를 쓰는 건 **AI API를 호출**해야 해. 이때 토큰(글자 수) 기반으로 요금이 나와.

```
수집 (npm run fetch)     → 무료. RSS 긁기.
리뷰 생성 (AI API 호출)  → 유료. 토큰당 과금.
```

### 리뷰를 생성하는 방법은 세 가지야

| 방법 | 어떻게 동작하냐 | 비용 |
|------|---------------|------|
| Claude Code에서 수동 | `/news` 치면 Claude가 직접 리뷰 생성 | Claude Code 구독료에 포함 |
| OpenRouter API | 스크립트가 자동으로 API 호출 | 토큰당 과금 (~$0.001~0.01/기사) |
| Antigravity에서 수동 | AI 워크플로우 도구에서 실행 | 무료 플랜 있음 |

**가장 쉬운 건 Claude Code에서 `/news` 돌리는 거야.** 0장에서 해봤잖아. Claude Code 구독 안에서 다 처리돼.

**완전 자동화하고 싶으면** OpenRouter 같은 API를 써야 해. GitHub Actions에서 LLM API를 호출하는 거야. 이건 5장에서 다룰 거야.

**돈을 아끼고 싶으면** [Antigravity](https://antigravity.ai) 같은 AI 워크플로우 도구를 쓰면 돼. 수집된 기사를 넣고 리뷰 생성 워크플로우를 돌리면 돼. 프로젝트에 리뷰어별 프롬프트 템플릿이 다 준비돼 있어서 워크플로우에 그대로 연결하면 돼.

:::info 토큰이 뭐야?
AI가 글을 읽고 쓸 때 쓰는 단위야. 대충 한국어 1글자 = 2~3토큰 정도. 기사 하나를 읽고 리뷰를 쓰면 약 2,000~5,000토큰을 써. 모델에 따라 다르지만 기사 하나당 1원~10원 수준이야.
:::

## Skills가 뭐냐

바이브코딩에서 `CLAUDE.md` 만들었잖아. "이 프로젝트는 이렇게 해줘"라는 지침서.

**Skills도 같은 거야.** 다만 역할별로 나뉘어 있어.

```
.agent/skills/
├── content_router/    ← 편집장 (기사 분배)
├── dev_reviewer/      ← 개발 도구 담당 기자
├── product_reviewer/  ← 서비스 담당 기자
├── story_reviewer/    ← 사례 담당 기자
├── refine_content/    ← 교정 데스크
└── create_reviewer/   ← 새 기자 채용 가이드
```

각 폴더 안에 `SKILL.md`라는 마크다운 파일이 있어.

AI가 이 파일을 읽고 "아, 나는 개발 도구 리뷰어구나. 설치법이랑 프롬프트를 꼭 넣어야 하는구나" 하고 이해해.

CLAUDE.md가 "전체 프로젝트 규칙"이라면, SKILL.md는 "역할별 업무 지침서"야.

## 새 리뷰어가 필요하면 어떡하냐

YouTube 영상 리뷰가 필요해졌다고 해보자.

```
> YouTube 영상 리뷰용 리뷰어를 새로 만들어줘.
> 영상 요약 + 핵심 타임스탬프 + 한줄평 형식으로.
```

Claude Code가 `.agent/skills/` 폴더에 새 리뷰어를 만들고, 콘텐츠 라우터에 YouTube URL 트리거를 추가해줘.

바이브코딩에서 배운 대로야 — 코드가 아니라 "뭘 원하는지" 말하면 돼.

---

## 한 줄 정리

콘텐츠 라우터가 기사를 분류하고, LLM이 리뷰를 써. 수집은 무료, 리뷰 생성은 AI API를 쓰니까 방법에 따라 비용이 달라. 다음은 이 리뷰를 채널에 맞게 다듬는 법.
