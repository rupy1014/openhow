**`npm run fetch` 한 줄이면 10개 뉴스 소스에서 기사가 쏟아져.**

```
📡 RSS 수집 시작
  [hacker-news] 15개 확인 → 3개 신규
  [hackernoon] 10개 확인 → 2개 신규
  [marktechpost] 10개 확인 → 4개 신규
  ...
✅ 수집 완료 (9개 신규)
```

파이프라인의 첫 번째 단계야. 좋은 원재료가 안 들어오면 뒤에서 뭘 해도 소용없어.

---

## RSS가 뭐냐

**블로그의 택배 알림**이야.

블로그에 새 글이 올라오면, RSS 주소로 알림이 와. 우리는 그 주소를 등록해두고 "새 글 있어?" 하고 물어보는 거야.

```
일반 구독:  이메일 뉴스레터 신청 → 메일함에 옴
RSS 구독:   RSS URL 등록 → 프로그램이 자동으로 확인
```

RSS URL은 이렇게 생겼어:

```
https://hnrss.org/newest?points=100
https://hackernoon.com/feed
https://www.marktechpost.com/feed/
```

그냥 주소야. 이 주소를 프로그램에 넣으면 새 글 목록을 가져와.

---

## API는 뭐가 다르냐

RSS는 **구독 우편함**이야. 새 글이 쌓여 있으면 가져오는 거야.

API는 **직접 물어보는 창구**야. "오늘 인기 글 뭐야?" 하고 질문하면 답이 와.

```
RSS:  수동적. 쌓여 있는 걸 가져옴
API:  능동적. 조건을 걸어서 질문함
```

이 프로젝트에서는 둘 다 써. Hacker News는 API로, 나머지는 RSS로 가져와.

| 소스 | 방식 | 뭘 가져오냐 |
|------|------|-----------|
| Hacker News | API | 테크 커뮤니티 인기 글 |
| HackerNoon | RSS | AI 스타트업 트렌드 |
| MarkTechPost | RSS | AI 연구, 적용 사례 |
| The Bootstrapped Founder | RSS | 솔로프리너 운영기 |
| levels.io | RSS | 인디해커 실전기 |
| Trends.vc | RSS | AI 니치 시장 분석 |
| Product Hunt | API | 신제품 런칭 |
| Lenny's Newsletter | RSS | 프로덕트 전략 |
| SaaS Weekly | RSS | SaaS 트렌드 |
| Entrepreneurs Handbook | RSS | 창업 스토리 |

## RSS 없는 사이트는 어떡하냐

RSS를 안 만들어주는 사이트도 있어. Anthropic 블로그, Cursor Blog 같은 곳.

그러면 **직접 만들면 돼.** [Olshansk/rss-feeds](https://github.com/Olshansk/rss-feeds)라는 프로젝트가 딱 이걸 해:

```
GitHub Actions가 매시간 실행
  → 사이트 페이지를 읽어서
  → RSS 파일로 변환해서
  → GitHub에 저장
```

6장에서 이 패턴으로 아무 사이트든 RSS로 만드는 법을 다룰 거야.

## 어떻게 돌리냐

0장에서 `/workflow`로 한 번에 돌렸잖아. 수집만 따로 돌리고 싶으면:

**Step 1.** 프로젝트 폴더에서 수집 명령 실행

```bash
npm run fetch
```

**Step 2.** `content/오늘날짜/` 폴더 확인

```bash
ls content/2025-03-09/
```

수집된 기사들이 마크다운 파일로 쌓여 있어. 제목, 본문, 원문 링크까지 다 들어있어.

소스를 추가하고 싶으면 Claude Code에게 말하면 돼:

```
> RSS 소스에 GeekNews 추가해줘. URL은 https://news.hada.io/rss
```
