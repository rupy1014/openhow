**매일 아침, AI가 뉴스를 골라서 요약해서 카톡으로 보내줘.**

```
안녕하세요. 3월 9일(월) 바이브 코더를 위한 AI 브리핑입니다.
오늘 당장 써먹을 수 있는 '실전 AI 기술' 15가지를 요약했습니다.

[Today's AI News]

1. Claude Code, 멀티에이전트 워크플로우 지원 추가
2. Perplexity, 제로에서 90억 달러까지
3. MCP 서버 디버깅 도구 Inspector 출시
...
```

내가 안 해도 매일 이게 와. 이걸 지금부터 만들 거야.

---

## 바이브코딩이랑 뭐가 다르냐

바이브코딩에서는 **사람이 쓰는 앱**을 만들었어.

버튼 누르면 반응하는 UI.

뉴스봇은 달라. **시간이 되면 알아서 돌아가는 파이프라인**이야.

```
사람이 쓰는 앱:   버튼 클릭 → 화면 반응
뉴스봇:          매일 아침 8시 → 자동 수집 → 자동 요약 → 자동 발송
```

앱은 "사용자"가 트리거야. 뉴스봇은 "시간표"가 트리거야.

---

## 파이프라인이 뭐냐

뉴스봇의 전체 흐름은 6단계야:

```
모으기 → 분류하기 → 다듬기 → 퇴고 → 승인 → 릴리즈
```

| 단계 | 뭘 하냐 | 비유 |
|------|---------|------|
| 모으기 | 해외 뉴스 사이트에서 기사 수집 | 신문 배달 |
| 분류하기 | AI가 유형별로 분류하고 리뷰 작성 | 편집장이 기사 분배, 기자가 리뷰 |
| 다듬기 | 채널(카톡/웹/슬랙)에 맞게 포맷 변환 | 지면에 맞게 편집 |
| 퇴고 | 번역투 제거, 톤 맞춤, 사실 확인 | 데스크가 교정 |
| 승인 | 내가 훑어보고 OK 하기 | 최종 검토 |
| 릴리즈 | 카톡/Threads/웹에 발송 | 인쇄·배포 |

이 6단계를 하나씩 만들어갈 거야. 각 단계가 독립적이라서 소스만 바꾸면 경쟁사 모니터링 봇도 되고, 채용공고 봇도 돼.

## 일단 돌려보자

완성된 코드를 먼저 받아서 한번 돌려보자.

**Step 1.** [max5-clone.ai.zip 다운로드 (Google Drive)](https://drive.google.com/file/d/1tedjVB8XoLFY8fkCIc3-CRHzVPjfTyOn/view?usp=drive_link) 받아서 압축 풀기

```bash
unzip max5-clone.zip
cd max5-clone
npm install
```

**Step 2.** Claude Code를 열고 `/news` 실행

```bash
claude
```

```
/news
```

이거 하나면 수집 → 분류 → 리뷰 생성 → 퇴고까지 전부 돌아가:

```
📡 1단계: RSS 수집
  [hacker-news] 15개 확인 → 3개 신규
  [hackernoon] 10개 확인 → 2개 신규
  ...
✅ 수집 완료 (9개 신규)

🤖 2단계: AI 리뷰 생성
  hacker-news-agent-safehouse.md → dev_reviewer → ✅
  hackernoon-ai-startups.md → story_reviewer → ✅
  ...

✍️ 3단계: 퇴고
  번역투 제거, 톤 맞춤 ✅
```

**Step 3.** 결과 확인

```bash
npm run dev
```

브라우저에서 열면 완성된 리뷰가 보여. 이게 6단계 파이프라인이 한 번에 돌아간 결과야.

---

## 한 줄 정리

뉴스봇 = 6단계 파이프라인. `/news`로 한 번에 돌아가. 다음 장부터 각 단계가 뭘 하는지 하나씩 뜯어볼 거야.
