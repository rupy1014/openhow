**지금까지는 내가 `/workflow` 쳐야 돌아갔어. 이제 매일 아침 알아서 돌아가게 만들어.**

```

  → 뉴스 수집
  → AI 리뷰 생성
  → 퇴고
  → 카톡/슬랙 발송
```

내가 자는 동안 다 끝나 있어.

---

## cron이 뭐냐

**프로그램의 알람시계야.**

알람이 울리면 네가 일어나듯이, cron이 울리면 프로그램이 실행돼.

```
알람:  매일 아침 8시 → 나를 깨워
cron:  매일 아침 8시 → 이 스크립트를 실행해
```

cron 시간 표기법은 이렇게 생겼어:

```
0 8 * * *
│ │ │ │ │
│ │ │ │ └── 요일 (무관)
│ │ │ └──── 월 (무관)
│ │ └────── 일 (무관)
│ └──────── 시 (8시)
└────────── 분 (0분)
```

`0 8 * * *` = 매일 아침 8시 0분.

외울 필요 없어. Claude Code한테 "매일 아침 8시에 실행해줘"라고 하면 알아서 cron 표현을 만들어줘.

---

## 서버가 꼭 필요하냐

cron은 **누군가가 24시간 켜져 있어야** 돌아가. 세 가지 방법이 있어:

| 방법 | 특징 | 비용 | 추천 |
|------|------|------|------|
| 내 컴퓨터 cron | 컴퓨터 켜져 있을 때만 동작 | 무료 | 테스트용 |
| **GitHub Actions** | **24시간 동작, 설정 간단** | **무료** | **가장 추천** |
| VPS 서버 | 완전한 자유도 | 월 $5~ | 고급 |

## GitHub Actions가 뭐냐

**GitHub에서 코드를 대신 실행해주는 서비스야.**

바이브코딩에서 GitHub에 코드 올려봤잖아. GitHub Actions는 거기에 "이 코드를 **언제** 실행해줘"를 설정하는 거야.

```
Git push할 때:       코드 올리면 → 테스트 자동 실행
매일 아침 8시:       cron 설정 → 뉴스 수집 자동 실행
```

설정은 `.github/workflows/` 폴더에 `.yml` 파일 하나로 해. 이 파일이 "작업 지시서"야:

```yaml
name: 매일 뉴스 수집
on:
  schedule:
    - cron: '0 23 * * *'  # UTC 23시 = 한국시간 8시

jobs:
  fetch-news:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install
      - run: npm run fetch
      - run: node scripts/generate-newsletter.js
```

"매일 한국시간 8시에 수집하고, 뉴스레터를 만들어줘."

이걸 코드로 적은 거야.

:::info 환경변수는 어디에 넣어?
바이브코딩에서 Vercel에 환경변수 넣었잖아. GitHub Actions도 같아. GitHub 리포 Settings → Secrets에 넣으면 돼. `.env`에 있던 것들을 그대로 옮기는 거야.
:::

## 어떻게 설정하냐

**Step 1.** Claude Code에게 시키기

```
> GitHub Actions로 매일 아침 8시(한국시간)에
> 콘텐츠 수집 → 리뷰 생성 → 슬랙 발송하는 워크플로우 만들어줘.
```

**Step 2.** `.github/workflows/daily-news.yml` 파일이 생겨

**Step 3.** GitHub에 push

```bash
git add .github/workflows/daily-news.yml
git commit -m "매일 뉴스 수집 자동화"
git push
```

push하면 GitHub이 매일 아침 자동으로 돌려줘.
