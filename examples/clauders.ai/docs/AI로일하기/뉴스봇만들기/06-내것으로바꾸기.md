**소스를 바꾸고, 필터를 바꾸고, 채널을 바꾸면 — 전혀 다른 봇이 돼.**

파이프라인 구조는 그대로야. 각 단계의 내용만 바꾸면 돼.

```
모으기 → 분류하기 → 다듬기 → 퇴고 → 승인 → 릴리즈
```

---

## 같은 구조로 뭘 만들 수 있냐

| 만들고 싶은 봇 | 소스 바꾸기 | 리뷰어 바꾸기 | 채널 바꾸기 |
|---------------|-----------|-------------|-----------|
| 경쟁사 모니터링 | 경쟁사 블로그 RSS | 경쟁 분석 리뷰어 | Slack |
| 채용공고 봇 | 채용 사이트 RSS | 공고 요약 리뷰어 | 카카오톡 |
| 논문 요약 봇 | arXiv RSS | 논문 해설 리뷰어 | 이메일 |
| 트렌드 리포트 | 여러 뉴스 RSS | 트렌드 분석 리뷰어 | 웹사이트 |
| 유튜브 요약 봇 | YouTube RSS | 영상 요약 리뷰어 | Threads |

전부 같은 6단계 파이프라인이야. 레고 블록처럼 끼워 맞추는 거야.

---

## 어떻게 바꾸냐

Claude Code에게 말하면 돼. 예를 들어 경쟁사 모니터링 봇을 만든다면:

**Step 1.** 소스 바꾸기

```
> 소스를 경쟁사 블로그 3개로 바꿔줘:
> https://blog.competitor1.com/feed
> https://blog.competitor2.com/rss
> https://competitor3.com/blog.xml
```

**Step 2.** 리뷰어 바꾸기

```
> 경쟁사 분석용 리뷰어를 만들어줘.
> "뭘 출시했는지", "우리한테 위협인지", "대응 방안" 형식으로.
```

**Step 3.** 채널 바꾸기

```
> 결과를 슬랙 #competitive-intel 채널로 보내줘
```

3단계면 완전히 다른 봇이 돼.

---

## RSS가 없는 사이트는 어떡하냐

1장에서 소개한 [Olshansk/rss-feeds](https://github.com/Olshansk/rss-feeds) 패턴을 쓰면 돼.

```
> 이 사이트(https://competitor.com/blog)의 RSS 피드를 생성하는
> 스크래퍼를 만들어줘. GitHub Actions로 매시간 돌게.
```

Claude Code가 사이트를 분석해서 글 목록을 추출하는 스크립트를 만들어줘. 5장에서 배운 GitHub Actions로 매시간 돌리면 RSS가 없는 사이트도 자동 수집이 돼.

---

## 여기까지 온 거 한눈에

```
0장: 전체 지도            ← 파이프라인 이해 + /news로 한번에 돌려보기
 │
1장: 모으기              ← RSS, API로 수집
 │
2장: 분류 + 리뷰         ← AI가 유형별로 분류하고 리뷰 생성
 │
3장: 다듬기 + 퇴고        ← 채널별 포맷 + 교정
 │
4장: 승인 + 릴리즈        ← 검토하고 발송
 │
5장: 자동화              ← cron, GitHub Actions
 │
6장: 응용 (지금 여기)     ← 소스/리뷰어/채널 바꿔서 내 봇으로
```

바이브코딩에서 앱을 만드는 법을 배웠어. 여기서는 **파이프라인**을 만드는 법을 배운 거야.

코드를 직접 짜지 않아도 돼. "뭘 원하는지" 말하면 AI가 만들어줘. 그건 바이브코딩이랑 똑같아.
