> "뉴스 요약해서 매일 아침 알람 보내줘." AI가 만들어줬고, 실행하면 잘 돼.
> 근데 컴퓨터 끄니까 작동이 멈추는데?

**프로그램 종류가 다르면, 만들어지는 것 자체가 달라.**

AI한테 "앱 만들어줘"라고만 하면 AI가 추측해. 웹을 원했는데 모바일 앱이 나오면? **처음부터 다시** 만들어야 해.

오늘부터 **PART 3: 기술 개념 - 큰 그림**이 시작돼.

## 프로그램 종류는 왜 알아야 해?

같은 "할 일 관리" 기능도 **어디서 돌아가게 만드느냐**에 따라 완전히 다르게 만들어져.

```
📱 스마트폰 앱 → 앱스토어에서 다운, 스마트폰에서만 돌아감
🌐 웹 → 브라우저에서 접속, 설치 필요 없음
🤖 자동화/봇 → 사람이 안 열어도 자동으로 실행, 화면 없음
```

어디서 돌아가는지가 중요해: 웹(브라우저) vs 앱(폰) vs 봇(서버)
![어디서 돌아가는지가 중요해: 웹(브라우저) vs 앱(폰) vs 봇(서버)](./images/program_types_overview.png)

---

## 1. 웹 서비스

**브라우저에서 돌아가는 프로그램.**

- 설치 필요 없음 (URL만 알면 접속)
- 모든 기기에서 접속 가능
- 업데이트 쉬움 (고치면 바로 반영)
- 배포 쉬움

노션, 유튜브, 구글독스 전부 웹 서비스야. 브라우저에서 돌아가고, 설치 안 해도 돼.

**바이브 코더가 가장 많이 만드는 종류야.** 만들기도 쉽고, 배포도 쉽고, 고치기도 쉬워.

---

## 2. 모바일 앱

**스마트폰에 설치해서 쓰는 프로그램.**

카메라, GPS, 푸시 알림 같은 스마트폰 고유 기능이 필요할 때 만들어.

"크로스 플랫폼" 기술(React Native, Flutter)을 쓰면 한 번 만들어서 iOS/Android 둘 다 돌아가게 할 수 있어. 이걸 모르면 iOS용 따로, Android용 따로 만들게 돼.

```
이럴 때 웹으로: 빨리 만들어서 테스트, 컴퓨터에서도 써야 할 때, 설치 없이 바로 쓰게 하고 싶을 때
이럴 때 모바일 앱으로: 카메라/GPS 필요, 푸시 알림 중요, 오프라인에서도 써야 할 때
```

**바이브 코더 초보라면 웹부터 시작해봐.**

---

## 3. 자동화/봇

**사람이 직접 안 열어도 자동으로 실행되는 프로그램.**

화면이 없고, 정해진 작업을 자동으로 처리해.

- 마케팅 지표 자동 수집 → 매일 아침 슬랙으로
- 경쟁사 뉴스 모니터링 → AI가 요약해서 전송
- 고객 문의 자동 분류 → 긴급한 건 담당자한테 알림

**핵심은 "화면이 필요한지, 자동으로 돌아가는지"야.**

"뉴스 모아주는 거 만들어줘"라고만 하면 AI가 웹으로 만들 수도 있어. 매일 자동 실행을 원했다면 이렇게 말해야 해:

✅ "매일 아침 자동으로 뉴스 수집해서 슬랙으로 보내주는 스크립트 만들어줘"

---

## AI한테 정확히 말하는 법

막연한 "앱 만들어줘" vs 구체적인 "웹앱 만들어줘"
![막연한 "앱 만들어줘" vs 구체적인 "웹앱 만들어줘"](./images/ambiguous_vs_specific_request.png)

```
❌ "앱 만들어줘"
   → AI가 추측해서 만듦. 나중에 바꾸려면 전부 다시.

✅ "브라우저에서 돌아가는 웹앱으로 만들어줘"
   → 정확히 이해. 처음부터 제대로 만들어짐.
```

---

## 한 줄 정리

```
✅ 프로그램 종류는 "어디서 돌아가느냐"로 나뉨
   → 웹 (브라우저), 모바일 앱 (스마트폰), 자동화 (자동 실행)

✅ 바이브 코더 초보라면:
   1순위: 웹 서비스
   2순위: 자동화/봇
   3순위: 모바일 앱 (나중에)

✅ AI한테 요청할 때:
   "앱 만들어줘" (❌)
   → "브라우저에서 돌아가는 웹앱으로 만들어줘" (✅)
```
