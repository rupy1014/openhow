# 터미널이랑 익스텐션, 뭐가 달라?

이 질문 진짜 많이 받아. 그래서 물어본 대로 답해줄게.

## "VS Code에서 터미널로 쓰는 거랑 익스텐션으로 쓰는 거, 뭐가 달라?"

VS Code는 똑같이 켜.

근데 그 안에서 클로드 코드 부르는 길이 두 개야.

하나는 **아래쪽 까만 터미널 창에** `claude` **치기**.

하나는 **클로드 코드 익스텐션 켜기**. 별 모양(Spark) 아이콘 누르면 옆에 채팅 화면이 떠.

> 둘 다 똑같은 클로드야. 똑똑함은 차이 없어. 다른 건 "생긴 거"뿐이야.

## "그럼 익스텐션이 뭐가 더 좋은데?"

마우스로, 화면 보면서 하는 게 편해.

- 코드 바꿀 때 **나란히(빨강/초록)** 보여줘. 버튼 누르면 적용돼.
- 에디터에서 코드 드래그하면, 그 부분을 **자동으로** 클로드한테 넘겨.
- 대화를 **탭 여러 개**로 띄워. 이거 시켜놓고 저거 물어보기 좋아.

눈으로 확인하면서 천천히 가고 싶으면 익스텐션이야.

## "그럼 터미널은 왜 써?"

기능이 다 돼. 그리고 어디서나 똑같아.

- 슬래시 명령어, 스킬 같은 거 **전부** 돼.

왜 이게 중요하냐면, 익스텐션은 자주 쓰는 것만 돼. 전부는 아니거든.

- VS Code가 아니어도 똑같이 써. 가볍고 빨라.

> 근데 터미널로 써도 VS Code 안에서 `claude`를 돌리면, 코드 바뀔 때 diff는 똑같이 화면으로 떠. 그래서 둘은 섞어 써도 돼.

## "난 그래서 뭘 써야 해?"

- 화면 보면서 천천히 하고 싶어 → 익스텐션.
- 명령어 익숙하고 기능 다 쓰고 싶어 → 터미널.

근데 제일 많이 쓰는 건 **VS Code 터미널에서** `claude` **치기**야.

기능은 다 쓰면서, diff는 화면으로 보거든. 둘의 좋은 점만 가져가는 거야.

## 한 줄 정리

> 같은 클로드야. 익스텐션은 보기 편하고, 터미널은 다 돼. VS Code 터미널에서 `claude` 치면 둘 다 가져가.
