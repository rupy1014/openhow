**먼저 재. 고치는 건 그 다음.**

:::success 이 페이지가 끝나면
- 내 `CLAUDE.md` / `AGENTS.md` 가 권장 한도 안에 있는지 알아
- 어떤 규칙이 여러 파일에 복붙됐는지 알아
- 다음 페이지의 작업 목록이 손에 잡혀
:::

**사람이 하는 것**: 명령어 4개 실행, 결과 해석
**AI 가 하는 것**: (없음 — 사람이 직접 측정)
**해결 방식**: 측정
**걸리는 시간**: 10분

---

## 왜 진단부터?

다음 페이지([03. 청소](./03-청소-자르고-합치기))에서 AI 한테 시킬 거거든. "이 파일을 자르고 저 파일을 합쳐" 라고 시키려면 **어디가 무거운지 정확한 숫자** 가 있어야 해.

그래서 이 페이지의 결과물은 **하나의 진단표**. 03 의 입력으로 쓰여.

---

## 1. 줄 수 재기

Anthropic 공식 권장: **CLAUDE.md 는 200줄 이하.**

```bash
wc -l CLAUDE.md AGENTS.md MEMORY.md 2>/dev/null
find .claude -name "*.md" -exec wc -l {} \; | sort -rn | head -10
```

판정:

| 줄 수 | 상태 | 다음 액션 |
|-------|------|----------|
| ~100 | 좋아 | — |
| 100\~200 | OK | 더 늘리지 마 |
| 200\~300 | 위험 | 자를 거 찾아 ([03. 청소](./03-청소-자르고-합치기) 패턴 A or B) |
| 300+ | 빨간불 | 무조건 분리 ([03. 청소](./03-청소-자르고-합치기) 패턴 A) |

---

## 2. 중복 확인

`CLAUDE.md` 와 `AGENTS.md` 가 거의 같은 내용이면 둘 중 하나가 죽은 무게야.

```bash
diff CLAUDE.md AGENTS.md | wc -l
```

5줄 이하 차이면 통합 대상.

---

## 3. 복붙된 규칙 찾기

같은 경고/규칙이 여러 파일에 박혀있는지 봐.

```bash
grep -rn "DO NOT" .claude CLAUDE.md AGENTS.md 2>/dev/null
grep -rn "절대" .claude CLAUDE.md AGENTS.md 2>/dev/null
```

같은 문장이 3 곳 이상 나오면 → 단일 출처로 통합 대상.

---

## 4. 죽은 문서 찾기

`docs/` 루트에 ARCHIVED, DEPRECATED, OLD 가 섞여있으면 AI 가 매번 검색에 끌어와.

```bash
ls docs/ | head -30
grep -lr "ARCHIVED\|DEPRECATED\|OLD" docs/ 2>/dev/null
```

→ `docs/archive/` 로 이동 대상.

---

## 5. 결과를 진단표로 정리

다음 페이지가 이 표를 받아서 작업해. 적어두는 게 핵심이야.

```
# 진단 결과

| 파일 | 줄 수 | 상태 | 액션 |
|------|-------|------|------|
| CLAUDE.md | 470 | 빨간불 | 200줄로 자르기 |
| AGENTS.md | 470 | 중복 | 심볼릭 링크로 |
| .claude/commands/write.md | 262 | 위험 | 분리 |

복붙된 규칙: "DO NOT hardcode" 5곳, "tone: informal" 3곳
ARCHIVED 섞임: SERVICE-DIRECTION.md (30KB)
```
