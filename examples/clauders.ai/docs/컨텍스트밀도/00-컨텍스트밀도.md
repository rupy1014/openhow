**`CLAUDE.md` 가 길어질수록 Claude가 더 멍청해져.**

이 시리즈는 그걸 거꾸로 돌리는 법이야.

---

## 이 시리즈는 누구한테 필요해?

- `CLAUDE.md` / `AGENTS.md` 에 규칙을 계속 덧붙이고 있어
- "또 까먹었네" 가 자주 일어나
- 같은 잔소리(`DO NOT ...`)를 매번 프롬프트에 박고 있어
- `.claude/commands/` 에 명령어 MD 가 7개 넘어가서 관리가 힘들어

하나라도 해당하면 이 시리즈가 도움 돼.

---

## 30초 진단 — 내 프로젝트는 무거워?

세 개만 답해봐.

| 질문 | Yes 면 |
|------|--------|
| `CLAUDE.md` 가 200줄 넘어? | 무거움 |
| 같은 규칙이 여러 MD 파일에 복붙됐어? | 새고 있음 |
| 새 enum/상수 추가하면 5곳을 손으로 고쳐야 해? | 드리프트 위험 |

**Yes 가 1개 이상**이면 이 시리즈로 풀 수 있어.

## 진입 경로 — 누구는 어디부터?

**처음이면**: 01 부터 순서대로.

**위생만 급한 사람**: 02 → 03 만 해도 즉시 효과 (CLAUDE.md 가 짧아져서 돈 절약).

**이미 200줄 이하인 사람**: 04 → 05 또는 06 으로. 본인 상황 분류하고 한쪽만 봐도 OK.

**자동화에 관심**: 07. 단, 06 까지 끝낸 다음에 봐야 의미 있음.

## 핵심 원칙 (한 줄)

> **"왜" 는 MD 에, "뭘 / 어떻게" 는 코드 / 스키마 / 스크립트에.**

| 어디에? | 뭘? |
|---------|------|
| **MD** | 결정 배경, 비즈니스 맥락, 로드맵 |
| **코드** | enum, 상수, 타입 |
| **스키마** | API 형태, 검증 규칙 |
| **스크립트** | 반복 명령 |

이게 "내가 매번 잔소리할 일" 을 "AI 가 자동으로 지키게 만드는 일" 로 바꾸는 작업이야.
