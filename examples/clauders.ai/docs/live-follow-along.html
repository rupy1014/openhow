CLAUDE.md 첫 문단 만들기

목표: Claude가 내 프로젝트의 대상, 문제, 기준을 먼저 묻게 만들기

아래 질문을 하나씩 물어봐줘.
- 이 프로젝트는 누구를 위한 것인가
- 사용자가 겪는 문제는 무엇인가
- 이번 주에 만들 최소 기능은 무엇인가
- 만들지 않을 것은 무엇인가

한 번에 다 묻지 말고 첫 질문부터 시작해.

에러 질문 잘하기

목표: “고쳐줘” 대신 WHAT / WHERE / WHY / NEXT로 진단받기

따라 입력할 프롬프트

아래 에러를 보고 바로 고치지 말고 먼저 진단해줘.

1. WHAT: 무슨 에러인지
2. WHERE: 어느 파일/단계에서 난 것 같은지
3. WHY: 원인 후보 3개
4. NEXT: 내가 먼저 확인할 것 1개

에러 메시지:
[여기에 에러 붙여넣기]

AI 기다리는 동안 퀴즈

Q. 에러가 났을 때 제일 나쁜 질문은?

  1. 이 에러의 원인 후보를 알려줘
  2. 내가 먼저 확인할 것 하나만 알려줘
  3. 안 돼요. 고쳐줘
  4. 어느 파일에서 난 것 같은지 알려줘
정답: C — “안 돼요”만으로는 Claude가 원인, 위치, 다음 확인 행동을 잡기 어렵습니다.
