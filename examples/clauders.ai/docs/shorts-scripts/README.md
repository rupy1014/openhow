# 쇼츠 대본 제작 전략

**기존 문서가 이미 롱폼 원본입니다. 지금은 롱폼을 새로 만들 단계가 아니라, 원본에서 한 포인트씩 잘라 쇼츠로 뽑는 단계입니다.**

## 롱폼 먼저 만들어야 하나요?

이번 커리큘럼은 새 롱폼을 먼저 만들 필요가 없습니다.

이미 `docs/` 안에 긴 강의 문서가 있습니다. 그래서 순서는 이렇게 가면 됩니다.

```text
기존 강의 문서
→ 한 문서에서 한 포인트 추출
→ 30~45초 쇼츠 대본
→ 반응 좋은 쇼츠만 라이브/롱폼으로 확장
```

새 주제라면 다릅니다.

아직 생각이 정리 안 된 주제는 바로 쇼츠로 만들면 말이 얇아집니다. 그때는 먼저 1장짜리 롱폼 브리프를 쓰세요.

```text
왜 중요한가
누구에게 말하나
한 줄 결론은 무엇인가
오해하면 안 되는 것은 무엇인가
```

이 네 개가 잡히면 쇼츠로 잘라내도 됩니다.

## 쇼츠 포맷

각 대본은 같은 구조로 맞췄습니다.

- **Source**: 원본 문서
- **Hook**: 첫 2초 문장
- **Script**: 30~45초 말 대본
- **Visual**: 화면에 보여줄 것
- **CTA**: 다음 행동
- **Tone**: 유튜브용 존댓말 내레이션

## 제작 원칙

0. 유튜브 업로드용이므로 진행자 톤은 말하듯한 편한 존칭으로 갑니다. `합니다/입니다`보다 `해요/예요/거든요`를 우선하고, 시청자 호칭은 `여러분`으로 통일합니다.
1. 한 영상에 하나만 말합니다.
2. 설명보다 장면을 먼저 보여줍니다.
3. 튜토리얼은 명령어보다 결과를 먼저 보여줍니다.
4. 끝에는 저장·댓글·다음 강의 중 하나만 남겨요.
5. 안 되는 건 안 된다고 말합니다. 과장하지 마세요.
