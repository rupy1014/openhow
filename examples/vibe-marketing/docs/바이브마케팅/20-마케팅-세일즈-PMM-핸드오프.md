*검증 기준일: 2026-04-15 (HubSpot Academy + PMA 기준)*

**좋은 마케팅은 리드 생성에서 끝나지 않는다. 세일즈와 PMM이 같은 질문, 같은 포지셔닝, 같은 증거를 들고 움직여야 전환이 이어진다.**

---

마케팅은 리드를 넘겼다고 생각하고, 세일즈는 맥락이 부족하다고 느끼고, PMM은 현장 objection을 늦게 듣는 경우가 많다. 이때 제일 먼저 무너지는 건 메시지 일관성이다. 같은 질문이 들어왔는데 팀마다 다른 답을 하게 된다. 결국 고객은 불안해지고, 조직은 같은 설명을 반복해서 다시 만든다.

---

## 핸드오프에 필요한 정보

리드 자체보다 **맥락**이 중요하다.

| 항목 | 이유 |
| --- | --- |
| 유입 경로 | 어떤 문제 프레임으로 들어왔는지 보기 위해 |
| 소비한 자산 | FAQ, 비교표, 웨비나 등 무엇을 봤는지 알기 위해 |
| 세그먼트 | 역할/산업/팀 규모에 따라 메시지가 달라지기 때문 |
| 주요 질문 | 세일즈가 처음부터 다시 묻지 않기 위해 |
| objection | 가격/도입/보안/기능 중 어디에서 망설이는지 보기 위해 |

---

## PMM의 자리

PMA 관점에서 PMM은 메시지, enablement, launch를 잇는 역할을 한다. [출처](https://www.productmarketingalliance.com/)

실무로 옮기면 PMM은 아래를 연결한다.
- VOC → 포지셔닝 문장
- 경쟁 리서치 → 비교 자산
- 세일즈 objection → enablement 자료
- 마케팅 메시지 → 현장 대화 정합성

PMM은 브랜드 카피 팀이 아니라, **시장 언어를 조직 안으로 번역하는 허브**에 가깝다.

---

## 실제 핸드오프 문서의 최소 구성

1. 리드가 누구인지
2. 어떤 자산을 보고 들어왔는지
3. 어떤 질문을 했는지
4. 어떤 포지셔닝 문구가 먹혔는지
5. 다음 대화에서 무엇을 확인해야 하는지

이 다섯 개만 있어도 세일즈는 훨씬 덜 헤맨다.

---

## 흔한 실패 패턴

### MQL/SQL 숫자만 본다
숫자만 보면 왜 전환됐는지, 왜 막혔는지가 안 남는다.

### 세일즈가 매번 새로 설명한다
그러면 마케팅 자산이 축적되지 않는다.

### objection이 PMM으로 환류되지 않는다
그러면 같은 문제를 분기마다 다시 듣게 된다.

## 실습

1. 최근 리드 10개를 골라 본다
2. 유입 자산, 질문, objection, 세그먼트가 기록돼 있는지 본다
3. 빠진 필드를 정한다
4. 세일즈 전달 카드 1장을 표준화한다
