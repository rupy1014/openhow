**좋은 메시지는 회의실에서 갑자기 나오지 않는다. 오늘은 원문에서 고객 언어를 뽑고, 그 언어로 문제와 메시지를 만든다.**

---

## 오늘 만들 것

- [ ] 고객 언어 10개
- [ ] 반복 문제 5개
- [ ] 구매 직전 망설임 5개
- [ ] 원하는 결과 5개
- [ ] 메시지 초안 3개

---

## 완성 기준

- [ ] 고객 원문 10개를 모았다
- [ ] 문제 / 망설임 / 원하는 결과를 각각 5개씩 정리했다
- [ ] 그 재료를 바탕으로 메시지 3개를 썼다

---

## STEP 1. 원문을 먼저 모은다

팀노트AI 예시에서 먼저 쓸 수 있는 원문은 아래와 같다.

- “회의는 많은데 남는 게 없어요”
- “좋은 표현이 콜 안에 있는데 다시 못 찾아요”
- “세일즈, 마케팅, CS가 같은 문장을 안 써요”
- “후속 메일이 늘 늦어져요”
- “도입은 쉬운데 팀원 교육이 걱정돼요”
- “FAQ는 있는데 실제 질문과 안 맞아요”
- “경쟁사보다 뭐가 다른지 설명이 길어져요”
- “고객 인터뷰를 했는데 문서가 흩어져 있어요”
- “데모 뒤에 뭘 보내야 할지 항상 고민돼요”
- “상담 내용을 랜딩 문장으로 못 옮기겠어요”

이렇게 원문을 먼저 적고, 요약은 나중에 한다.

> **확인**: “내가 고친 문장”이 아니라 “고객이 실제로 할 법한 말”이 10개 모였는지 본다.

---

## STEP 2. 비슷한 말을 묶어 문제 / 망설임 / 원하는 결과로 정리한다

이제 원문을 세 묶음으로 나눈다.

### 문제 5개

| 문제 | 연결되는 원문 예시 |
|------|------------------|
| 기록은 많은데 정리가 안 남는다 | “회의는 많은데 남는 게 없어요” |
| 좋은 고객 언어를 다시 못 찾는다 | “좋은 표현이 콜 안에 있는데 다시 못 찾아요” |
| 팀마다 메시지가 달라진다 | “세일즈, 마케팅, CS가 같은 문장을 안 써요” |
| 후속 조치가 느리다 | “후속 메일이 늘 늦어져요” |
| 질문과 자산이 연결되지 않는다 | “FAQ는 있는데 실제 질문과 안 맞아요” |

### 구매 직전 망설임 5개

- 도입은 쉬운데 팀원 교육이 걱정된다
- 회의록 도구와 뭐가 다른지 애매하다
- 우리 팀에도 바로 맞을지 모르겠다
- 세일즈와 마케팅이 함께 쓸 수 있을지 확신이 없다
- 새 도구를 또 추가하는 부담이 있다

### 원하는 결과 5개

- 콜 뒤 정리 시간이 줄어든다
- 고객 언어를 다시 쉽게 찾는다
- FAQ와 랜딩 문장이 실제 질문과 맞아진다
- 후속 메일이 더 빨라진다
- 팀이 같은 설명을 쓰게 된다

> **확인**: 문제 / 망설임 / 원하는 결과가 각각 따로 보이도록 정리한다.

---

## STEP 3. 태그를 붙여 우선순위를 정한다

워크시트 팩 기준으로 아래 태그를 같이 붙인다.

| 원문 | 태그 예시 |
|------|-----------|
| 회의는 많은데 남는 게 없어요 | 문제 / 결과 / 운영 |
| 도입은 쉬운데 팀원 교육이 걱정돼요 | 망설임 / 도입 / 비교 |
| FAQ는 있는데 실제 질문과 안 맞아요 | 문제 / 비교 / FAQ |

이렇게 태그를 붙여 두면 FAQ, 랜딩, 메일로 옮길 때 훨씬 쉽다.

---

## STEP 4. 문제를 메시지 초안 3개로 바꾼다

문제를 그대로 반복하면 불평이 되고,
문제를 결과로 바꾸면 메시지가 된다.

### 메시지 초안 1
```text
흩어진 인터뷰와 상담 기록을 한곳에 정리해 팀이 같은 질문에 더 빨리 답하게 하세요.
```

### 메시지 초안 2
```text
고객이 실제로 한 말을 다시 찾고, FAQ·랜딩·후속 메일로 바로 다시 쓰세요.
```

### 메시지 초안 3
```text
세일즈, 마케팅, CS가 각자 다른 설명을 하지 않도록 고객 언어를 한 흐름으로 연결하세요.
```

좋은 메시지는 아래 세 가지를 같이 담는다.

1. 누구의 문제인가
2. 어떤 불편을 줄이나
3. 어떤 결과를 주나

## 예시 답안 요약

### 고객 언어 10개
- 회의는 많은데 남는 게 없어요
- 좋은 표현이 콜 안에 있는데 다시 못 찾아요
- 세일즈, 마케팅, CS가 같은 문장을 안 써요
- 후속 메일이 늘 늦어져요
- 도입은 쉬운데 팀원 교육이 걱정돼요
- FAQ는 있는데 실제 질문과 안 맞아요
- 경쟁사보다 뭐가 다른지 설명이 길어져요
- 고객 인터뷰를 했는데 문서가 흩어져 있어요
- 데모 뒤에 뭘 보내야 할지 항상 고민돼요
- 상담 내용을 랜딩 문장으로 못 옮기겠어요

### 문제 5개
- 기록이 흩어진다
- 고객 언어를 다시 못 찾는다
- 팀 메시지가 어긋난다
- 후속 조치가 늦다
- 질문과 자산이 연결되지 않는다

### 구매 직전 망설임 5개
- 팀원 교육이 번거로울 것 같다
- 기존 회의록 도구와 차이가 애매하다
- 우리 팀에도 바로 맞을지 모르겠다
- 세일즈와 마케팅이 함께 쓸 수 있을지 불안하다
- 새 도구를 추가하는 부담이 있다

### 원하는 결과 5개
- 정리 시간이 줄어든다
- 고객 언어를 다시 쉽게 찾는다
- FAQ와 랜딩이 실제 질문과 맞아진다
- 후속 메일이 빨라진다
- 팀이 같은 설명을 쓰게 된다

### 메시지 3개
- 고객 언어를 한곳에 정리해 같은 질문에 더 빠르게 답하게 한다
- 인터뷰와 상담 기록을 FAQ·랜딩·메일로 바로 다시 쓰게 한다
- 팀마다 다른 설명을 줄이고 일관된 메시지를 만든다

## 자주 하는 실수

- 원문을 너무 빨리 예쁘게 고친다
- 문제와 메시지를 섞어서 쓴다
- 증거 없는 좋은 말만 남긴다
- 고객 언어보다 회사 언어가 많아진다
