| 변경 유형 | 내용 |
|-----------|------|
| 추가 | 04강 Quick Win (신규) |
| 삭제 | v1 06강 "고객이 돈을 내는 순간" → Part 3 가격/오퍼(20강)에 흡수 |

| 삭제 | v1 35강 "운영 보드 만들기" → 36강에 흡수 |

| 승격 | 확장판 "SEO/커뮤니티/광고 시점" → 본편 35강 |
| 번호 변경 | Part 0: 3강→4강, Part 1: 6강→5강. 이후 번호 동일 |

## 상태 기준
- **재사용**: 기존 본문을 거의 그대로 쓸 수 있음
- **재서술**: 기존 본문은 있지만 초보자용으로 다시 써야 함
- **신규**: 기존에 직접 대응하는 본문이 없음
