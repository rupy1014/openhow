**코스 전체를 같은 맥락으로 따라가려면, 모두가 같은 제품을 놓고 연습하는 게 가장 빠르다.**

---

## 먼저 이 장면부터 보자

마케팅 강의를 듣는다.
"고객 문제를 정의해 보세요"라고 한다.
근데 내 제품이 아직 없거나, 있어도 막상 적으려니 막막하다.

이럴 때 가장 좋은 방법은 **샘플 비즈니스 하나를 같이 보면서 연습하는 것**이다.
내 제품에 대입하기 전에, 감을 먼저 잡는 거다.

이 코스에서는 **팀노트AI**라는 가상의 B2B SaaS를 처음부터 끝까지 예시로 쓴다.

---

## 왜 공통 예시가 필요한가

- 매 강의마다 "내 제품으로 해보세요"만 반복하면, 초반에 감을 못 잡는다
- 같은 제품을 놓고 연습하면, 강의 사이의 연결이 보인다
- 리서치 → 메시지 → 랜딩 → 이메일까지 하나의 흐름으로 체험할 수 있다
- 샘플로 감을 잡은 뒤, 내 제품에 대입하면 훨씬 빠르다

---

## 팀노트AI 한눈에 보기

### 한 줄 소개
고객 인터뷰, 상담 통화, 회의 메모를 자동으로 정리해서
팀이 바로 FAQ, 세일즈 메모, 후속 이메일에 재사용하게 도와주는 작은 B2B SaaS.

### 1차 타깃
- 5~50명 규모의 작은 B2B 팀
- 고객 인터뷰, 세일즈 콜, 데모 콜이 잦은 팀
- Notion, Google Docs, Slack을 함께 쓰는 팀

### 고객이 겪는 문제
1. 회의와 인터뷰는 많이 하지만 정리가 흩어진다
2. 같은 질문에 팀마다 다른 답을 한다
3. 좋은 고객 언어가 있어도 랜딩/FAQ/메일로 연결되지 않는다
4. 상담 뒤 후속 메일과 다음 액션이 느리다

### 고객이 실제로 할 법한 말
- "회의는 많은데 남는 게 없어요"
- "좋은 표현이 콜 안에 있는데 다시 못 찾아요"
- "세일즈, 마케팅, CS가 같은 문장을 안 써요"
- "후속 메일이 늘 늦어져요"

### 핵심 약속
회의와 인터뷰에서 나온 고객 언어를 바로 정리하고, 태깅하고, 다시 쓰게 만든다.

### 차별점
1. 단순 회의록이 아니라 **마케팅/세일즈 재사용**까지 연결한다
2. 질문, objection, 원하는 결과를 구조적으로 뽑아낸다
3. FAQ / 랜딩 / 후속 메일 / CRM 메모로 다시 쓰기 쉽게 설계한다

---

## 코스에서 이 예시를 쓰는 방식

| 파트 | 팀노트AI로 연습하는 것 |
|------|----------------------|
| 리서치 | 고객/문제/오퍼 정의, 고객 언어 수집 |
| 포지셔닝 | 포지셔닝 문장, 경쟁사 비교 |
| 랜딩 | 랜딩과 FAQ 초안 작성 |
| 콘텐츠 | 인터뷰 원본을 콘텐츠로 재가공 |
| 이메일 | 데모 신청자 후속 이메일 설계 |
| 운영 | 질문/신뢰 지표와 90일 계획 |

---

## 정리표: 팀노트AI vs 내 제품

아래 표의 오른쪽 칸은 비워 뒀다. 이 코스를 진행하면서 하나씩 채워 보자.

| 항목 | 팀노트AI | 내 제품 |
|------|---------|---------|
| 한 줄 소개 | 회의/인터뷰 자동 정리 → 재사용 | |
| 타깃 고객 | 5~50명 B2B 팀, 고객 통화 잦은 팀 | |
| 고객의 핵심 문제 | 회의 정리가 흩어지고 재사용이 안 됨 | |
| 대안(경쟁) | 직접 정리, 회의록 도구, 일반 AI 노트 | |
| 차별점 | 단순 요약이 아닌 마케팅/세일즈 재사용 | |

---

## 막히는 지점

**"내 제품은 팀노트AI랑 너무 다른데요?"**
괜찮다. 예시의 역할은 "정답"이 아니라 "감 잡기"다.
B2C든 하드웨어든, 고객-문제-오퍼-메시지 구조는 똑같다.
팀노트AI로 흐름을 한 번 체험하고, 내 제품에 대입하면 된다.

- [ ] 내 제품과 팀노트AI의 공통점이 1개 이상 떠오르는가?

---

## Micro-Action

> **팀노트AI와 내 제품의 공통점 1개를 적어 보자.**
>
> 예시: "우리도 고객 데이터를 정리해서 팀이 재사용하는 구조다"
>
> 공통점이 안 떠오르면, "둘 다 고객의 ___을/를 해결한다"로 시작해 보자.
> 적을 곳이 없으면 위 비교표의 오른쪽 칸 하나만 채워도 된다.
