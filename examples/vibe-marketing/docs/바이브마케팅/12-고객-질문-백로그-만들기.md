*검증 기준일: 2026-04-15 (HubSpot Academy + Google Search AI Mode + 사례 문서 기준)*

**AI 시대 마케팅의 핵심 자산은 키워드 목록보다 질문 백로그다. 고객은 점점 더 긴 질문을 던지고, 답을 비교한 뒤, 다시 커뮤니티에서 확인한다.**

---

어떤 팀은 키워드 캘린더를 열심히 만든다. 어떤 팀은 경쟁사 블로그 주제를 따라간다. 어떤 팀은 알고리즘이 좋아할 만한 포맷을 먼저 찾는다. 그런데 세일즈 콜을 들어보면 고객은 전혀 다른 식으로 말한다. "우리 팀도 바로 쓸 수 있나요?" "기존 방식보다 뭐가 쉬워지죠?" "도입하면 누가 관리해야 하나요?"

좋은 마케팅 자산은 대개 이런 질문들에서 시작한다. 그래서 AI 시대에는 키워드 목록보다 **질문 백로그**가 더 중요해진다.

Google은 2025년 3월 5일 AI Mode를 소개하면서, 사용자가 더 복잡하고 긴 질문을 던지고 후속 질문으로 더 깊게 탐색하는 흐름을 강조했다. 검색은 링크 클릭 이전에 이미 질문과 답변의 왕복 구조로 바뀌고 있다. [출처](https://blog.google/products/search/ai-mode-search/)

---

## 질문 백로그가 하는 일

### 추측으로 콘텐츠를 만들지 않게 한다
질문이 없으면 팀은 내부에서 중요해 보이는 것, 경쟁사가 하는 것, 채널 알고리즘이 좋아할 것 같은 것을 만든다. 질문 백로그가 있으면 출발점이 달라진다.

### 검색, 세일즈, CS를 묶어 준다
질문은 한 부서에만 있지 않다.
- 검색어
- 세일즈 콜
- 고객 지원 티켓
- 커뮤니티 댓글
- 데모 전 문의
이 전부가 같은 문제의 다른 표정일 수 있다.

### AI 활용의 품질을 높인다
질문 백로그가 있으면 AI에게 FAQ 초안, 비교 페이지 초안, objection 분류, 세그먼트별 메시지 정리를 훨씬 정확하게 시킬 수 있다.

---

## 질문은 어디서 모이는가

### 세일즈 콜 / 데모 요청 전후
구매 직전 질문이 가장 진하다.
- 가격
- 도입 기간
- 기존 툴과 차이
- 보안/운영 리스크

### 고객 지원 / 문의 채널
도입 후 질문은 유지와 확장에 중요하다.
- 설정
- 온보딩
- 실패 상황
- 기대와 현실의 차이

### 검색어 / 검색 콘솔 / 사이트 검색
검색은 고객이 사람 앞에서 말하기 전 단계의 질문을 드러낸다.

### 커뮤니티 / Reddit / Discord / 슬랙
이 구간은 브랜드가 없는 자리에서 나오는 언어가 많다.

### Build in Public 반응
업데이트 글에 달리는 댓글, DM, 인용 포스트는 초기 메시지 검증 데이터다.

---

## 질문 백로그의 기본 필드

복잡하게 시작할 필요는 없다. 아래 7개면 충분하다.

| 필드 | 설명 |
| --- | --- |
| 질문 원문 | 고객이 실제로 한 말 |
| 출처 | 세일즈, 커뮤니티, 검색, CS 등 |
| 단계 | 인지 / 비교 / 구매 / 도입 / 유지 |
| 주제 | 가격, 경쟁사, 기능, 보안, 도입 등 |
| 강도 | 얼마나 자주/강하게 나오는지 |
| 현재 답변 자산 | 이미 답하는 FAQ/문서/영상이 있는지 |
| 다음 액션 | 새 자산 제작, 기존 자산 수정, 세일즈 자료 반영 등 |

중요한 건 정리된 문장보다 **원문 표현**을 남기는 것이다.

---

## 운영 원칙

### 원문을 먼저 저장한다
AI나 사람이 요약하기 전에 고객 원문을 남겨야 한다. 나중에 메시지로 쓸 때 차이가 크다.

### 주간 1회는 반드시 리뷰한다
질문은 쌓아두기만 하면 방치된다. 적어도 주 1회는 아래를 본다.
- 새로 많이 들어온 질문
- 아직 답변 자산이 없는 질문
- 전환에 직접 연결되는 질문

### 질문을 자산으로 바꾼다
좋은 질문 백로그는 결국 아래 중 하나로 변해야 한다.
- FAQ
- 비교표
- 랜딩 섹션
- 세일즈 원페이저
- 이메일 시퀀스
- 데모 스크립트

### 부서별로 따로 두지 않는다
마케팅용 질문표, 세일즈용 질문표, CS용 질문표를 따로 두면 같은 질문이 흩어진다.

## AI를 붙이는 방법

HubSpot Academy가 말하는 customer insights와 personalization을 실무로 내리면, 질문 백로그는 AI의 가장 좋은 입력 데이터 중 하나가 된다. [출처](https://academy.hubspot.com/courses/AI-for-Marketers)

```text
아래 질문 백로그를 읽고,
1) 인지 단계 질문 5개
2) 비교 단계 질문 5개
3) 구매 직전 objection 5개
4) FAQ로 바로 전환할 항목 5개
5) 세일즈 원페이저로 보내야 할 항목 3개
를 분류해줘.
원문 표현은 유지해줘.
```

---

## 실습

1. 세일즈/CS/커뮤니티에서 질문 30개를 모은다
2. 위 7개 필드로 표를 만든다
3. 답변 자산이 없는 질문 5개를 고른다
4. 이번 주 콘텐츠/세일즈 작업은 그 5개부터 만든다
