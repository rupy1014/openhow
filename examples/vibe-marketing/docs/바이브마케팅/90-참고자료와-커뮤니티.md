## 0. 핵심 스토리 소스

### Kevin Kelly — 1,000 True Fans
- 링크: https://kk.org/thetechnium/1000-true-fans/
- 확인 포인트:
  - 초기 창작자/메이커는 대중적 히트보다 깊은 팬층을 먼저 확보하는 편이 현실적
  - 직접 관계를 맺는 팬 기반이 장기적인 지속 가능성을 만든다
- 이 커리큘럼에 준 영향:
  - 초반 학습 흐름을 `1,000명의 진짜 팬`에서 시작하게 함

### Andrew Chen — retention, virality, cold start
- retention + virality: https://andrewchen.com/more-retention-more-viral-growth/
- cold start: https://andrewchen.com/chapter-one-cold-start/
- 확인 포인트:
  - 바이럴은 공유 기능만이 아니라 retention이 붙는 구조여야 유지된다
  - 네트워크적 제품은 작은 작동 네트워크를 먼저 만들어야 한다
- 이 커리큘럼에 준 영향:
  - `첫 50명/100명/첫 매출`, `바이럴은 설계하는 것`의 핵심 근거

## 4. 자료를 종합해 얻는 결론

### 결론 1. AI 교육은 기초 + 운영 + 거버넌스까지 가야 한다
기초 prompting만으로는 부족하다.
정책, roadmap, team model까지 들어가야 팀에 남는다.

### 결론 2. 검색은 커뮤니티와 분리해서 가르치면 안 된다
AI 검색은 질문, 비교, 인용, 커뮤니티 권위를 같이 본다.

### 결론 3. 마케팅 커리큘럼은 포지셔닝 중심으로 돌아와야 한다
콘텐츠 양산보다,
리서치 → 포지셔닝 → 메시지 → 자산 설계가 더 중요하다.

### 결론 4. 마지막은 팀 운영이다
대시보드, 검수 기준, 역할 분담, 90일 실행 로드맵이 있어야
AI가 팀에 내재화된다.
