**랜딩은 예쁜 소개문이 아니라 고객 질문을 멈추게 하는 페이지다. 오늘은 팀노트AI 기준으로 한 페이지 초안을 끝까지 써본다.**

---

## 오늘 만들 것

- [ ] 헤드라인 1개
- [ ] 서브헤드 1개
- [ ] 핵심 혜택 3개
- [ ] FAQ 3개
- [ ] 가격/오퍼 블록 1개
- [ ] CTA 1개

---

## 완성 기준

- [ ] 누구/문제/결과가 헤드라인과 서브헤드에 보인다
- [ ] 혜택 3개가 기능이 아니라 결과 중심이다
- [ ] 가격/오퍼 블록이 "누구를 위한 것인지 + 결과"로 적혀 있다
- [ ] FAQ 3개와 CTA 1개까지 한 번에 정리했다

---

## STEP 1. 헤드라인과 서브헤드를 쓴다

팀노트AI의 핵심 문제는 “콜은 많은데 정리가 안 남는다”다.
이 문제를 그대로 보이게 쓴다.

### 헤드라인 예시
```text
콜은 많은데 정리가 안 남는 팀을 위해,
고객 언어를 FAQ·세일즈 메모·후속 메일로 바로 다시 쓰게 하세요.
```

### 서브헤드 예시
```text
팀노트AI는 흩어진 인터뷰와 상담 기록을 정리하고 태깅해,
세일즈·마케팅·CS가 같은 질문에 더 빠르고 일관되게 답하게 돕는다.
```

> **확인**: 누가, 어떤 문제를, 어떤 결과로 푸는지 10초 안에 보이는가?

---

## STEP 2. 핵심 혜택 3개를 적는다

기능 나열 대신 결과 중심으로 적는다.

| 구역 | 초안 |
|------|------|
| 혜택 1 | 고객이 실제로 한 말을 다시 찾는 시간을 줄인다 |
| 혜택 2 | FAQ, 세일즈 메모, 후속 메일에 같은 언어를 재사용하게 한다 |
| 혜택 3 | 팀마다 다른 설명을 줄이고 메시지를 맞춘다 |

짧게 말하면 아래 구조가 좋다.

```text
무엇을 줄이는가 + 무엇을 더 잘하게 만드는가
```

---

## STEP 3. FAQ 3개와 CTA 1개를 붙인다

랜딩에서 자주 막히는 질문을 바로 처리한다.

### FAQ 예시

**Q1. 이건 회의록 도구와 뭐가 다른가요?**
A. 단순 기록 저장이 아니라, 고객 언어를 FAQ·랜딩·후속 메일로 다시 쓰게 만드는 데 초점이 있다.

**Q2. 누가 주로 쓰나요?**
A. 고객 인터뷰와 상담 콜이 잦은 작은 B2B 팀이 가장 먼저 효과를 본다.

**Q3. 도입하면 바로 무엇이 달라지나요?**
A. 콜 뒤 정리 시간이 줄고, 같은 질문에 팀이 더 일관되게 답하게 된다.

### CTA 예시
```text
실제 고객 언어 정리 예시 보기
```

지금 단계에서는 “무조건 가입”보다
“다음 이해 단계로 가는 CTA”가 더 자연스럽다.

---

## STEP 4. 가격/오퍼 블록을 붙인다

20강에서 배운 원칙을 적용한다: 기능이 아니라 **”누구를 위한 것인지 + 결과”**로 쓴다.

### 가격 블록 예시

| 플랜 | 대상 | 핵심 결과 | 가격 |
|------|------|-----------|------|
| 솔로 | 혼자 인터뷰 정리하는 1인 | 콜 끝나면 5분 안에 요약이 온다 | 월 19,000원 |
| 팀 | 팀원 5명까지 | 팀이 같은 FAQ로 답한다 | 월 49,000원 |
| 비즈니스 | 팀 무제한 + CRM | 세일즈콜 후속이 자동으로 잡힌다 | 월 99,000원 |

핵심 체크:
- 각 플랜에 “누구를 위한 것인지” 한 줄이 있는가
- 가격 아래에 “무료 체험 시작” 같은 **다음 행동 CTA**가 있는가

> **확인**: 가격 블록까지 붙이면 랜딩 초안이 완결된다.

| 구역 | 초안 |
|------|------|
| 헤드라인 | 콜은 많은데 정리가 안 남는 팀을 위해, 고객 언어를 FAQ·세일즈 메모·후속 메일로 바로 다시 쓰게 하세요 |
| 서브헤드 | 팀노트AI는 흩어진 인터뷰와 상담 기록을 정리하고 태깅해, 세일즈·마케팅·CS가 같은 질문에 더 빠르고 일관되게 답하게 돕는다 |
| 혜택 1 | 고객이 실제로 한 말을 다시 찾는 시간을 줄인다 |
| 혜택 2 | FAQ, 랜딩, 후속 메일에 같은 언어를 재사용하게 한다 |
| 혜택 3 | 팀마다 다른 설명을 줄이고 메시지를 맞춘다 |
| FAQ 1 | 회의록 도구와 뭐가 다른가요? |
| FAQ 2 | 누가 가장 먼저 쓰나요? |
| FAQ 3 | 도입하면 바로 무엇이 달라지나요? |
| 가격 | 솔로 19K / 팀 49K / 비즈니스 99K — 대상과 핵심 결과 포함 |
| CTA | 실제 고객 언어 정리 예시 보기 |

## 자주 하는 실수

- 헤드라인에 기능이 너무 많다
- 고객 질문보다 회사 설명이 길다
- FAQ가 너무 아래로 밀린다
- CTA가 너무 막연하다
