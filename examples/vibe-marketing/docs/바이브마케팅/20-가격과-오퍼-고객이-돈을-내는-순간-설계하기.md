**랜딩에 기능도 적고 FAQ도 달았는데, 가격 페이지에서 이탈한다. 문제는 가격이 비싸서가 아니라, "이 돈을 내면 뭘 얻는지"가 안 보이기 때문이다.**

---

## 먼저 이 장면부터 보자

팀노트AI가 무료 체험 후 유료 전환 페이지를 만들었다.

```
스타터: 월 29,000원
프로: 월 79,000원
엔터프라이즈: 문의
```

3주 뒤 결과: 체험 100명 중 유료 전환 2명.

창업자가 가격을 낮추려고 한다.
그런데 문제는 가격이 아니었다.

고객은 "월 29,000원"이 아니라
**"월 29,000원을 내면 뭐가 달라지는데?"**를 보고 있었다.

---

## 핵심 개념: 가격이 아니라 오퍼를 설계한다

| 흔한 착각 | 실제 |
|-----------|------|
| 가격이 비싸서 안 산다 | 가격 대비 **얻는 것**이 안 보여서 안 산다 |
| 플랜을 3개 만들면 된다 | 플랜 차이가 **고객 문제 기준**이 아니면 혼란만 준다 |
| 무료 체험이면 전환된다 | 체험 중에 **"아, 이거 없으면 곤란하겠다"**를 못 느끼면 안 산다 |

**오퍼 = 가격 + 포함 내용 + 약속한 결과**

가격만 적는 건 메뉴판 없이 숫자만 보여주는 것과 같다.

---

## 오퍼를 설계하는 3단계

### 1단계. 고객 문제 기준으로 플랜을 나눈다

기능 수로 나누지 말고, **고객이 겪는 문제의 크기**로 나눈다.

| 접근 | 예시 |
|------|------|
| 기능 기준 (나쁨) | 스타터: 녹음 50시간 / 프로: 녹음 무제한 |
| 문제 기준 (좋음) | 스타터: 혼자 쓰는 프리랜서 / 프로: 팀이 같이 쓰는 5인 이상 |

팀노트AI 예시:

```
솔로: 혼자 인터뷰 정리하는 1인 — 월 19,000원
팀: 팀원 5명까지, 공유 FAQ 보드 — 월 49,000원
비즈니스: 팀 무제한 + CRM 연동 — 월 99,000원
```

각 플랜 이름이 **"누구를 위한 것인지"**를 바로 알려준다.

### 2단계. 각 플랜에 "이걸 얻는다"를 적는다

기능 목록이 아니라 **결과 문장**으로 적는다.

| 기능 나열 (나쁨) | 결과 문장 (좋음) |
|-----------------|-----------------|
| 월 100건 요약 | 회의 끝나고 5분 안에 요약이 온다 |
| FAQ 자동 생성 | 고객 질문을 다시 타이핑하지 않아도 된다 |
| CRM 연동 | 세일즈콜 끝나면 후속 메일이 자동으로 잡힌다 |

### 3단계. 비교 기준을 명확하게 한다

고객은 플랜을 비교할 때 **"나한테 뭐가 더 필요한데?"**를 본다.

| 비교 기준 | 솔로 | 팀 | 비즈니스 |
|-----------|------|-----|----------|
| 혼자 쓸 때 | 충분 | - | - |
| 팀원과 공유 | - | 여기 | - |
| CRM에 자동 연결 | - | - | 여기 |

이렇게 놓으면 고객이 "아, 나는 팀이니까 팀 플랜"이라고 스스로 고른다.

---

## 가격 페이지 체크리스트

가격 페이지를 만들 때 아래를 확인한다.

- [ ] 각 플랜에 **"누구를 위한 것인지"** 한 줄이 있는가
- [ ] 기능이 아니라 **"이걸 얻는다"**로 설명했는가
- [ ] 플랜 간 차이가 **고객 상황 기준**으로 나뉘는가
- [ ] 가장 인기 플랜에 **추천 표시**가 있는가
- [ ] CTA가 "구매"가 아니라 **다음 행동**(체험 시작, 데모 예약)으로 돼 있는가
- [ ] 자주 묻는 질문 3~5개가 바로 아래에 있는가

---

## 바로 어디에 쓰나

| 상황 | 적용 |
|------|------|
| 랜딩 가격 블록 | 결과 문장 + 플랜 비교표 |
| 가격 전용 페이지 | 체크리스트 전체 적용 |
| 제품 안 업그레이드 안내 | "지금 쓰는 것 vs 업그레이드하면 달라지는 것" |
| 제안서/견적서 | 오퍼 = 가격 + 포함 + 약속 구조 그대로 |

---

## 가격을 못 정하겠을 때

가격은 "정답"이 아니라 **실험 대상**이다.

**시작점 잡는 법:**
1. 경쟁사 3개의 가격을 본다 (비교 기준이 생긴다)
2. 고객 10명에게 "이 가격에 쓸 의향이 있나?"를 물어본다
3. 첫 가격은 한 달 안에 바꿀 수 있게 만든다 (고정하지 않는다)

**흔한 함정:**
- 너무 싸게 시작하면 나중에 올리기 어렵다
- 무료 플랜이 너무 넉넉하면 유료 전환 이유가 없다
- "일단 다 무료로 하고 나중에 과금하자"는 거의 안 된다

---

## 체크 질문

- [ ] 우리 가격 페이지에 "누구를 위한 것인지" 한 줄이 있는가
- [ ] 기능 나열이 아니라 결과로 설명돼 있는가
- [ ] 고객이 스스로 플랜을 고를 수 있는 비교 기준이 있는가
