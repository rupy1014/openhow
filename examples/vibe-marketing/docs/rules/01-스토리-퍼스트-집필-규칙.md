# 스토리 퍼스트 집필 규칙

## 한 줄 원칙
**정의보다 장면, 설명보다 질문, 이론보다 실제 사례를 먼저 둔다.**

## 규칙
1. 첫 3문단 안에 실제 문제 장면이 나와야 한다
2. 추상 명사만 늘어놓지 않는다
3. 고객 질문이나 실제 표현을 최소 1개 넣는다
4. 실습/체크리스트로 끝낸다

## 금지
- 교과서식 서론만 길게 쓰기
- 사례 없는 개념 설명
- 증거 없는 과장 문장
