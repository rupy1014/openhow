# 커뮤니티 참여 규칙

## 한 줄 원칙
**브랜드를 드러내기 전에 문제를 해결한다.**

## 규칙
1. 자사 홍보보다 질문 맥락 이해를 먼저 한다
2. 반복 질문은 질문 백로그로 환류한다
3. 커뮤니티 규범을 먼저 읽고 들어간다
4. 도움이 되는 링크와 문장을 준비한다

## 금지
- 광고성 진입
- 맥락 없는 링크 투척
- 커뮤니티 반응을 캡처만 하고 끝내기
