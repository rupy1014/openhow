# AI 초안 검수 규칙

## 한 줄 원칙
**AI는 초안을 빠르게 만들 수 있지만, 사실·톤·리스크는 사람이 책임진다.**

## 반드시 볼 것
1. 고객 언어가 살아 있는가
2. 증거 없는 주장만 늘어나지 않았는가
3. 가격/기능/보안/정책 표현이 정확한가
4. CTA가 단계와 맞는가

## 승인 레벨 예시
- 바로 발행: 내부 요약, 단순 리마인드
- 팀 리뷰: FAQ, 블로그, 비교표
- 리더 승인: 가격, 계약, 보안, 대외 발표
