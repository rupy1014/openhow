# Bootpay 블로그 디자인 개선 계획

> 벤치마크: [토스페이먼츠피드](https://www.tosspayments.com/blog)
> 작성: 2026-04-07

## 현재 vs 목표 비교

| 항목 | 토스페이먼츠피드 | Bootpay 블로그 (현재) | 목표 |
|------|---------------|---------------------|------|
| 네비게이션 아이콘 | 각 메뉴에 이모지/SVG 아이콘 | 텍스트만 | 이모지 아이콘 추가 |
| 카테고리명 | 한글 + 사용자 상황 기반 | 영문 기술 용어 | 한글화 |
| 카드 디자인 | 썸네일 + 제목 + 설명 + 날짜 | 날짜 + 태그 + 제목 (이미지 없음) | 썸네일 추가 |
| 레이아웃 | 좌측 사이드바 + 우측 콘텐츠 | 사이드바 없는 단일 컬럼 (BlogLayout) | 사이드바 추가 |
| 히어로 배너 | 상단 프로모션 배너 | 없음 | 추천 섹션 추가 |
| 서브카테고리 | 2단 접이식 | 1단 평면 | 2단 구조화 |
| 푸터 | 회사 정보 + SNS + 약관 | openhow 기본 푸터 | 커스텀 푸터 |

## 개선 항목 (우선순위순)

### 1. 사이드바 메뉴에 아이콘 추가

**범위**: `@openhow/types` + `packages/viewer`

- `NavigationItem` 타입에 `icon?: string` 필드 추가
- `Navigation.tsx`에서 icon 필드가 있으면 텍스트 앞에 렌더링
- 이모지 또는 SVG 아이콘 경로 지원

```
현재:  getting-started  |  subscription  |  commerce
목표:  💳 결제 시작하기  |  🔄 구독 결제  |  🛒 커머스
```

### 2. 카테고리명 한글화

**범위**: 콘텐츠 (폴더명/frontmatter만)

| 현재 | 변경 후 |
|------|--------|
| getting-started | 결제 처음 도입할 때 |
| subscription | 구독 결제 기획할 때 |
| commerce | 쇼핑몰 결제 붙일 때 |
| operations | 운영 중 꼭 알아야 할 것 |
| ai | AI 활용 |

### 3. 블로그 카드 썸네일 추가

**범위**: `packages/viewer`

- frontmatter에 `thumbnail` 필드 지원
- `blog-post-card`에서 좌측 썸네일 + 우측 텍스트 구조
- 썸네일 없으면 카테고리별 기본 아이콘 표시

### 4. 서브카테고리 구조화

**범위**: 콘텐츠 구조

```
결제 처음 도입할 때
  ├─ 기획 단계: 일정이 밀리는 이유, 화면 설계, 완료 확정 시점
  ├─ 결제 선택: 결제수단 고르기, 직접 구현 vs SDK
  └─ 심사·런칭: 심사 반려 패턴, PG 심사 준비, 테스트→라이브
```

### 5. 히어로/추천 섹션

**범위**: `packages/viewer`

- `openhow.json`에 `featured` 필드 추가
- 블로그 홈 상단에 추천 글 카드 3개 하이라이트
- 큰 썸네일 + 제목 + 간단 설명

### 6. 커스텀 푸터

**범위**: `@openhow/types` + `packages/viewer`

- workspace 설정에 `footer` 객체 지원
- 회사 정보, 고객센터, SNS 링크, 약관 링크 등
